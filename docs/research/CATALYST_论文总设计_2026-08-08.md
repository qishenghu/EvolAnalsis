## 1. 三幕叙事(每条证据标注状态:✅已入库 / 🔄主跑待出)

### 第一幕:法医式分析——模仿这条路从根上就是坏的
设定:多轮真实环境 agentic RL + text-only 黑盒跨家族教师 + 部分覆盖(37–91%),
工业界真实约束。核心问题(用户原表述的操作化):teacher off-policyness 如何
闭环地取精去糟、加速且不伤天花板。
1. ✅ **仪器饱和裁决**:判别器/序列比率开局 AUC 0.93–1.00,修正式范式(DUET v1
   / LUFFY 系)没有可用的测量器官;
2. ✅ **尾巴解剖**:off-policyness 是 token 级稀疏毛刺(~90% 孤立单点),深尾
   = 家族格式口癖 ∪ 计划枢纽词 ∪ 随机实体——**似然量原理上分不开精华与糟粕**;
3. ✅ **梯度错配定量**:plain SFT 把 45–55% 的损失质量花在最陌生的 10% token 上
   ——模仿把最大的力气精确花在最可能是毒的地方(图 1 素材);
4. 幕落逻辑:与其修理模仿(TRAPO 系的信任域=修理),不如**废除模仿**。

### 第二幕:CATALYST 设计——零模仿不变式 + 三通路 + 治理层
**不变式**:梯度只流过"学生自己写的、且被环境验证的 token";教师文本零进损失。
- **通路①转写**(主力):教师 think 作上下文参考 → 学生自写 → 环境验证 →
  hindsight 去提示 → φ 审计后重放。✅ 试点:真角点转写率 AF 98.1% / WS 58.9%
  (判据 15%);腔调无汇率成本(|Δ|<2pp,用原文);
- **通路②状态课程**(攻硬角点):重放教师前 k 步动作推进环境,学生接管,k 倒退
  火。✅ 试点:AF 角点 S(75%)=38.0%、坡度 +17.3pp;WS 半过(18.8%/坡度压线);
  重放零偏差;
- **通路③因果计价**(选择性的真正解法):同任务提示臂/裸臂的 SR 差 = 该教师素材
  的**环境实测因果效用**,驱动 ρ(脚手架比例)与退休——精华糟粕由环境裁决,
  不由似然猜;
- **治理层**:φ 仪器(零点自校准,forward 顺带)从过滤器转岗**审计师**——认证/
  加权去提示重放数据(✅ 纯度:WS p10 −0.05≈学生地板,17–26×;AF −0.82,2.1×,
  按预注册降级为"显著缓解",φ 审计因此训练期常驻)+ 熵恒温器 + 各 setpoint
  达成时教师项全零(不动点一致性,可证);
- **兜底层(可选)**:SIEVE v1 门控 BC 处理残差角点(✅ 残差:AF 1/52=2%、
  WS 14/56=25%),兼任 TRAPO 系对照臂。

## 2. 算法规格(训练循环)

任务级路由(重放统计在线驱动,任务随训练迁移):
- R0(无轨迹 或 SR_bare≥s_hi):纯 GRPO;
- R1(可引导):GRPO 组内 ρ_task 比例的 rollout 带教师 think 前缀(分臂基线,
  复用 BS 机制);ρ_task = clip(1−SR_bare/s_hi,0,ρ_max)·1[U_task>0];
- R2(角点,提示裸考皆败):entry-k 接管课程,k 由接管 SR 倒退火(0.75→0);
- 重放通道:去提示的自写成功轨迹作辅助 BC(自我克隆),token 权重 = φ 审计
  w=min(1,e^φ)(自写数据近地板,w≈1,审计只挡个别漂移点);窗口内刷新防陈旧;
- 熵恒温器:A′=A+λ(−logπ−b),λ 追 H_ref;
- (消融/兜底)残差角点可开 SIEVE v1 门控 BC:μ·m·w·CE,μ 由前沿债驱动。
全部旋钮(ρ、k、U、λ、w、退休)由在线读数驱动,无手工日程。

**与 v1 的关系**:v1 的门控 BC 不再是主角,是兜底层与对照;v1 的测量学
(φ/CLL)全部保留并升级职能(审计/计价/退休)。

## 4. 实验设计

**主表**:4 环境(AF/WS/SciWorld/DeepSearch)× 2 教师(flash 跨家族/122B 同家族)
× 3 seed;方法:GRPO、SFT→GRPO、CHORD、LUFFY-adapted、TRAPO-adapted(TrSFT+
前缀阶梯搬到 agentic,主动头对头)、DUET v1、CATALYST(±兜底层)。
指标:终点 SR(天花板)、学习曲线 AUC(加速)、达到 X% 的样本数。

**机制图五张**:F1 梯度错配(45–55%→5–27%);F2 转写漏斗(角点 0% → 提示下
98/59% → 全通道残差 2/25%);F3 纯度三分布(教师文本 vs 去提示自写 vs 学生
地板);F4 退休动力学(ρ/k/U→0 而 SR 继续升——"脚手架拆除后房子自己站着");
F5 家族轴(同一算法,两教师,脚手架用量/审计读数自动分化,无家族标签)。

**消融**:−转写、−状态课程、−因果计价(ρ 均匀)、−去提示(带提示训练=泄漏
检验)、−φ 审计、±兜底层、TrSFT 头对头、恒定 ρ 对照(BC-parity 教训:每个
自适应组件配恒定版)。

**覆盖谱分析**:教师覆盖 37–91% 作横轴,验证部分覆盖下的鲁棒性(满覆盖假设
是 TRAPO 系的隐含前提,我们不需要)。

## 5. 相关工作定位(一句话版)

| 家族 | 代表 | 我们的分界 |
|---|---|---|
| 门控模仿 | TRAPO/LUFFY/CHORD/IDFT | 他们修理模仿(教师 token 在损失里);我们废除(零进损失);其信任域=我们的兜底消融 |
| 自我提升 | STaR/RFT/ReST | 单轮 QA、提示=答案;我们:多轮环境过程验证、hindsight 去提示 + φ 认证、因果计价、退休治理 |
| 蒸馏 | GKD/on-policy KD | 需教师 logits;我们黑盒 text-only |
| 状态课程 | Backplay/反向课程 | 经典 RL 状态;我们经由契约级确定性文本重放,面向 LLM agent |
| 语境教学 | States-not-Tokens/context distillation | 有通道无治理;我们闭环治理 + 环境验证转写 |

**统一主张**:首个使黑盒教师知识**只能**以学生自写、环境验证的经验形态进入
多轮 RL 的框架;由法医式测量直接导出,治理全闭环,脚手架可证自拆。
