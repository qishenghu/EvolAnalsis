# CATALYST v6 设计:思考保全 + 峰值锚定(基于零自举 v4)

日期:2026-08-21。地位:设计提案,待用户裁决后实施。
目标(用户指令):基于零自举 v4 改进,**前中期保持加速,后期不退化坍缩**。
约束:hint 通道弃用是既定裁决(只保留教师前缀重放 entry);不缝补纪律
(每版一个原则性改动,不堆 trick);先 1 seed 试点。

## 一、诊断:五步排除后幸存的机制链

对 5 个 run(v4 s0/s3、GRPO s0/s1/s2)的全程遥测、rollout 逐行统计与
具体轨迹阅读,先记录**被证伪的四个假说**(过程保留,防止回头路):

| 假说 | 证伪证据 |
|---|---|
| 低熵⇒崩盘,加熵恒温器 | v4_s0 末段熵最低(0.21-0.25)却最健康;GRPO_s2 断崖时熵 0.54 |
| "打转但成功"轨迹拿正优势自增殖 | 成功轨迹 revisit 步占比五 run 全程平稳 5-8%,无组间差异 |
| m(1−m) 课程集中螺旋(任务变窄) | 任务是固定扫场,每 era 320 行全唯一,五 run 完全一致 |
| 先验锚定负压(整批净负优势挤压) | s3 末段 advMean **+0.04~+0.05**(锚定校准良好);反而 GRPO_s2 advMean −0.6 对上其 step60 断崖——那是基线自己的病理,记入对比叙事 |

同时更正一处旧口径错误:s3 **训练批内得分末段稳定 0.72**(此前把
response_length 误读为 score)。于是核心矛盾变为:
**训练侧全程健康(0.72)+ val 崩 20.7pp = 泛化裂口,不是训练时退化。**

幸存的机制链(证据链完整):

1. **think 萎缩是唯一分化变量**。每步决策响应长度(token,era 均值):
   - v4_s0(健康,val@100=75.0):234 → 104 → 127 → 104 → **93**
   - v4_s3(崩盘,val@100=39.8):192 → 157 → **44 → 37 → 42**
   具体轨迹对读:step 5 的 think 在做任务语义推理("任务说清洗后放台面,
   所以…");step 95 只剩反射套话("I have the egg. I should prepare
   coffee.")。
2. **萎缩的时间起点 = entry 退火归零之后**(era 41-60,aux→0)。教师
   122B 的 think(占教师 token 85.2%)从上下文消失后,batch 里再无长
   思考的分布锚;RL 的正优势梯度对短响应的偏好失去对抗力量,
   萎缩自增强(成功的短 think → 更短)。
3. **为什么训练不崩、val 崩**:课程任务第二次到访,"条件反射"够用
   (bare SR 0.72);held-out 新任务需要真推理,思考萎缩的策略没有储备,
   滑入徘徊吸子(训练 rollout 的 rep3 前兆:0.15@80;val 失败样本
   死循环占比 59%@100)。
4. 熵收窄、Brier 回升(0.14→0.34)、rep3 上升皆为下游症状。

一句话病因:**v4 的闭环只管"给不给教师上下文",不管"学生的思考器官
是否在退化"。退火把教师 think 撤走后,没有任何机制保卫学生自己的
deliberation,而 deliberation 正是泛化的储备。** 这直接回到项目初心:
"teacher 是怎么思考的也值得学习"——v6 把它变成机制。

## 二、设计:v6 = 零自举 v4 + 双闭环

### 闭环 A:思考保全(治因)——退火不许归零,地板与 think 健康度联动

把 bare 行响应长度 EMA(L̂_think,现成遥测 response_length/mean 按臂
拆分即可)纳入法则状态。排产时给 entry 加**份额地板**:

    aux_floor = 0                          若 L̂_think ≥ θ·L_ref
    aux_floor = f_min(如 12.5%,16/128)   若 L̂_think < θ·L_ref

其中 L_ref = era-1 的 bare think 长度基线(零自举:开局自测,无先验),
θ≈0.5。含义:学生思考健康时完全退火(保持 v4 的课程行为,前中期加速
不受影响);思考开始萎缩时,教师 think 强制回到上下文里当分布锚。
**复用现有排产机制,不加任何损失项,不动优势公式**——这是 v4 统一
分配法则的自然扩展(法则的输入从"会不会做"扩到"还会不会想"),
不是新 trick。

保全的因果通路有三条(与用户对齐 2026-08-21):
1. **在场通路(即时)**:entry 行上下文带教师 122B 完整 think(教师
   token 85% 是 think),学生在其后续写,自己的 think 被条件生成拉长
   拉深——不需梯度即起效;
2. **梯度通路(巩固)**:以丰富 think 为条件的续写成功后拿正优势,
   "在此状态这样思考"被写进参数——教师思考方式经学生自己的成功续写
   内化,非 BC 硬抄(延续"上下文进、损失不进"哲学);
3. **压力对抗通路**:think 萎缩的驱动力是正优势下的长度压力,损失
   聚合偏置核查(见附查项)若证实即修——A 是带病时的主动再锚定,
   偏置修复是釜底抽薪,二者互补。

### 闭环 B′:冻结式 EMA 锚 + 训练侧健康信号(保底)

【2026-08-21 修订,用户裁决触发】初版 B 用"最优 val checkpoint"做锚、
val 峰差控 λ——**被用户否决,理由成立**:我们的 val 即汇报指标(128
任务,无独立 test),val 进训练闭环 = 直接优化汇报指标 = 基准泄漏;
且方法将依赖"目标 benchmark 有 val 可用",泛化主张自毁。修订如下:

- **锚**:策略权重的慢速 EMA(Polyak 平均,mean-teacher 谱系),
  不引用任何评测数据;
- **健康信号全部来自训练 rollout 自身**(跨环境通用、已在测):
  ①bare 行 think 长度 EMA(闭环 A 同源);②rep3(训练样本中同动作
  连打 ≥3 的占比);③值表 Brier(预测突然变差 = 策略漂移);
- **控制逻辑**:信号健康 → EMA 正常跟随、λ_KL≈λ₀(0.001,形同无,
  不伤加速);信号恶化(如 rep3>0.10 或 L̂_think<θ·L_ref 或 Brier
  EMA 突升)→ **冻结 EMA 更新**(锚停在最后一个健康策略)并升 λ_KL
  (平滑升至 ~0.02),信号恢复后解冻、λ 衰减。

retrodiction 不受修订影响:s3 在 step 80 时 rep3=0.15 且 think 已塌
(37-44 token),训练侧信号在 val 崩盘(90-100)之前就会触发。

**汇报层配套(与训练无关但同源于泄漏防线)**:ALFWorld eval 池大于
现用 128,切一个不相交 test 集——val 仅用于 checkpoint 选择,test
报数。论文的选点操作从此完全干净。

### 附查项(实施前一行核查)

损失聚合方式(token-mean vs seq-mean)是否在正优势下天然奖励短响应
——若是,属长度偏置,修正它是 bias 修复不是补丁,与 A 互补。

## 三、回放检验(诚实标注:定性 retrodiction,非模拟)

- **A 的证据**:s0 天然保持长 think 且不崩(长 think 与健康同现);
  s3 萎缩起点恰在退火归零后(时序吻合);教师素材 85.2% 是 think
  (地板抬起后有货可放)。反例检查:s0 的 aux 也退火,为何 think 没
  萎缩?——n=1 无法排除运气(s0 开局 think 更长 234 vs 192,可能
  路径依赖);所以 A 必须做同种子 A/B 才算数。
- **B′ 的 retrodiction**(全部用训练侧信号回放,对三个崩盘 run):
  s3 的 rep3@80=0.15、think 长度 era 41-60 已跌破 θ=0.5 基线(44 vs
  192×0.5=96)——A 地板会在 era 41-60 抬起,B′ 会在 val 崩盘(90-100)
  之前冻结锚并升 λ;GRPO_s2 的 rep3@60=0.18 对上断崖@60 当步触发;
  s1 的 rep3 全程 0.12-0.19 高位,会早触发(它属慢性病,B′ 对它是
  持续收紧而非一次拉回)。健康 run 的检查:GRPO_s0 末段 rep3
  0.00-0.03、v4_s0 rep3 0.03-0.04 且 think 稳 93-127——**两个健康
  run 全程不触发,无误伤**。
- **前中期加速**:A 在思考健康时 floor=0,B′ 在信号健康时 λ≈λ₀,
  两个控制器在 1-50 步(各 run 信号均健康)都不介入——加速主张
  (step50 达 GRPO step90 水平)
  不受影响。

## 五、风险与边界

- A 的地板若常驻触发,退火名存实亡 → 遥测 aux_floor_active 占比,
  >50% 步数触发即视为设计失败信号。
- B 的 λ 阶跃可能引起损失尖峰 → 平滑升档;ref 热换用现成权重同步
  管线(export/reload 25s,每峰值事件一次,可忽略)。
- think 长度是 deliberation 的代理指标,可被"注水"钻空子(长而空的
  think)——正优势不奖励注水(注水不提高成功率),风险可控;若出现,
  升级为 think 质量判据(留 v6.x)。
