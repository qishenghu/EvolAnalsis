# 近邻调研:teacher 经验利用 × on-policy distillation(2026-08-19)

**动机**:v4 已实现 2.5× 加速,但终点仅 +5pp——怀疑撞到"信号源瓶颈"。
本调研回答:别人怎么用 teacher 经验、我们独特在哪、瓶颈是不是真的、下一步弹药。

---

## 一、三大流派全景

### 流派 1:教师 token 进损失(off-policy 校正系,2024–2025 主流)

| 方法 | 教师信号通道 | 校正手段 |
|---|---|---|
| LUFFY | 教师轨迹混入 GRPO 组 | 策略整形 π/(π+γ) 放大低概率教师 token |
| CHORD | GRPO + 加权 SFT 辅助损失 | token 级 p(1−p) 权重 + μ 调度 |
| TAPO/SRFT/ReLIFT/UFT/Prefix-RFT | 模板注入/混合微调/交错 FT/前缀脚手架 | 各式熵感知/信任域(TRAPO)加权 |
| **DUET(我们的前身)** | BC 通道 + 判别器密度比 + 进度 shaping | 被 NeurIPS 裁定"启发式堆叠" |

**共同软肋**(也是我们 v1 用血换来的定律):教师 token 进损失就要正面处理
off-policyness,校正只能减毒不能除根;且"是校正有效还是模仿本身有效"归因困难。

### 流派 2:教师进上下文,不进梯度(2606–2608 爆发,与我们同路)

| 方法 | 特权上下文 | 与我们的差异 |
|---|---|---|
| **ZPPO**(2606.18216) | 教师响应重构为对比式问题(BCQ/NCQ),难题循环直到 50% 准确 | 哲学同源("Teacher in Prompts, Not Gradients"!);但无状态通道、无分配法则、无退火机制,聚焦零奖励逃逸 |
| SDPO | 兄弟成功轨迹当上下文 | 自产上下文(≈我们学生状态池的 token 版);实测在部分骨干上退化 |
| Skill-SD | 技能摘要库 | 手工上下文,LOPD 实验示其不稳 |
| **LOPD**(2608.13040) | 可学习 latent token(检索+压缩) | 上下文端到端学习 + margin 防塌;基建重、不可解释 |

### 流派 3:on-policy 蒸馏(OPD:学生采样、教师逐 token 打分)

| 方法 | 要点 | 对我们的意义 |
|---|---|---|
| GKD / Thinking Machines OPD | 学生 rollout + 教师 reverse-KL,能力转移的成熟范式 | 稠密信号的标准做法 |
| **SAGE-OPD**(2606.19659) | **多轮 agentic**(ALFWorld!):教师在学生轨迹劣化时**选择性接管**+蒸馏 | 与我们同场地;其"教师接管"恰是我们 entry-k 的镜像(教师续学生 vs 学生续教师) |
| KL-Agreement-Trap(2606.09471) | 诊断 OPD 失败模式:token 分布一致 ≠ 任务成功 | 佐证我们"只信环境"的立场 |
| **OPSD 降多样性**(2606.26091) | **OPSD 使 pass@k 曲线变平**:教师条件打分放大既有模式,权重集中;RL 保持概率比例 | **关键预警**:pass@3 是我们的招牌指标,朴素 OPD 桥会伤它 |

## 二、我们在版图上的位置(诚实评估)

**独有资产(三样,均无近邻)**:
1. **分配法则**:所有近邻都"固定使用"特权上下文;没人回答"何时/何任务/哪种
   上下文值得用"。我们的 V̂(1−V̂)×锚定是这个空缺的答案,且与任何流派可组合;
2. **状态通道(修正版主张,2026-08-19 用户纠正)**:"从半程接着练"本身
   有完整谱系——token 前缀系(TRAPO prefix learning 率先、Prefix-RFT、UFT)
   与状态重置系(Backplay、Salimans-Chen 2018)。我们的增量是三个限定词的
   **组合**:①介质是动作重放出的**环境状态**而非 token 前缀(教师推理文本
   零出现,规避 v1 实测的文风/内容泄漏);②前缀取自**学生自产**成功轨迹
   (治 exposure bias);③用量由可学习性法则**逐任务竞价**而非固定退火表。
   单点皆有前人,组合与调度层是我们的;related work 须给全谱系。
3. **纯环境信号**:零 token 克隆、零蒸馏——在 OPSD 降多样性的证据面前,
   这从"保守"变成了"先见":我们 pass@3 84–88 健康,OPSD 系按该文预测会变平。

**真实的瓶颈(承认)**:我们是同一份稀疏结局信号的**更好调度者**,不是新的
**信号源**。终点仅 +5pp 的根源:天花板由"结局奖励 + prompt 条件"所能榨取的
上限决定。OPD 系的稠密逐 token 信号正面攻这个瓶颈——代价是多样性与
"KL 一致陷阱"。

## 三、突破瓶颈的三条路(按风险/收益排序)

| 路 | 内容 | 依据 | 风险 |
|---|---|---|---|
| **A. 任务级分配(v4.1b)** | 法则上移:dataloader 按可学习性采样任务 | 纯预算效率,零新信号源,与瓶颈正交但无害 | 低 |
| **B. V̂ 门控 OPD 桥(v5 主候选)** | 裸 rollout + hint 条件自我重打分 + reverse-KL,**仅在 V̂_hint−V̂_bare>m 的任务**,并带多样性护栏(监控 pass@k、只蒸馏低 V̂_bare 任务、熵地板) | LOPD/SAGE 证明稠密信号有效;2606.26091 的教训内建为门控 | 中:多样性、KL 陷阱 |
| **C. 救场通道(新 context 类型)** | 学生裸跑劣化 → hint 自我接管救活 → 从救场点重试,纳入 context 族竞价 | SAGE-OPD 镜像 + 我们分配法则的自然扩展;把失败轨迹变成前沿奖励 | 中:实现量 |

**建议节奏**:3 seed 终裁(8/22)前不动;终裁后若确认"终点差距是主要遗留",
先 B 后 C(B 的多样性护栏必须一开始就在,而非事后补)。A 可与任何路并行。

**论文定位收益**:本调研直接产出 related work 的定位表——我们与 ZPPO 的
分界(分配法则+状态通道)、与 OPD 系的分界(环境信号纯度+多样性保持,
引 2606.26091 为据)、与 off-policy 校正系的分界(v1 失败的因果证据链)。
