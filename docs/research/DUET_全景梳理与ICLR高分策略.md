# 第一部分：我们原来做的 DUET 是什么

## 1.1 要解决的问题

用 GRPO 在交互环境（ALFWorld/WebShop）里训小模型 agent，冷启动是死穴：1.5B 学生纯
on-policy 训练在 ALFWorld 上只有 **1.0%** 成功率——探索不到成功轨迹，就没有正向奖励，
就永远学不会。最自然的解法是把强教师（Qwen2.5-72B）的成功轨迹混进 rollout batch，
让学生"看着学"。LUFFY、CHORD 都是这条路。

我们的出发点：**直接混合是有偏的**，而且偏差可以被精确指出：

- **Bias 1（基线污染）**：GRPO 用组内平均奖励做基线。教师轨迹都是成功的（success-filtered），
  混进来把组均值抬高，on-policy 样本的 advantage 被系统性压成负值——**探索被惩罚**。
- **Bias 2（分布错配）**：教师轨迹是别的策略生成的（off-policy），按 policy gradient 理论
  应该做重要性修正 π_θ/π_teacher。但教师往往只给文本、不给 log-prob（API 模型尤其如此），
  修正项算不出来，大家就默默不修。

## 1.2 算法：先纠偏、再提取（correct-then-extract）

**第一步（纠偏）**两个机制：

- **BS（Baseline Separation）**：teacher 样本和 on-policy 样本分开算均值/方差。消掉 Bias 1。
  一行统计学，但消融显示去掉它 1.5B 训练直接崩到 **0.0%**——全文最硬的因果证据。
- **DR3（密度比修复）**：训一个小判别器 D 区分"这段文本是学生生成的还是教师 cache 的"，
  用 ŵ = D/(1−D) 估计缺失的密度比（实现里是 α-relative 形式，有上界 ≈1.13，**只能降权
  不能放大**）。教师样本的 PG 项按 ŵ 加权。关键性质：学生越像教师，ŵ 越接近 1；训练后期
  ŵ 自然衰减（实测 0.94→0.53），教师影响自动退场，无需手调 schedule。

**第二步（提取）**两个通道：

- **BC（动作通道）**：对教师 token 做加权行为克隆，权重 μ 由**同一个判别器**的准确率驱动
  （μ ∝ 1−disc_acc）：判别器分不出师生 → 学生已像教师 → BC 减小。一个判别器同时服务
  纠偏和调度，是设计上的得意之笔（后面会讲它如何变成隐患）。
- **SC（状态通道）**：从教师轨迹建"进度图" Φ(s)（每个观测在教师轨迹里出现的相对位置），
  给 on-policy 轨迹按访问状态的平均进度发稠密 shaping 奖励。只加给 on-policy 样本。

## 1.3 原来的 infra

- 栈：AgentEvolver 框架 + veRL（FSDP 分布式训练）+ vLLM（colocated rollout，训练和推理
  共卡、sleep/wake 切换）+ Ray。Hydra 配置，`launcher.py` 入口。
- 环境：FastAPI + Ray actor 的 env service（ALFWorld :8081 / WebShop :8083）。
- 模型：学生 Qwen2.5-1.5B/3B（+7B 做 scaling 分析），教师 Qwen2.5-72B 离线采集的轨迹
  cache（AF 19K 条 / WS 26K 条），react_tags 文本格式。
- 训练协议：100 步，n=8 rollout 每任务混 1 条教师轨迹，验证 200 任务 strict SR。

## 1.4 拿到的结果（NeurIPS 主表口径）

| 1.5B | GRPO | LUFFY | CHORD | SFT→GRPO | DUET |
|---|---|---|---|---|---|
| ALFWorld | 1.0 | 5.5 | 27.0 | 30.0 | **47.5** |
| WebShop | 0.5 | 5.5 | 11.5 | 18.5 | **36.0** |

加上 7B 的安全性故事：教师已无用时 LUFFY 反而有害（−2.9/−3.7），DUET 中性偏正（+1.8），
因为 ŵ 自动退场。

# 第二部分：遇到了哪些问题

## 2.1 评审怎么说（4 / 3 / 3，未过线）

三份评审归成三条主线：

1. **泛化面窄**（UyKJ, 4 分）：只有两个 2023 年的文本环境、SC 依赖观测精确匹配、
   教师只有一个、没有跨家族学生。
2. **理论定位存疑**（bDeY, 3 分, 高置信）：Eq.9 印出来是 ŵ·ρ 乘积，读起来像修正叠加了两次；
   "principled" 的宣称覆盖了 SC 这种明显的启发式——**overselling**。
3. **证据质量**（y9x6, 3 分）：单 seed headline、方差没报、若干 claim 依赖单点数字。

## 2.2 Rebuttal 期自查出来的问题（比评审说的更痛）

为回应评审我们做了全面 forensics，结果自己挖出一串雷（都记录在 `rebuttal/paper_corrections.md`
C0–C9）：

- **WS 主表 36.0% 复现不出**：固定同 seed 同课程重跑 3 次得 16.5/14.0/6.5（均值 12.3）。
  36.0 是单 seed 的幸运值。
- **3B 列找不到 validation log**（C0）：主表 3B 数字在本机不可复算，附录图和主表来自
  不同的 run。
- **公式与代码不符**：Eq.8 实际是 α-relative 有界形式；Eq.9 实际是分母替换不是乘积；
  一度用来辩护的 telescoping 推导被三次 code audit 证伪。
- **配置归属错误**（C7）：主表 WS cell 记错了 config；两环境的 μ 超参其实不同
  （AF 0.3/0.05/0.4/0.5 vs WS 0.3/0.10/0.6/0.2），而我们公开说过"只有 d_floor 不同"。
- **两环境跑的其实是两种算法**（C8）：AF 的 teacher 项走 clip 形式，WS 走
  ŵ×policy-shaping 形式——论文只印了前者。

## 2.3 最深的科学问题：BC-only parity

Rebuttal 期补的对照实验里最扎心的一个：**BC-only（μ≡1.0 固定 + BS，不要 DR3 不要 SC
不要自适应）居然和 DUET 打平**——WS 上两者的多 seed 分布完全无法区分；AF 上 BC-only
在 step 50 还领先（48.0 vs 42.5），只在 step 100 输（31.0 vs 47.5，BC-only 峰值后崩）。

这意味着：如果不能证明自适应机制在某个 regime 里**明确赢过恒定 μ**，整套
correct-then-extract 装置就有"过度工程"的嫌疑。这是比任何评审意见都严重的威胁，
也是 ICLR 版实验设计的核心靶点（好消息：AF 那条"BC-only 峰值后崩、DUET 持续上升"的
曲线形状，本身就是自适应价值的证据雏形）。

**一句话总结 NeurIPS 的失败：方法没输，输在证据形态（单 seed、复现、口径）和宣称尺度
（principled 覆盖过宽）。这个结论直接决定了 ICLR 版的两条军规：所有数字可从 raw log
复算；所有宣称在 baseline 也 multi-seed 之后仍成立。**

# 第三部分：ICLR 版的计划与理由

## 3.1 为什么换模型：Qwen3.5-4B/2B 学生 + DeepSeek/122B 教师

三个理由，重要性递增：

1. **时代性**：Qwen2.5-1.5B 在 2027 年的 ICLR 上是老模型，"你的方法在推理模型上还成立吗"
   是必然会被问的问题，与其被动挨打不如主动做。
2. **叙事升级**：教师换成 API 模型（DeepSeek-v4-flash 走 OpenRouter）让"教师只有文本、
   没有 log-prob"从实现上的无奈变成**设定的主张**——任何 API 模型都能当教师，跨 tokenizer、
   跨家族。这是 DUET 相对需要教师内部信息的方法的真实差异化。
3. **新科学问题**（最重要）：推理教师的轨迹 **85.2% 的 token 是 `<think>`**。跨家族的
   think 文本对学生来说是支撑集之外的（学生几乎不可能生成 DeepSeek 风格的推理）。
   这把 off-policyness 推到了极端，正好是 DUET 这类"off-policy 修正"方法该被检验、
   也最有东西可讲的地方。

教师双轨的分工：**Qwen3.5-122B-A10B（同家族）做主教师**——风格 gap 小，DR3/μ 的机制有
正常的学习曲线，NeurIPS 版的 fade-out 叙事能存活；**DeepSeek-v4-flash（跨家族 API）做
压力测试**——支撑"任何 API 教师"的适用性主张，同时把家族 gap 本身变成一条科学轴。

## 3.2 新 infra：为什么长这样

- **方案 (b)：vendor 旧 verl + rollout 外置**。Qwen3.5 需要新 transformers/vllm，但我们
  的 fork 对 verl 内部依赖 ~8000 行，全量升级要 15-25 人日且要重验一切正确性。方案 (b)
  把训练环境（`duet2`：torch 2.9 + vendored verl）和推理环境（`vllm2`：vllm 0.19 起
  4 个外置 rollout server）解耦，每步做 FSDP→vLLM 权重同步（实测 34-45s，带 checksum）。
  **DUET 的全部算法代码一字不动**——正确性零重验，这是选它的根本理由。
- **exact-snapshot 上下文管理**。推理模型的多轮训练暴露了一个此前没人意识到的 bug 类：
  rollout 时模型看到的上下文和训练时构造的上下文不一致（旧实现事后改写历史前缀，
  token 一致性 0/6）。新方案：确定性 token 预算渲染器 + **只训"采样时确切条件下的那个
  决策"**。长度契约锁定 32K = 22,528 prompt + 10,240 response。
- **师生同上下文军规**（你 08-01 定的）：先定上下文方案 → GRPO 验证 → 教师在**同一套
  上下文下**采集。否则教师选动作时看到的信息学生看不到，BC 等于在克隆"从可见上下文
  推不出来的动作"。已采的 4000 条 v4-pro 全观测轨迹因此 on hold。
- 现状：ALFWorld/WebShop 的 Qwen3.5-4B GRPO 基线已在新栈跑通（WS 正在 s200 长跑，
  step ~179，训练期 SR 50-64%，熵健康）；122B 已下载完；SciWorld env 就绪。

## 3.3 新设定暴露的新问题（这是算法层面真正要动刀的地方）

先建立一个直观图景。教师（DeepSeek）的一条轨迹长这样：

```
<think> 好，用户要找一个干净的杯子。ALFWorld 里杯子通常在柜子或水槽附近，
我应该先去检查 cabinet 1，如果没有再看 sinkbasin…… </think>
<action> go to cabinet 1 </action>
```

`<think>...</think>` 占全部 token 的 **85.2%**，是 DeepSeek 自己的"说话方式"；
`<action>` 只占一小部分，且受环境语法约束（合法动作就那几十种写法）。学生是
Qwen3.5——它自己也思考，但用的是 Qwen 的说话方式。让学生给 DeepSeek 的 think
文本逐 token 打分（算 log-prob），分数会**极低**：不是内容错了，而是风格不是它的。

**"学生给跨家族 think 文本打分极低"这一件事，是下面三个故障的共同根源**——
三个机制对它做出了三种不同的错误反应。

off-policyness 在新设定下实际分裂成两个性质不同的 gap：

- **G1 风格 gap**：教师的 think 是另一个家族的文风，学生对它 p≈0。这不是我们要学的。
- **G2 能力 gap**：教师会解这个任务、学生不会。这才是我们想提取的东西。

DUET 现有机制把两者混在一个标量 ŵ 和一个标量 μ 里。同家族时二者近似重合
（所以 NeurIPS 版没暴露），跨家族时二者背离：

### 故障 1：判别器"双杀"——两个学习通道在第 0 步同时关闭

判别器的工作是回答一个问题："这段文本是学生自己生成的，还是教师 cache 来的？"
它用的特征不是文本本身，而是**学生给这段文本打的分**（log-prob 的均值/方差/最低值、
"打分低于 −10 的 token 占比"等，见 `dr3_ratio.py:146-175`）。

- **旧设定（同家族）**：Qwen2.5-72B 教师和 Qwen2.5 学生文风接近，学生给教师文本
  和给自己文本打的分差不多 → 判别器起初分不出（准确率 ≈50%），随训练慢慢学会
  → disc_acc 从 0.5 **缓慢爬升**到 0.95。DUET 的全部自适应机制都建立在这条缓慢
  爬升的曲线上：ŵ 缓慢下降（教师影响缓慢退场）、μ 缓慢下降（BC 缓慢减弱）。
- **新设定（跨家族）**：学生给 DeepSeek think 打的分第 0 步就断崖式低于自己的文本
  → 判别器**第 0 步就能近乎 100% 分对**。

disc_acc 一上来就 ≈1，触发两条方向相同的连锁反应：

```
disc_acc ≈ 1 ─┬→ ŵ = D/(1−D) ≈ 0（被下限 w_min=0.01 兜住）
              │    → 教师样本的 RL 梯度被乘 0.01 → PG 通道关闭
              └→ μ ∝ (1−disc_acc) ≈ 0（落到 valley）
                   → BC 权重归零 → BC 通道也关闭
```

两个从教师学习的通道**同时静音**：花钱采的教师数据实际没被用上，DUET 退化成
GRPO+SC。"一个判别器同时服务修正和调度"这个 NeurIPS 版的得意设计，在这里变成
单点故障。

最讽刺的是：**判别器没有坏**。学生确实永远不会生成 DeepSeek 风格的 think，
"这两个分布可以完美区分"是对所提问题的正确答案。错的是我们问的问题——我们想
知道的是"学生会不会做这个**动作**"（能力问题，G2），却让判别器看**整条序列**，
答案被 85% 的风格 token（G1）淹没了。

### 故障 2：对 think token 做策略梯度——既没道理，又危险

教师 PG 通道（Eq.9）把教师轨迹里的**每一个 token** 都当作要强化的"动作"，
按 advantage 加权推高其概率。拆开看是两个问题：

- **修正不可估**：学生**自己** rollout 的 think 做 PG 没有任何问题——那是标准
  reasoning RL，on-policy 不需要修正。但**教师**的 think 做 PG 需要密度比修正，
  而跨家族 think 的真实比率 ≈0 且无法可靠估计：这一项要么被 ŵ 归零（等于没学），
  要么在错误的 ŵ 下偏差不可控。**问题不是 think 不该学，而是"带重要性修正的 RL"
  不是学它的正确工具**——正确工具是 BC（见故障 3 与 §3.4）。
- **危险**：策略梯度的推力 ∝ ∇log π(token)，而这个量在 p 越小时越大。对一个学生
  打分 p≈e^{−10} 的 token，梯度是巨大的——等于用很大的力气把学生往"逐字模仿
  DeepSeek 的说话方式"上推。几千个这样的 token 加起来，就是一股带 reward 权重的
  风格改造力，足以破坏学生自己的格式与熵稳定性（我们在新栈已经见过格式崩溃有
  多致命）。BC 通道有 φ(p) 阻尼挡着（见故障 3），**PG 通道什么都没有**——clip
  形式下 ŵ 是整条轨迹一个数，挡不住单个 token 的爆炸。

### 故障 3：BC 的 φ(p) 加权——挡住了爆炸，也挡住了想学的东西

BC 通道对每个教师 token 的损失乘一个权重 φ(p)=p(1−p)，p 是学生对该 token 的概率
（CHORD 的设计，我们默认开启）：

| 学生对该 token 的把握 | φ 权重 | 含义 |
|---|---|---|
| p≈1（已经会了） | ≈0 | 不浪费梯度 |
| p≈0.5（半会不会） | 最大 | 重点学 |
| p≈0（完全不会） | ≈0 | **也不学** |

跨家族设定下这是双刃剑：

- **好的一面**：DeepSeek think token 全是 p≈0，φ 自动把它们静音——故障 2 的爆炸
  风险在 BC 这一侧天然被挡住了，不会训崩。
- **坏的一面**：85.2% 的教师 token 恰恰就是这些 p≈0 的 think token。所以**冷启动
  阶段 BC 实际上把教师的推理内容整个跳过了**，只在学动作和常见短语。而"冷启动时
  最需要教师的推理示范"正是我们想主张的卖点——机制和主张自相矛盾。随着学生文风
  逐渐靠近，think token 的 p 上升、进入可学区间，BC 才开始学它们。这其实是一种
  "自步课程"（先学近的、再学远的），可以正面写进论文，但前提是我们意识到它、
  测量它，而不是以为 BC 从第一步就在做推理蒸馏。

### 三个故障的共同结构（一句话）

同一个事实——学生给跨家族 think 打分极低——被三个机制做出三种错误反应：
**判别器把它当成"师生可分"的证据（过度反应），PG 把它当成要推高的目标（危险反应），
φ 把它当成不可学的噪声（保守反应，误伤了推理内容）**。

注意三个故障没有一个说明"教师的 think 不值得学"。恰恰相反——DUET 的初心是让学生
快速适应并吸收 off-policy 的教师，包括教师怎么思考。故障说明的是**工具用错了地方**，
修正原则（§3.4）：**gap 不可估处用监督，gap 可估处用 RL**——监督通道（BC）不需要
密度比，跨支撑集依然无偏（DeepSeek-R1 → Qwen 学生的纯 SFT 蒸馏是现成先例），
教师的 think 由它全额承担；ŵ 加权的 RL 通道只在比率可估的 action 段工作；μ 的语义
修正为"**差距大 → 多模仿，学会了 → 退场**"（现在的 disc_acc 驱动在跨家族下恰好把
这个方向弄反了）。

## 3.4 算法改进提案：DUET-R（segment-aware 化）

核心原则（通道分配）：**think 不是不学，而是换正确的工具学**。监督通道（BC）不需要
密度比，跨支撑集依然无偏——教师的 think 由它全额承担（R1-distill 先例：DeepSeek-R1
→ Qwen 学生的纯 SFT 蒸馏，跨家族 think 可学且高价值）；RL 通道（ŵ 加权 PG）需要
可估的密度比，只在支撑重叠的 action 段工作。完整动力学正是初心的字面实现：
**冷启动 think-BC 主导（快速吸收教师怎么想）→ 学生分布向教师靠近 → 密度比可估 →
修正后的 action-PG 接棒 → 掌握后 μ、ŵ 自然退场**。具体四条改动：

- **R1**：判别器特征收窄到 **action 段**。ŵ 回到它的 MDP 语义（"学生在该状态会不会产生
  这个 action"），action 受环境语法约束、跨家族支撑重叠大，disc_acc 恢复正常爬升，
  fade-out 叙事存活。
- **R2**：teacher PG 统一为 **ŵ_act × f(π) shaping** 一种形式（两环境同一算法，根治 C8）。
  think 退出的**仅是 ŵ 加权的 RL 项**（比率在那里不可估），学习信号由 BC 全额承担。
  f(π)=π/(π+β) 的梯度在 π→0 时消失，是现成的 token 级信任域（当年的 WS 稳定性补丁，
  升格为方法本体）。
- **R3**：μ 分段 + 语义修正——**μ_think 是冷启动推理蒸馏系数**，由学生对教师 think 的
  NLL 差距驱动：**差距大 → 多学，随掌握退火**（现行 disc_acc 驱动在跨家族下方向是反的：
  disc 一饱和 μ 即落 valley，把"教师和我很不一样"解读成"少模仿"）。think 段的 φ 加权
  关闭或温度化，否则 p≈0 的推理 token 永远进不了可学区间、蒸馏无法启动。μ_act 继续
  disc/NLL 驱动。BC 按段归一化，消除"教师 think 越长 μ 有效强度越稀"的隐式耦合。
- **R4**：think/action 段 mask 一等公民化 + 教师轨迹 K-snapshot 回放（exact-snapshot 下
  每轨迹只出一个决策样本，教师 BC 信号太稀，K=2-4 零成本加密）。

这套修正同时缓解故障 1 的双杀：双杀的前提是学生分布永不向教师靠近；think-BC 开启后
学生持续向教师移动，disc_acc 不会钉死在 1，整套自适应机制复活。

统一后教师 token 的梯度权重可以写成一行，所有机制一目了然：

> g_t = 1[action] · ŵ_act · Â^β · ∂f(π_t)  +  μ_seg · φ(p_t)

（细节论证见 `docs/research/ICLR2027_reasoning_offpolicy_design.md`。）

# 第四部分：什么样的叙事和算法设计能在 ICLR 拿高分

## 4.1 先看清 ICLR 2027 的竞争环境

Agentic RL for LLM 在 2027 年是最拥挤的赛道之一。审稿人见过无数"我们在 ALFWorld/WebShop
上比 GRPO 高 X 点"的论文，这类增量在他们眼里默认是 5-6 分。能到 8 分的论文通常具备：

1. 一个**别人一读就承认存在、但没人系统处理过的问题**（问题新颖性 > 方法新颖性）；
2. 机制**可证明地必要**（拿掉就崩的消融，而不是拿掉降两个点）；
3. 至少一个**反直觉的干净发现**（审稿人愿意转述给别人听的那种）；
4. 无懈可击的严谨性（multi-seed 分布、预注册、可复算）。

## 4.2 三种叙事选项

**选项 A：「bias-corrected experience replay」**（NeurIPS 版的修正版）
把两个 bias 的诊断-修正做扎实，SC 如实降为启发式。
→ 安全、诚实、但问题不新（LUFFY/CHORD 已把赛道踩热），上限 6 分。

**选项 B：「推理时代的教师利用」（推荐作为主叙事）**
> *你只有一个 API 推理教师的文本轨迹——85% 是另一个家族风格的思维链，没有 log-prob，
> 没有内部权重。如何把它安全地用进 on-policy RL？*

这个问题是**新的**：跨家族推理教师 → 小推理学生的 agentic RL，此前没有系统处理。
它天然包含三个别人没有的东西：

- **G1/G2 分解**：风格 off-policyness 和能力 off-policyness 是两回事，必须分开处理
  ——这是一个概念贡献，一句话就能讲清，且一读就觉得对。
- **判别器作为测量仪器**：disc_acc/ŵ 轨迹是师生分布距离的显式读数。同一方法在
  同家族（122B）和跨家族（DeepSeek）教师下的轨迹对比图，是任何 baseline 给不出的
  机制证据。
- **段分治（DUET-R）**：think 退出 PG、action 段估密度比、μ 分段——每一条都从
  G1/G2 分解自然推出，不是堆 trick。

**选项 C：「上下文管理/exact-snapshot」为主**
条件分布一致性是真问题，但作为主叙事会把论文变成系统论文，和 replay 主线抢地盘。
→ 作为协议贡献放一节 + 附录，不做主叙事。

**推荐结构：B 为叙事骨架，A 为技术脊柱，C 为严谨性证明。**
一句话贡献（草稿）：

> 我们研究只有文本轨迹的（跨家族、推理型）教师如何用于 agent RL；指出教师混合的偏差
> 由可分离的"能力错配"与"风格错配"构成，给出对前者的可证修正与对后者的段级退出机制，
> 并用一个判别器同时实现修正、调度与测量。

## 4.3 高分的五个组成要素（按对分数的边际贡献排序）

**① 自适应性的决定性证据（对 BC-only parity 的正面回答）——这是 6 分和 8 分的分界线。**
预注册机制预测：恒定 μ 的模仿应在"教师信号变有害"处受伤——长预算（BC-only 在 AF 上
48→31 的峰值后崩 vs DUET 42.5→47.5 持续上升，1.5B 已有雏形）、强学生（7B 上 LUFFY
有害而 DUET 中性）、弱教师。把 **second-half dynamics（后半程斜率）**做成主表旁的
核心图：动力学形状比终点数字抗 seed 噪声，且直接可视化"自适应退出"这个卖点。
如果多 seed 下这个形状在 4B/2B 复现，adaptivity 的价值无可辩驳；如果不复现,
诚实降级为"同性能 + 自动调度 + 强学生端可证安全"（5-6 分安全区，不要硬撑）。

**② 两三个可证明的小命题，兑现"principled"。**
- 命题 1：混入比例 m、师生成功率差 δ 下，pooled baseline 的 advantage 偏移闭式表达
  （Bias 1 的精确刻画）；BS 消除之。配 −BS→0.0% 的实验。
- 命题 2：Bayes 最优判别器下 ŵ_α 等于真实相对密度比，有界 1/(1−α)；教师项梯度是
  单次 ŵ 加权（Eq.9 之争的终局形式）。
- 引理：判别器误差 ε 下 ŵ 的偏差界（现在没有，成本低，值钱——它让 DR3 从启发式
  升格为有误差保证的估计器，正面回应 bDeY 型审稿人）。
"principled" 只落在这三条上，SC 明写 heuristic——NeurIPS 已经为宣称过宽付过一次学费。

**③ 家族轴 + 判别器读数（选项 B 的独有资产）。**
同一套 DUET，教师从 122B 换成 DeepSeek，报告 disc_acc/ŵ/μ 轨迹如何变化、各通道贡献
如何重新分配。预注册预测：**家族 gap 越大，SC（状态通道）份额越大**——因为环境观测
是家族不变的，而动作通道受风格错配伤害。这个"SC 是家族不变通道"的反转，把 NeurIPS
版最弱的组件变成新设定下的亮点。

**④ 反直觉小发现（论文的"华彩段"，从现有分析里挑最硬的 1-2 个）。**
候选：(a) 跨家族教师 85% 的 token 冷启动时不可学（φ≈0），BC 的 φ 加权自动形成
从"近支撑 token"开始的自步课程；(b) 判别器的"失效"其实是如实报告 think 段密度比
为零——修正机制没坏，是测量对象错了；(c) 长度捷径不存在（AUC 0.558）而 NLL 捷径
必然存在的对比。

**⑤ 严谨性作为可见的卖点，不只是底线。**
主表每格标 n(seeds)、分布优先、task×seed bootstrap；预注册全部 regime 并报告 null；
Reproducibility Statement 写明"所有数字可由 validation_log 一键复算"。NeurIPS 的教训
反过来用：我们是被复现问题咬过的人，把复现体系本身做成论文的可见特征。

## 4.4 反面清单（会直接丢分的东西，全部有前科）

1. 两环境跑两种算法（C8）——R2 统一后此雷拆除，**这是所有算法改动里优先级最高的**；
2. 单 seed 亮点数字、无法复算的 cell（C0/WS 36.0 的教训）；
3. "principled/only-X-differs" 式的过度宣称（C7 教训；且 OpenReview 旧帖可查，
   审稿人可能是原班人马，任何与公开记录矛盾的表述都是实锤）；
4. 机制证据和 headline 用两套模型（y9x6 会一枪打穿；legacy 结果全部进附录并标注）；
5. 事后挑 regime 讲故事（HARKing）——预注册是唯一防御。

## 4.5 现实预期

- 诚实执行现有计划（换模型 + 三环境 + 分布式证据 + 诚信手术）＝ 稳 6（poster）。
- 冲 8 的路径 ＝ ①自适应动力学证据成立 + ③家族轴故事干净。两者都依赖 DUET-R 的
  R1/R2 先落地（否则跨家族教师下机制直接空转，什么故事都讲不了）。
- 最大科学风险仍是 BC-only parity 在新栈复现；最大工程风险是判别器饱和未在开跑前
  排雷。两者的先手棋都已列在设计文档 §4：判别器离线 AUC 预测试（半天）和 φ(p)
  分段画像（2 小时），本周就能做，不占训练卡。
