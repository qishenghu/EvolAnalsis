# CATALYST v2 设计:entry-k 状态课程主力化(2026-08-13)

**决策背景**:v1 失败归因(见 `CATALYST_失败归因_2026-08-13.md`)裁定转写重放通道
(剥提示 token 克隆)注入上下文级 off-policyness;导师裁决:**成功 hint 轨迹不入重放池**,
其余修复方向(治理上电、预算中性、协议)采纳。v2 以试点 P-B 已验证的 entry-k
状态接管(真角点 S(75%)=38.0% ≥ 判据 30%)替代转写作为教师经验的主转移通道。

## 0. 不变式(比 v1 更强)

教师信息只允许通过两条通道影响学生,且都不进损失:

1. **条件通道**(hint 臂):教师思路作为 prompt 参考,学生自写全部 token;
2. **初始状态通道**(entry 臂):教师前 k 个 action 重放推进环境,学生从中局接管。
   教师前缀 seed 进 CMT 作 prompt(StructuredContextPolicy 剥 history think 为
   action-only;**教师 think 永不出现**);可训练 token 仅来自本 episode 的
   decision snapshot(结构保证:seed 消息不产生 snapshot → loss mask 恒 0)。

损失恒为纯 GRPO PG。无 BC 项、无重放池、无 token 克隆。治理把两条通道都退火
(hint 退休 / entry rung→毕业),终点逐字还原 GRPO —— 天花板论证干净。

## 1. 槽位分配(plan_arms v2,每任务 n=8)

按裸成功率 EMA(离线自举 + 在线更新)三段:

| 段 | 条件 | 分配 | 依据 |
|---|---|---|---|
| 毕业 | bare_ema ≥ s_hi(0.8) | 8 裸 | 已会,不打扰 |
| 角点 | bare_ema < s_lo(0.125)且入册 | **4 entry + 4 裸** | 裸 rollout 在全败组里梯度为零 → 挪 4 槽给 entry 的机会成本≈0(v2 预算中性的关键论证) |
| 中带 | 其余,且 U 门开 | 2 hint + 6 裸(v1 的 rho 0.5 降为 0.25) | hint 对中带有效(v1 实测 SR_hint 85% vs bare 65%),税率减半 |

**零机会成本论证**:GRPO 全败组 advantage 恒 0,角点任务的裸 rollout 不产生任何
梯度。把它们换成 entry 臂是把"死槽位"变成"活奖励",这不是税,是复活。

## 2. entry 臂机制(复用 P-B 试点代码路径,divergence=0 已验)

- **EntryBook**(新,`catalyst_entry.py`):从 `alfworld_dsv4flash_success_dedup.jsonl`
  离线构建(`scripts/build_catalyst_entry_book.py`),每任务取**最短**成功教师轨迹,
  存 init_messages + 逐步 (action, observation);manifest + sha。覆盖 1437 任务
  (决策数 p50=13,98.9% ≥4)。
- **计划构建**:`build_entry_plan(task_id, frac)` 逐字对齐试点 `build_takeover_plan`
  (k = max(1, floor(frac·n)),k ≤ n−1 且 k < max_steps 防御)。计划在 trainer 的
  plan_arms 里构建,经 TrajExpConfig 传给 worker(worker 不碰 EntryBook)。
- **执行**(agent_flow.py,镜像试点 TakeoverAgentFlow 三步):
  ① 逐步 env.step 重放教师 action,观测与教师记录文本比对,divergence 只计数;
    重放中 env 终止 → RuntimeError(fail-fast,走 worker 重试);
  ② save_init_input 之后追加教师 k 对 (assistant author=llm, user author=env)
    进 full_context(与试点 _seeded_save_init 逐字同构);
  ③ 学生步数预算 = max_steps − k。
- **元数据**:catalyst_arm="entry"、entry_frac、entry_k_steps、replay_divergence。

## 3. rung 课程(walk-back)与治理

- 梯子 fracs = [0.75, 0.5, 0.25](rung 0..2,毕业=离册)。任务初始 rung=0(最易)。
- 每任务 entry 臂成功率 EMA(alpha 0.5,按批更新;一批 4 obs):
  * ≥ promote_hi(0.5)→ rung+1(更早接管,更难);走完梯子 → entry 毕业回中带策略;
  * 连续 retire_windows(3)窗 ≤ demote_lo(0.125)且已在 rung 0 → entry 退休
    (教师前缀无用,别再烧槽位)——对应 v1 的"去其糟粕"半环,这次真的会触发,
    因为角点任务每次被抽中就有 4 个 obs,不再是 v1 逐任务 EMA 的聋子。
- **时间尺度修复(v1 教训)**:
  * 离线自举:`scripts/build_catalyst_task_stats.py` 从 GRPO 100 步 + CATALYST 76 步
    的 rollout_log 重建每任务裸 SR(目标文本归因,GRPO 全裸臂 → 每任务 ~16 obs),
    开跑即有全池难度画像,消灭冷启动旁路(v1 的 54% 任务卡冷启动);
  * 在线更新照旧,但分段判定只用"自举 + 在线"合并后的 EMA。
- 遥测:entry_rollouts / entry_frac_hist / rung 分布 / entry_sr_by_rung /
  entry_promotions / entry_retired / replay_divergence_total(军规探针,预期≈0)。

## 4. 明确不做 / 延后

- **重放池与 replay BC 全关**(config `replay.enable=false`、`actor.catalyst.replay_bc.enable=false`;
  M1 代码保留供归档,v2 配置断言互斥)。
- **恒温器 v2.0 保持 off**:一次只动一个变量,先看 entry-k 的净效果;h_hat 遥测照记,
  熵若塌到 GRPO 水平(~0.07)再在 v2.1 开(h_ref=0.35,已有 v1 区间 0.33–0.57 佐证)。
- **WS 不开 entry**(P-B WS 判据未过:rollout 级 18.8% < 30%);WS 只保留 hint 臂。
- DeepSearch/SciWorld 不在 v2 范围。

## 5. 实验协议

- 配置:`alfworld_qwen35_4b_catalystv2_grid100.yaml`(save_freq 10、resume auto、
  绝对数据路径、lane 与 GRPO 逐项同参)。
- 对照:GRPO 需补跑 save_freq=10 版(v1 的 GRPO 只有 50/100 两个 checkpoint,
  峰值 60 无存档)。步数 100(2 epoch),**seed 优先于步数**:v2 冒烟 1 seed 30 步
  验遥测(rung 流转、divergence≈0、零 replay 键),然后 v2 与 GRPO 各 3 seed。
- 评测:训练器贪心 val 只作监控;裁决口径 = 扫评 sampled n=4 报 pass@1/pass@3
  (贪心已被证明放大跌幅一倍且系统性低估 5–10pp)。
