## 2. DUET v1：是什么、结果、病理（"过去"）

**机制**（correct-then-extract，教师轨迹混入 GRPO 批次后修偏）：
- **BS 基线分离**：教师/on-policy 分开算组均值方差（防教师成功污染基线）。
- **DR3 密度比**：判别器估 ŵ=D/(1−D)，α-relative 压扁上界 ~1.13、地板
  w_min=0.01；特征是学生 NLL 统计量（lp_mean/std/min/max、lp_low_ratio、
  resp_len、kl_ref_mean）——**估的从来不是真比率，是有界平滑 gate**。
- **BC 通道**：教师 token 上的加权 SFT，μ 由 disc_acc 自适应
  （μ=clamp(μ_max·(1−EMA(disc_acc))/(1−d_floor),...)）；φ(p)=p(1−p)
  token 加权默认开。
- **SC 状态通道**：教师观测哈希建进度图 Φ(s)，给 on-policy 样本加
  β·P(τ) + η·ΔΦ 整形（exclude_teacher=true）。

**结果与病理**（rebuttal 期实锤）：
- 1.5B 主表 AF 47.5 / WS 36.0，但 **WS 36.0 不可复现**（复现 12.3±5.2）。
- **BC-only 平价问题**：BC-only 48@50→31@100（先高后塌）vs DUET
  42.5→47.5——成为后来"先学后拆/熵透支"理论的实物证据。
- **判别器双杀**：disc_acc→1 同时导致 ŵ→w_min 和 μ→valley，教师影响
  被同一信号双通道掐死。
- **跨家族死刑**：教师轨迹 85.2% 是 think token，跨家族逐 token 差距累出
  序列比率 e^-800；ESS ≤ n·e^(−D₂) 信息论上限，不可救。
- **四层故障层级**（为什么持续教师压力反而输 GRPO）：①基线污染
  ②d_teacher≠d_π ③KL 投影 ≠ 学生能力类最优 ④熵挤压。
- **解构洞察**：教师项 ≡ ŵ·Â·∇logπ = 加权 BC——DUET 的教师通道本质是
  改装的模仿项。

**事后审判（与用户对齐的定论）**：DUET 的**初衷没错，槽位错了**——想做
"带修正的 path 干预改善动力学"，却从 loss 侧（唯一过敏的接口）注入，被迫
发明 BS/DR3/μ 三个补丁止血；SC 是唯一落在合法槽位（reward 接口）的组件，
恰好也是唯一零补丁的。三资源记账（§4）下：mixing 是唯一正项（bootstrap），
修正机制全是防御项（止损不造血），无人管熵、BC 还在烧熵。

## 4. 现行理论：TEMPO 三资源预算理论（`TEMPO_三资源预算理论与算法.md`）

**公理**：预算固定 B 步，最大化 J(θ_B)。渐近分析无区分力，一切在动力学。
一步增益 ΔJ ≈ α⟨∇J, E[g]⟩ 拆出三个可测资源：

**资源一 燃料（长得快）= 数量 × 质量**
- 引理 1（可证，证明在正式文档）：二值奖励、组大小 n、成功率 p：
  全同组梯度**精确为零**，死组概率 = pⁿ+(1−p)ⁿ；E[g]=(1−1/n)∇J；
  ‖∇J‖ ≤ √(p(1−p))·G；p∈{0,1} 时精确零（不是弱，是零）。
- 当步速度 = 批次活组占比。冷启动 = 燃料沙漠（梯度恒零，不是学得慢）。
- 质量因子 = 对齐度 ρ（与 ∇J(task, s₀) 的夹角）。三档信号：s₀ 进带组
  （ρ=1 满分）＞入场组（**干净但打折**：纯 on-policy 零污染，练的是
  相邻目标）＞教师 token 进 loss（**方向被污染的假营养**）。深入场在
  自举期是**脚手架**（期权价值：解锁整条燃料链残局→中盘→开局）。
- 定理 1（燃料分配律）：把组填进混合成功带 [0.2,0.8]；教师数据的最优
  用法被推导为**搬运起点**（打井）而非注入样本。DAPO 动态采样/VADE/
  Knapsack-RL 等 = 本定理限制在单轴的特例。

**资源二 方向（不长歪）= 约束不是商品**
- 定理 2 = CONDUCTOR 契约（C/S 条款）。入场版只用 S 条款：给定起点
  续写恒 on-policy，比率≡1；纪律 = 同 (task, 起点) 才能同组 + 终态退火
  回 s₀。MDP 最优策略逐状态定义 ⇒ 换起始分布根本不动最优策略。
- DUET v1 的基线污染病 = 混起跑线排名；按起跑线分组后病根不存在。

**资源三 熵（长得高）= 按计划花的资本**
- 协方差定律（Cui et al. 2505.22617）：ΔH ≈ −α·Cov(logπ, Â)。给自信
  动作发奖励熵跌，给冷门成功发奖励熵涨。
- 汇率论（用户修正后定稿）：教师 reasoning = 内在逻辑 + 外在风格；
  SFT 学到 ≈0.7外在+0.3内在——不是买不到，是**汇率被外在稀释且随
  师生差距变大**（token 似然是语法层目标，风格便宜逻辑贵，梯度先捡
  便宜的）；on-policy RL 汇率 100%（只强化自己验证过的计算）。
- 定理 3（熵步调，训练的欧拉方程）：凹收益 + 总预算 ⇒ KKT 等边际，
  **匀速花最优，前置梭哈（SFT→RL）必亏**；角点解：连 guidance 都造
  不出燃料时前置 SFT 反而最优——**R1 冷启动派与 CHORD/TRAPO 反对派
  = 同一条互补松弛条件的两支**，判据可测（guided 成功率>0 否）。
  Entropy Scheduling（OpenReview fhvjv6UDAj）实验摸出的"早稳后退火"
  正是本定理推导的形状（他们靠试，我们靠证）。
- 工具 = 一行优势平移：Â ← Â − λ(logπ − 组内均值)（冷门成功发补贴、
  热门成功打折）；λ 对偶闭环追踪滑翔道 H̄(t)（线性 H₀→H_min）：
  λ ← [λ+η(H̄(t)−Ĥ)]₊。经典熵 bonus = λ 冻结特例，Clip-Cov = 截断
  实现，ES = 开环版本。
- 附录级：SFT→GRPO 不动最优点却更差的四机制（熵塌缩断燃料/先学后拆/
  可达性指数慢 Mei'20 & Li-Wei-Chi'21/KL-ref 实际动了目标）——见
  CONDUCTOR §3.7。
- **H1/H2 是假设不是定理**（用户逼问后标定，见通俗版 §1.6）：H1 大模型
  花熵便宜（可证骨架：softmax(Wφ) 连带挪动 ∝ 特征重叠 + Welch 界
  N≫d 时平均重叠≥~1/d；桥是假设）；H2 小模型破产线高（骨架硬：
  H=决策熵+噪声熵，协方差定律 ⇒ RL 只花得动决策熵，scaling law ⇒
  噪声地板随规模降）。**TEMPO 零押注**：闭环 λ 不需要任何跨模型常数。
- Think 传授理论（用户"内在/外在"分解后想通）：入场前缀带教师 think
  = in-context 条件化。两个不对称：**看得懂 ≪ 写得出**（差距越大差价
  越大，恰在 SFT 汇率最差处此通道汇率最好）；**语义层通道自带内外
  分离**（学生用自己风格复述读到的逻辑，腔调留在 prompt 里梯度为零）。
  管线：教师 think →语义过滤→ 学生自己的 token →环境验证→ 100% 汇率
  入账。差分预言：SFT 学生风格向教师收敛，入场学生性能涨风格不动。

## 5. 现行算法：TEMPO v2 双恒温器（`TEMPO_v2_双恒温器定稿.md`）

> **2026-08-04 换版**：用户判定 v1 的调度机构（EMA 档位表/前沿指针/
> 换档对冲/毕业检测，七个手调件）"非常 heuristic/hacking"——判定成立，
> 机构全废（决策日志第 15 条）。理论层不动，算法层压缩为两个标量
> 负反馈回路，每个一行更新式：
>
> ```
> k ← clip(k + η_k(0.5 − p̂), 0, k_max)      燃料恒温器（入场深度）
> λ ← [λ + η_λ(H̄(t) − Ĥ)]₊                 熵恒温器（熵税率）
> ```
>
> 派生链：p\* = 0.5 由 Lemma 1 派生（活组概率在 p=0.5 最大且平顶不敏感）；
> p(k) 单调 ⇒ 选深度从 bandit 降为求根（Robbins-Monro，自带时间平均，
> 无需 EMA）；task-once 下逐任务自适应信息论上不可能 ⇒ 总体级标量是
> 可行控制器的完备类；k₀ = k_max（t=0 根最深）；η_k = 30·k_max/T
> （预算带宽派生）。唯一真旋钮 = H_min。毕业 = k 触 0（涌现事实，
> 非检测机构；p̂ 回落时教师支持自动复热）。
> **保留**：组内同深度（反 TRAPO Bias-1）、前缀零梯度 ratio≡1、think
> 前缀通道（初心）、重放确定性前提。完整定稿+旋钮审计+六消融臂见
> `TEMPO_v2_双恒温器定稿.md`。

**真实预算（用户确认）**：约 1600 任务，batch-8×200 步或 batch-16×100 步
= 每任务全程只见一次（task-once）。

**以下 v1 定稿内容仅作演化史存档（调度机构已废，勿按此实现）**：

**全部状态量（v1，已废）**：7 格深度档 EMA + 1 个前沿指针 + 1 个 λ + 教师档案。
**没有**逐任务状态、没有判别器、没有进度图、没有状态匹配、没有 BC 项、
没有 μ、没有 rehearsal、没有学生自切点（后三者均因用户质疑被删，§6）。

- **档位**：{0,15,30,45,60,75,90}% × k_max（k_max=该任务教师轨迹长度；
  百分比是任务长短的正确归一化）。"从 d% 入场"= 环境自动重放教师前
  round(d%×T) 个动作后学生接管（前缀在 context 里，可选渲染教师 think，
  梯度严格为零）。
- **测量 = 数数**：p̂(档) 就是该档各组的成功次数比例做 EMA。**绝无状态
  soft-match**（用户曾猜测类似 DUET state-channel——已澄清不需要：入场
  是正向重放，深度自己选精确已知，成败由环境终局判定）。
- **流程**：①开训指针=90%（最深保底燃料），第 1 步 8 任务撒 7 档摸底
  （深档必活立刻出梯度，摸底免费）；②稳态：**8 任务全部去前沿档**
  （无常设侦察岗）；按 (任务,档) 分组跑标准 GRPO + 一行熵定价；
  ③换档：p̂[前沿] EMA > 0.8（免费信号）→ 4/4 对冲过渡几步 → 新档
  ≥0.2 则指针左移，<0.2（断崖）则退回隔十几步再试；④毕业 = 最后一次
  换档（指针到 0%），此后 = 普通 GRPO + 熵定价。全程约 5~6 次换档。
- **两个独立闭环**：燃料闭环（数成败→比带→挪指针，慢）；熵闭环（读
  已有 logπ 平均→比参考线→微调 λ，快）。
- **残余低效（诚实记录）**：pooled 指针对个别过难/过易任务不合身；靠
  EMA 跨任务平均 + 宽带 + 4/4 对冲压小；可选升级 = 按任务类型裂成
  6 个指针（MVP 看数据再定）。
- **基建前提唯一一条**：重放确定性（同动作序列落同状态；验证清单里
  50 条轨迹 observation-hash 检查先行）。
- **v2 扩展（不动理论）**：hint/交接笔记臂（C 类程序，双 log-prob +
  context surgery）。v1 不做。
