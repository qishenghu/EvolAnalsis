# CATALYST v3 设计:分布课程 + 课程 critic + 自产状态(2026-08-15)

**决策背景**:v2 复盘(同日文档)裁定三条机制断层:①同起点×组基线→方差坍缩
(entry 组梯度活性 17.7%,低于裸对照 20.3%);②阶梯课程遍历需求(≥150 步)
与任务到访频率(1 次/50 步)算术冲突;③教师状态不在学生分布上,hint→bare
无转移桥。导师方向确认:机制级修复,目标 = 稳定超越 GRPO(pass@1 + pass@3)。

**战场判断(扫评中期数据)**:v2 贪心强但采样零增益(+1pp vs GRPO +17pp)
——GRPO 的 pass@3 红利来自"很多题会一点"的任务级随机性;v3 的赢法是
"更多题真的会":每攻克一道 val 角点 ≈ pass@3 +0.8pp。

## 0. 不变式(继承 v2 并升级)

损失恒为纯 PG(无 BC/无 token 克隆)。教师影响通道进一步收缩:
prompt 参考(hint)+ 初始状态选择,且状态源**学生自产优先、教师册仅兜底**。
课程收缩到 f→0 时逐字还原 GRPO。

## 1. 三个机制替换

### 1.1 分布课程(替换阶梯,修断层①②)

每任务维护 frac 区间 [f_lo, f_hi] ⊂ [0.05, 0.95],初始 [0.5, 0.9]。
任务被抽中时,4 个 entry 槽各自独立采样 frac(确定性 hash(task, step, slot)
→ 均匀分布,可复现)。区间端点按本次到访的槽级成败更新(δ=0.05):

- 全败 → 区间上移(更靠近终点,更易):f_lo,f_hi += δ(f_hi ≤ 0.95);
- 全成 → 区间下移(更早接管,更难):f_lo,f_hi −= δ(f_lo ≥ 0.05);
- 混合 → 不动(已在前沿带)。

毕业:f_hi ≤ 0.15 且本次有成 → entry 停用(接近全程能力,交还裸臂);
退休:f_lo ≥ 0.85 且连续 retire_windows 次全败 → 素材无用,停用。
无"逐级毕业"遍历需求:一次到访即覆盖难度带;promote_hi 悖论随阶梯一起消失。

### 1.2 课程 critic(替换 entry 组基线,修断层①的另一半)

entry 行优势不再用组均值:**A = r − V̂(task, frac 段)**,五段
([0,.2),[.2,.4),[.4,.6),[.6,.8),[.8,1])。V̂ = 逐任务分段 EMA(α=0.5),
观测 < 2 时退化到**全局分段 EMA**(每步 ~12 观测,数步收敛——critic 的
时间尺度靠全局段解决,同 v2 难度自举的思路)。性质:

- 全成组:A = 1−V̂ > 0,新攻克状态信号最强,V̂→1 自退火(防自我强化);
- 全败组:A = −V̂ ≤ 0,V̂≈0 时无信息归零;
- 混合组:同一公式(不再分支);uid 仍带 |e 后缀,仅为把 entry 行
  从裸组基线里隔离出去(保护裸组统计),不再参与组均值计算。

实现:_catalyst_post_advantage 里对 entry 行覆写优势(response mask 内广播
r−V̂);V̂ 在 plan 时随 payload 传入(metadata catalyst_entry_vhat),行成败
从 reward 取。与 skip_zero_advantage 兼容(A≠0 的行照常更新)。

### 1.3 自产状态课程(修断层③,转移闭环)

**状态池 CatalystStatePool**:任一**非 entry 臂**成功轨迹(裸/hint)的
action 序列 + 逐步观察入池(质量门:全部 decision 有合法 action、步数 ≤
max_steps、无长度截断;每任务上限 4 条 FIFO,随 checkpoint 持久化)。
entry 计划构建优先取池中最新学生路径,**教师册仅在池空时兜底**。

闭环因果链:hint 让学生成功 → 该轨迹(学生 action,无 hint、无教师 token)
的中途状态入池 → 学生从**自己走到过的状态**练裸续写(critic 记分)→
区间下移至 f→0 = 该任务裸掌握。转移不再依赖"祈祷权重泛化"。

配套:**角点任务混臂 2 hint + 4 entry + 2 裸**(v2 是 0 hint——角点无学生
成功轨迹可产的配置漏洞,v3 修复;hint 在角点同时承担"造燃料"职责)。
中带任务维持 2 hint + 6 裸不变。

## 2. 协议变更

- 漂移门 mean 0.02 → **0.025**(七次触发实测 0.0200–0.0206 为数值地板;
  p99/比率越界余量 43%/10 倍不动)。**GRPO 重跑同步放宽**,协议对齐,
  论文如实记录;
- save_freq 10、resume auto、评测 = 扫评 sampled n=4 报 pass@1/pass@3;
- 队列:v3_s0 → GRPO(新协议)_s0 → v3_s1 → GRPO_s1 → v3_s2 → GRPO_s2
  (seed 经 data.seed/task_seed 派生;单槽纪律)。

## 3. 继承不动

hint 注入/审计、零模仿结构、裸臂 EMA 与难度自举、divergence/降级军规探针、
entry 执行三步(重放→seed→预算收缩;计划 payload 契约不变,agent_flow 零改动)、
分臂 uid 机制、恒温器保持 OFF(变量隔离)。

## 5. 风险与观测点(冒烟裁决线)

- 全成正优势的自我强化风险:靠 (1−V̂) 自退火 + 观测 catalyst/entry_adv_mean
  (应随训练→0);若持续高位即课程停滞报警;
- 学生路径质量:入池率、池命中率(entry 计划取自学生池的比例,应爬向 1);
- 组活性:catalyst/entry_group_live_frac,目标 ≥40%(v2 是 17.7%);
- divergence 军规探针延用(学生路径重放同样应 ≈0——确定性环境)。
