## 第一部分：用大白话讲清楚 TEMPO

### 1.1 问题设定：一场预算固定的考试复习

你有 **B 步训练预算**（比如 200 步，每步一次梯度更新），到第 B 步交卷，
看最终成功率 J(θ_B)。教师数据是你手里的一本"学霸笔记"。问题：每一步的
训练批次怎么组装，才能让**交卷那一刻**的成绩最高？

传统理论关心的是"无限复习下去最终能到多少分"（渐近分析）——但在固定预算下
这个问题没有区分力：几乎所有方法无限跑都能到差不多的地方，差别全在**路上**。
所以真正的问题是三件事：**长得快**（每一步都别浪费）、**长得高**（别提前
平台期）、**保住熵**（别把后期的探索本钱提前烧光）。

TEMPO 的全部内容就是：把这三件事各自变成一个**可测量、可证明**的量，
然后推导出"每一步该怎么花预算"的分配规则。

> **命名速查（防混淆）**：本文里"燃料"专指**活组占比**（资源一，要最大化，
> 越多越好）；"熵"是**探索资本**（资源三，要按计划花，不是越多越好也不是
> 越省越好）。两者管理方式完全不同，别把熵叫燃料。

### 1.2 资源一：燃料——GRPO 的梯度是会"熄火"的

先看一个所有人都知道但很少有人当回事的事实。

GRPO 给一组（比如 8 条）同任务 rollout 打分，每条的优势 = 自己的分 − 组平均分。
现在想想两种极端：

- **8 条全部失败**：每条都是 0 分，组平均也是 0，优势 = 0−0 = 0，八条全零。
  这一组的梯度**精确等于零**——不是"信号弱"，是数学上严格的零。
- **8 条全部成功**：同理，全零。

也就是说：**只有"有对有错"的组才产生梯度**。全对或全错的组，GPU 照烧、
时间照花，对学习的贡献是零。我们管这种组叫**死组**，管"有对有错"叫**活组**。

死组的概率能精确算出来：任务成功率是 p 时，8 条全错的概率是 (1−p)^8，
全对是 p^8。感受一下数字：

| 成功率 p | 死组概率（n=8） |
|---|---|
| 0.5 | 约 0.8%（几乎必活） |
| 0.2 | 约 17% |
| 0.05 | 约 66% |
| 0.01 | 约 92% |
| 0 | **100%，永远死** |

这就是"燃料"的含义：**批次里活组的占比，决定当步的学习速度**。
"长得快"不是玄学，就是这一个数。

现在看冷启动：2B 学生刚上 ALFWorld，几乎所有任务成功率 ≈ 0，于是几乎所有组
都是死组——**纯 GRPO 的曲线前期平坦，不是学得慢，是梯度基本恒零**。
这片区域我们叫**燃料沙漠**。

教师数据能干什么？两种思路：

- **思路 A（DUET v1 / LUFFY）**：把教师的成功轨迹直接塞进组里当样本。
  组里确实"有对有错"了——但那条"对"的是别人的，由此带来基线污染、
  分布错配等一堆偏差，逼出 BS/DR3/自适应 μ 三个补丁（见 CONDUCTOR §3.8）。
- **思路 B（入场）**：环境按教师轨迹先走 k 步，然后**学生接管**。
  任务只剩后半段，难度骤降，学生自己的成功率从 0 变成比如 0.3——组活了，
  而且组里每一条都是**学生自己采的**，没有任何别人的样本。

一句话：**思路 A 是把鱼塞进你的渔获里，思路 B 是把你放到鱼多的地方钓**。
燃料理论说清楚了为什么 B 更好：你要的是活组，不是别人的成功样本。

### 1.3 资源二：方向——梯度不仅要有，还要指对

有梯度只是第一步，梯度还得指向"让**你**变强"的方向。

教师 token 进 loss（思路 A）的问题：loss 里混进了一股"变得更像教师"的力。
教师的姿势未必适合你的身体（跨家族时 think 风格差几百个 nat），这股力会把
你拉向一个"教师的影子"，而不是你自己能力类里的最优点。这就是为什么思路 A
需要一堆修正机制，而且修正只能止损不能除根。

入场法（思路 B）在方向上几乎是免费的干净：学生站在教师给的**位置**上，
但接下来每个 token 都是自己采样、按自己的分布记账——梯度是 100% 纯正的
on-policy 梯度，一分钱修正都不用。只需要遵守两条纪律：

1. **同一起跑线才能同组比**：从 80% 处入场的 rollout 和从头跑的 rollout
   不能放进同一组算平均——不同起跑线的赛跑成绩没有可比性。所以分组必须
   按 (任务, 入场点) 来。顺带说一句：DUET v1 的"基线污染"病，本质就是
   把不同起跑线的选手混在一组排名——当年用 BS 打补丁，现在按起跑线分组，
   病根直接不存在。
2. **最后要挪回起点**：一直从半路入场，学生会变成只会冲刺的"接力选手"。
   所以随着能力上涨，入场点要逐步退回 s₀（后面会看到这个退火是自动发生的，
   不用设计日程）。

理论上还有一个漂亮的保底：MDP 的最优策略是逐状态定义的，**换起始分布根本
不改变最优策略**——所以入场法连"最优点被挪走"的嫌疑都没有。

### 1.4 资源三：熵——探索资本要按计划花

熵 = 策略输出分布的"宽度"= 你还愿意尝试多少种不同做法 = **探索资本**。

有一条别人论文里已经推导并实测过的"物理定律"（The Entropy Mechanism,
2505.22617）：每次更新的熵变，约等于

> 熵变 ≈ −学习率 × Cov(该 token 的 logπ, 该 token 的优势)

人话版：**给高概率（你本来就爱做的）动作发正奖励，分布变得更尖，熵下降；
给低概率（冷门的）动作发正奖励，熵反而上升**。

由此得出三个大白话结论：

1. RL 训练必然花熵——把概率集中到成功做法上，本来就是"用熵买性能"，
   这是**良性支出**。
2. SFT 花熵买到的是一个**混合物**（用户 2026-08-03 修正，采纳）：教师
   reasoning = 内在（有用的逻辑）+ 外在（与学生不同的风格），SFT 学到的
   往往是"0.7×外在 + 0.3×内在"。它不是买不到性能——否则不会人人用 SFT——
   而是**汇率被外在稀释，且稀释度随师生差距变大**：token 级似然是语法层
   目标，按 token 付钱、分不清逻辑还是腔调，而风格 token 便宜好学、逻辑
   token 昂贵难学，梯度先捡便宜的。同家族小差距时学生已有支撑电路，内在
   占比高（SFT 平时好用的原因）；跨家族大差距时只剩背诵，外在占比逼近 1，
   "自信地错"还要退货。对比：on-policy RL 的汇率是 100%——只强化学生
   自己验证过的计算。
3. 熵像考前的精力总量：**匀速花完最优，第一天熬夜透支必亏**。
   SFT→GRPO 的"涨得快、停得早"，就是第一天透支的下场。

TEMPO 把这件事做成了一个自动控制器，实现只有一行：

> **优势修正：Â ← Â − λ × (这个 token 的 logπ − 组内平均 logπ)**

翻译：给冷门的成功**发补贴**，给热门的成功**打折**。λ 是税率，怎么定？
预设一条"熵应该缓慢下降"的参考线（滑翔道，比如从 H₀ 线性降到 H_min），
每步实测：熵掉得比参考线快 → 花超了 → λ 调高收紧；掉得慢 → λ 调低放松。
像央行盯着通胀调利率。没有任何手工日程。

（顺带：有一篇纯实验论文 Entropy Scheduling 摸出来"熵要早稳后退火"的日程
形状——那正是我们这套"匀速花钱"理论**推导**出来的形状。别人靠试，我们靠证。）

### 1.5 三定理，每条一句人话

| 定理 | 人话版 | 管什么 |
|---|---|---|
| 定理 1（燃料分配律） | 把组尽量填进"有对有错"的成功率带（约 0.2~0.8）里，学习最快；教师数据的正确用法是**搬运你的起点**让组活起来，而不是把教师样本塞进组里 | 长得快 |
| 定理 2（方向契约） | guidance 只要只改"你站在哪、你看到什么"，不碰 loss，梯度就永远纯净无偏；同起跑线才能同组比 | 不长歪 |
| 定理 3（熵步调） | 熵预算要匀速花（等边际原则），前置透支（SFT→RL）必亏；**唯一例外**：连 guidance 都救不活的死局（教师自己都做不出来），此时先 SFT 反而是最优解 | 长得高 |

定理 3 的例外条款值得单独品味：文献里"SFT→RL 更好"（R1 冷启动）和
"SFT→RL 更差"（CHORD/TRAPO）两派打架的实验，在这里被统一成**同一条数学
条件的两个分支**，判据可测：guided 成功率是否 > 0。这是整个理论最锋利的一刀。

### 1.6 FAQ：大模型和小模型的熵账本一样吗？（2026-08-03 与用户对齐）

问：72B 和 4B，每一步消耗的熵幅度会很不同吗？模型 capacity 不同，
熵这个资本是不是也不同？

**答第一半：单步 ΔH 的幅度确实会差很多，但决定它的不是参数量，而是
"任务相对这个模型有多难"。** 回看协方差定律（§1.4）：正奖励落在模型
**本来就自信**的动作上，熵烧得快；落在**冷门**动作上（爆冷的成功），熵
反而涨。所以同一个 72B，在它的舒适区任务上会快速烧熵（RL 不断"确认"它
已经会的东西），在远超能力的任务上反而可能前期熵上升。**ΔH 是
(模型, 任务) 这一对的性质，不是模型单独的性质。**

**答第二半：参数量真正改变的是账本的三个端点，这才是 capacity 差异的
落点。**

1. **资本的质量不同**。小模型的原始熵通常反而更高——但其中大半是
   **噪声熵**：撒在语法 token、格式 token 上的无用犹豫，花不出去、买不到
   任何东西，相当于**冻结资产**。大模型平均熵更低，但不确定性集中在
   **真正的决策岔路口**上（"高熵少数 token"现象：一条轨迹里 80% 的 token
   几乎确定，真正的分岔集中在少数 token）。拿原始熵总量比较两个模型的
   探索资本，就像拿现金总额比较两家公司而不看多少被冻结。
   **有效资本 = 决策点的熵，不是全 token 平均熵。**
2. **假设 H1——物价（汇率）不同：大模型花熵更便宜**。小模型参数少、
   电路共享严重，强化一个行为会**连带**挪动很多无关状态的分布——买一件
   商品，货架上别的商品也跟着被撞。大模型更新更"外科手术"。
   **证明状态（2026-08-03 用户追问后标定）**：非定理，定向假设。可证的
   骨架：取 π = softmax(W·φ(s))，未采样状态 s′ 的连带 logit 挪动 ∝ 特征
   重叠 ⟨φ(s), φ(s′)⟩（直接计算）；而 Welch 界证明 N ≫ d 个方向塞进
   d 维时平均重叠平方 ≥ ≈1/d——**小 d 的干涉是数学必然（d 张床睡 N 个
   人），大 d 下界趋零**。证不了的桥："干涉大 ⇒ 每单位性能熵成本高"
   需要"连带挪动是无目标随机游走、二阶有害且熵漂移不受控"这个假设
   （实证锚点：灾难性遗忘随规模下降，Ramasesh et al. ICLR'22）。
   单调定量版本是外推。可证伪预言：小模型"同涨幅烧更多熵"。
3. **假设 H2——破产线不同**。**证明状态**：三步骨架，前两步硬。
   ①分解 H = 决策熵（Cov(logπ,Â)≠0 处）+ 噪声熵（Cov≈0 处）；
   ②协方差定律直接推论（严格的一阶结论）：**RL 只在协方差非零处花熵**
   ——梯度压力够不到噪声熵，观测的熵下降 ≈ 全部出自决策资本，噪声熵
   是想花也花不掉的冻结资产；③噪声地板随规模下降 = scaling law
   L(N)=L∞+(N₀/N)^α 的直接内容（全领域最硬的实证规律）。合并：表观
   破产线 = 噪声地板 + 最低决策熵，小模型更高；可花占比小 ⇒ 同样的
   平均熵滑翔 = 决策资本更快的比例损耗 ⇒ 塌方更陡。证不了的部分：
   "塌得惨"的具体退化动力学（重复循环等）仍是经验观察。
   可证伪预言：小模型熵曲线在更高位置出现性能拐点。

**兜底声明**：TEMPO 没有押注 H1/H2——闭环 λ 只看"实测熵 − 参考线"，
从不需要任何跨模型常数，两条假设全错算法一字不改。它们只影响多模型实验
的**解读**，MVP 双档熵轨迹（§2.5 第 5 项）就是它们的证伪实验。

**设计后果：这正是滑翔道必须"相对化"、控制器必须"闭环"的原因。**
如果滑翔道是绝对数值日程（"第 100 步熵应该是 0.8"），换个模型就作废。
TEMPO 免疫这个问题：滑翔道两端锚定在**模型自己**的 H₀（开训第一批
rollout 实测，白拿）和 H_min（短探针标定）上；λ 的对偶更新只看
"实测熵 − 参考线"的偏差，从不需要知道任何模型的交换律系数——4B 熵掉得快
λ 自动收紧，72B 掉得慢 λ 自动放松。**模型间 ΔH 幅度的全部差异都被闭环
吸收**。这是闭环设计对 ES 式开环预设日程的又一个实质优势，可写进论文。

测量军规：多模型实验必须同时记两条熵曲线——全 token 平均熵（粗账）和
决策点熵（真资本；agentic 里可取每个 action turn 的首 token 或 action 段）。
只看粗账会把小模型的噪声熵误读成探索资本。

免费实验：MVP 本来就要跑 2B/4B 双档学生，把两条熵轨迹对着性能画，就能
直接检验"小模型汇率更差"（同样涨幅烧更多熵）——熵账本这一章的一手素材。

### 1.7 FAQ：燃料的质量——自主 rollout 是不是最优质的信号？（2026-08-03 与用户对齐）

问：学习信号除了活组占比（数量），是否还分质量？s₀ 完全自主的 rollout
是不是最优质的？teacher entry 是不是次优但可作营养补充？

答：完整的燃料账是**数量 × 质量**。数量 = 活性 √(p(1−p))；质量 = 对齐系数
ρ——该组梯度 ∇J(任务, 入场点) 与目标梯度 ∇J(任务, s₀) 的夹角（定理 1 里
的正迁移假设，此处显形）。

- **s₀ 自主组**：ρ = 1，定义上就是目标本身，最优质无折扣——但沙漠里
  数量因子为零：油品最好，油泵是干的；
- **浅入场**：ρ 接近 1、p 低；**深入场**：p 高、只练残局，ρ 打折。
  **深度轴 = 一条数量-质量互换前沿**。"带内最浅优先"规则的真实身份：
  在保证有燃料（进带）的约束下最大化信号质量——带子规则同时管两个因子。

两处修正用户的直觉：

1. **入场信号是"打折的"，不是"劣质的"**。层级三档：s₀ 进带组（满分）；
   入场组（**干净但打折**——纯 on-policy、方向零污染，只是练的是相邻目标，
   价值 = 目标重叠度）；教师 token 进 loss（**垃圾食品**——不是打折，是
   方向被污染）。"营养补充剂"指第 2 档成立，切勿与第 3 档混同：
   一个是低浓度真营养，一个是含添加剂的假营养。
2. **自举期的深入场不是补充剂，是脚手架**。其价值 = 直接对齐 + **期权
   价值**：练会残局 → 中盘 p 被抬进带 → 中盘燃料解锁 → 倒推回 s₀。
   它在冷启动期是承重的，解锁整条燃料链；设计好将来拆（退火毕业），
   但当下少了会塌。

由此推出的设计细则（已并入 §2.2）：**同深度入场点，学生自己成功轨迹的
切点 > 教师轨迹的切点**（自己的状态在自己的自然路径上，ρ 更高）。教师
入场点负责开荒（尚无自身成功轨迹的任务），学生成功轨迹入档后同深度优先
换用自己的——顺带天然消解教师状态偏离学生流形的分布错配。

**澄清"会了还要自己的切点吗"（2026-08-03 用户追问）**：不要——且带子
规则自动不要（p̂(task,0) 进带 → 选 k=0 → 毕业断供）。
（**后记**：真实预算为每任务只见一次后，自切点整体删除——任务不回头，
切了也无处用，见 §2.2.5。以下两个中间地带仅适用于任务重访的预算。）
自己的切点值钱的是两个中间地带：

1. **侥幸成功区**（0 < p(s₀) ≪ 带下沿）：蒙对过一两次但复现不了，s₀ 组
   仍大概率死。侥幸轨迹是**种子不是能力**——从其中间状态入场反复夯实
   自己那条路，把"蒙对过"变"稳定会"（Go-Explore"先回到有希望的状态再
   探索"、CRPS 自生成重启同理）。只用教师切点会白扔学生自己发现的路。
2. **退火下坡途中的换血**：已打下来的深度上，学生从教师入场出发的成功
   后缀就是自己走过的状态，用它替换同深度教师切点（ρ 更高）；教师切点
   继续在更浅的未攻克深度当先锋。**教师开荒，学生在收复的地里补种自己
   的秧苗**——不是给会了的任务发拐杖。

## 第二部分：入场版 v1——只用 teacher entry（用户 2026-08-03 提议，采纳）

### 2.1 为什么"只用入场"不是妥协，而是正确的 v1

用户问：这一版能不能先只考虑 teacher 入场（entry-replay），不做 hint？
答：**能，而且应该**。理由：

1. **工程量断崖式下降**。hint 类程序（C 类）需要双 log-prob 记账 + context
   surgery + 逐决策快照，是整套方案里最重的新基建。入场类程序（S 类）
   **不需要任何这些**：比率恒等于 1，无双账、无手术、无第二次 forward。
   要做的只是"环境重放教师前 k 步 + 按 (任务, k) 分组"——重放基建我们有
   （exact-snapshot 上下文系统），分组是改一个 group key。
2. **理论一点不缩水**。三条定理在入场版里全部保留：定理 1 的新轴心本来就是
   入场轴（这是 agentic 独有、prompt 课程论文碰不到的自由度）；定理 2 的
   S 条款是三条款里最干净的；定理 3 的熵定价与程序无关，照用。
3. **冷启动天然覆盖**。入场深度 k 拉满（教师轨迹只剩最后一两步）时，
   任务几乎必成——**最深入场几乎保证有燃料**，所以入场版不需要 SFT 冷启动
   阶段就能自举。
4. **消融矩阵可控**。v1 就是三个开关：入场分配（定理1）× 分组纪律（定理2）
   × 熵定价（定理3），2³ 的消融干净漂亮，每个开关对应一个资源、一条曲线预言。

### 2.2 入场版算法（2026-08-03 应用户要求重写为带具体数字的版本）

#### 2.2.1 永久状态：四样"游戏存档"

1. **档案 A**。教师做"把苹果放进微波炉"花了 10 步。把轨迹切开得 10 个
   **存档点**：s₃ = 走完前 3 步后的局面，s₅ = 已拿到苹果站在微波炉前，
   s₉ = 只差最后一步。"入场" = **读档**：环境重放教师前 k 步，学生从
   存档点接手玩剩下的。（学生自己的成功轨迹也切进来；同深度优先用
   学生自己的切点，教师切点负责开荒——§1.7。）
2. **成功率表 p̂**：一张 Excel 表，格子 = 学生从这里接手的近期成功率
   （滑动平均，每跑完一组就记）。下文演示用"行 = 任务"的直观版：

   | 任务 | k=0 从头 | k=3 | k=5 | k=9 只差一步 |
   |---|---|---|---|---|
   | 苹果→微波炉 | 0.00 | 0.05 | 0.35 | 0.95 |

   它就是**燃料地图**：一眼看出哪个格子落在活组带（0.2~0.8）。
   **实现上表必须是合并版**（行 = 任务类型 × 列 = 相对深度档，
   共约 30 格——为什么逐任务的表测不出来、合并版为什么够用，
   见 §2.2.4，2026-08-03 用户质疑后修正）。
3. **熵滑翔道 H̄(t)**：一条**事先画好的参考线**，不控制任何东西，纯粹是
   计划表。开训实测 H₀（如 1.2），探针标定 H_min（如 0.4），200 步训练
   ⇒ 参考线从 (0, 1.2) 直线滑到 (200, 0.4)。
4. **对偶价格 λ**：**一个数字**，初始 0，是熵税率，唯一用途在第 4 步
   那行公式。每步自调：实际熵掉得比参考线快 → 调大；慢 → 调小。

#### 2.2.2 一个训练步，具体数字走一遍

设定：第 50 步，任务"苹果→微波炉"，每任务 8 条 rollout，带 [0.2, 0.8]，
当前 λ = 0.10。

1. **查表选起跑线**：k=0 是 0.00（死区）、k=3 是 0.05（大概率死组）、
   k=5 是 0.35（**在带内**）、k=9 是 0.95（太简单，也快死）。规则
   "带内最浅" → 选 **k=5**。分配：6 条从 k=5 读档，2 条照旧从头跑
   （rehearsal，两个作用：防学生练成只会打后半场的接力选手；持续给
   k=0 格刷新数据，不然永远不知道学生啥时候能从头打赢）。
2. **生成**：6 条：环境重置 → 自动重放教师前 5 步 → 学生从第 6 步起
   自己决策到终局（上下文 = 前 5 步历史 + 当前观察，可选带教师 think）。
   另 2 条正常从头跑。
3. **分组算优势**：6 条 k=5 自成一组（如 2 成 4 败：成的优势正、败的负，
   标准 GRPO）；2 条 k=0 另成一组（全败 → 优势全零，无所谓，它们是
   侦察兵）。**唯一纪律：不同 k 永不混组**——起跑线不同，成绩没有
   可比性。
4. **算 loss**：标准 GRPO loss，只多一行熵定价：
   Â ← Â − λ·(该 token 的 logπ − 平均)。
   感受：λ=0.1 时，成功轨迹里模型很自信的常见 token 奖励打小折，
   不自信却蒙对的冷门 token 奖励加小奖金。**λ=0 时整个算法退化为
   普通 GRPO**（加分组和读档），所以这行零风险，纯旋钮。
5. **记三笔账**：
   - 燃料账：k=5 本次 2/6≈0.33 滑动平均入表，k=0 的 0/2 也入表；
   - 熵账：实测熵 0.95，参考线在 1.0 → 烧快了 → λ: 0.10 → 0.12；
   - 档案账：新成功轨迹切片入档。

#### 2.2.3 全程三幕：为什么说课程是"自动涌现"的

- **开局（0~30 步）**：表上几乎全零，只有很深的 k 在带内 → 全员深入场
  练残局。
- **中期（50~150 步）**：残局练熟，k=5、k=3 的格子被学生自己的进步
  **顶**进带里 → 查表结果自动变浅。反向课程（深→浅）没有课程表，
  纯粹是每步查表的副产品。
- **毕业（150 步后）**：某任务 k=0 格爬到 0.3 进带 → 该任务从此全部
  从头跑，与普通 GRPO 完全相同。

一句话总结：**每步三件事——查燃料表选起跑线、按起跑线分组跑标准 GRPO、
记三笔账（成功率 / 熵税 / 档案）。** 没有 BC loss、没有判别器、没有 μ、
没有教师样本进 batch。旧世界要手调的课程表、μ 日程、熵系数，全是测量的
副产品（CONDUCTOR"去调度化"主题的延续）。

超参真的只剩：带边界 [0.2, 0.8]、rehearsal 比例（如 1/4）、H_min。

#### 2.2.4 FAQ：成功率表怎么可能测得出来？（2026-08-03 用户质疑，修正实现）

**用户的怀疑成立**：ALFWorld 训练池约 3.5K 任务，batch 32 任务 × 200 步
≈ 6400 任务位——每个任务全程只被访问 1~2 次，逐任务逐深度的密集表格
没有数据来源。修正靠三个机制：

1. **测量免费，问题只在覆盖**。每个训练组本身就是一次 n=8 的成功率抽样
   ——p̂ 是训练的副产品，不需要任何额外评测 rollout。n=8 噪声不小
   （p=0.3 时 ±0.16），但足够回答唯一的粗问题：这格在带内/死区/太简单。
2. **合并（pooling）**。成功率主要取决于"剩多少活、什么类型的活"，
   不取决于任务具体身份。表按 (任务类型 × 相对深度档) 存：ALFWorld
   6 类任务 × 深度按教师轨迹长度百分比分 5 档 = **30 格**，batch 每步
   几十个组落进这 30 格，格格常新。新任务直接继承同类型格子值；
   个别数据攒够的任务可叠逐任务修正（分层估计：有细账用细账，
   没细账用类型均值）。
3. **单调性省表**。成功率对 k 单调（越深越易），只需**追踪前沿**
   （当前在带内的那 1~2 档）：k=5 在带就不用测 k=9，k=3 死就不用测
   k=1；前沿只会单向变浅。每类型实际活跃格子只有一两个。

额外 rollout 成本清点：入场组零额外成本（就是训练数据）；唯一可能白跑
的是 rehearsal（早期 p(s₀)=0 时纯测量），减负：降到 1/8 或轮询触发
（每 3 次访问探一次 s₀，或等浅档抬头再探——单调性保证浅档没起来
s₀ 必然还是 0）。参照系：R3 零测量但日程瞎开；旧 DUET 花 1/8 batch
买教师样本还要搭修正机制；我们花 ~1/8 买无偏课程控制 + 自动毕业检测，
且侦察兵一旦活了就转正为训练数据。

#### 2.2.6 极限预算版完整流程（2026-08-03 应用户要求逐步展开）

**先纠正一个误解**：前沿指针的测量**不是**状态匹配。DUET state-channel
做状态 soft-match 是因为要给 on-policy 轨迹估"你走到哪了"；TEMPO 的入场
是**正向重放**——深度是自己选的（重放前 6 步深度就是精确的 6），成败由
环境终局奖励直接判定，**没有任何需要估计的状态量**。全算法的"测量"只有
三种：数成功次数（环境给）、读平均 logπ（训练器本来就算）、做减法比较。
没有 Φ(s)、没有判别器、没有 embedding 相似度、没有额外 forward。

**准备（开训前一次性）**：①1600 任务各配一条教师动作序列；②随机排成
访问序列（每步 8 个，200 步用完）；③定义 7 档 {0,15,30,45,60,75,90}%，
"从 d% 入场"= 环境自动执行教师前 round(d%×T) 个动作后学生接管；
④指针 := 90%（最深保底燃料），λ := 0，7 格全空；⑤H₀ = 第一步生成的
实测平均熵（白拿），H_min 先拍 0.3·H₀ 或短探针，参考线 = 两点连直线。

**摸底（第 1 步，也是正常训练步）**：8 任务撒 7 档。假设结果
90%:7/8、75%:3/8、60%:4/8、更浅全 0/8 → 填表。8 个组照常 GRPO
（深档活组立刻出梯度，浅档死组零梯度无害）——摸底零额外成本。
判定：带内最浅 = 60% → 指针 := 60%。

**稳态步（绝大多数步，如第 10 步；2026-08-03 修订：撤销常设侦察岗）**：
- 分配：**8 个任务全部去前沿档 60%**。没有侦察兵、没有 0% 岗——单调性
  保证前沿没打熟前更浅的档必然≈0，测了白测还烧任务。
- 生成：重放前缀、接管、跑到终局。
- 训练：按 (任务, 档) 分组——每任务只有一个档，8 条天然一组，想混都
  混不了；GRPO 优势 + 一行熵定价 Â ← Â − λ(logπ − 平均)。
- 记账：p̂[60%] 用全部 8 组 EMA 更新（数据厚）；熵账：实测 1.05 vs
  参考线 1.15 → 烧快了 → λ: 0 → 0.02。

**换档（如第 78 步触发）**：p̂[60%] 的 EMA 涨过带上沿 0.8——此信号
**免费**（就是前沿格自己的读数）。进入**对冲过渡**：其后几步 4 任务留
60%（p̂≈0.85 仍有燃料、训练稳定）、4 任务试 45%（每步 32 条，两三步出
可靠读数）。判定：p̂[45%] ≥ 0.2 → 指针左移，恢复全员前沿；< 0.2
（难度断崖）→ 全员退回 60%，隔十几步再试。**过渡期探测组活了就是
正常训练数据**，非开销。全程约 5~6 次换档。

**毕业（如第 160 步）**：指针沿 90→60→45→30→15→0 一路换档——
**毕业检测就是最后一次换档**，无需专门机制。此后 TEMPO 退化为
"普通 GRPO + 熵定价"直到训完。

**残余诚实问题（合并估计的固有低效）**：pooled 指针给所有任务同一相对
深度，个别过难任务在前沿档照样全灭、过易的照样全对。压小手段：EMA 跨
任务平均、带宽容忍 ±0.15 波动、对冲用 4 组非 1 组。可选升级：日志显示
类型间方差大时，全局指针裂成按任务类型的 6 个指针（回到 type×depth
表）——MVP 跑完看数据再定。

**两个独立闭环，都是"测量→比较→微调"**：

| 闭环 | 测什么（来源） | 和什么比 | 调什么 | 节奏 |
|---|---|---|---|---|
| 燃料闭环 | 各档成功率（数成败） | 带 [0.2, 0.8] | 前沿指针 | 慢，几十步一动 |
| 熵闭环 | 本步平均熵（已有 logπ） | 滑翔道参考线 | λ | 快，每步微调 |

唯一基建前提：**重放确定性**（同一动作序列落到同一状态；ALFWorld 为
确定性引擎，但须先过验证清单第 2 项的 observation-hash 检查）。

### 2.3 初心怎么办：teacher 的 think 还学不学？

用户的初心：不仅学教师做什么，也学教师**怎么想**。入场版看似砍掉了 hint
（think 的显式通道），但其实有个此前没点破的细节：

**入场重放的前缀就在学生的 context 里。** 学生从第 k+1 步接管时，它的上下文
包含教师前 k 步的完整轨迹——如果渲染时保留教师的 think 文本，学生就是
**一边读着教师的思考一边接管**。这是 in-context 的 think 传授：不进 loss
（前缀是 prompt 不是 response，梯度为零，方向契约完好无损），但实实在在
影响学生接管后的行为；等入场退火回 s₀，前缀消失，学生必须内化才能毕业。

为什么这个通道提取"内在"的效率比 SFT 高？两个不对称（2026-08-03 与用户
的内在/外在分解对齐后想通的）：

1. **看得懂 ≪ 写得出**。SFT 要求学生给教师 token 高似然，等价于要求
   "写得出"教师的推理；in-context 条件化只要求"看得懂"——2B 学生读懂
   122B 教师的推理步骤，远比把自己的生成分布贴上去容易。师生差距越大差价
   越大：**这个通道恰好在 SFT 汇率最差的地方汇率最好**。
2. **通道自带内外分离**。似然训练是语法层通道，风格和逻辑都长在 token 上，
   loss 没法只买逻辑不买腔调；条件化是语义层通道——学生续写时用**自己的
   风格重新表达读到的逻辑**（复述，不是抄写），教师的腔调留在 prompt 里
   （梯度为零），穿过注意力的是语义内容。

完整提取管线：教师 think →（语义过滤）in-context 条件化 →（风格母语化）
学生自己的 token →（正确性过滤）环境验证 → RL 只强化过筛后的部分，
按 100% 汇率入账。退火后内化下来的是学生自己的复述版本。

可测的差分预言（rollout 日志直接量）：SFT 学生的输出风格向教师收敛
（think 长度分布、n-gram 重叠趋近教师），入场学生应当**性能上涨、风格
不动**——"学到逻辑不学腔调"是一条画得出来的曲线。

这直接给出 v1 里**最便宜也最切初心的一个消融**：

> **入场前缀渲染 think vs 剥离 think**（其余全同）。
> 若带 think 的版本接管成功率更高、毕业更快 ⇒ "教师的思考值得学"拿到
> 直接的因果证据——初心从信念变成实验结论。

hint/交接笔记（C 类程序）不删除，降为 v2 扩展：v1 用入场把理论立住，
v2 加 hint 臂只是往程序库里多插一件乐器，理论无需改动。

### 2.4 诚实的代价：novelty 边际变薄了哪一块

只用入场，机制层的邻居会更近：R3（ICML'24，反向课程）、JSRL、CRPS
（后缀重启）、TRAPO（前缀）。**入场原子本身早就有主**，这点必须清醒。
v1 的差异化全部压在理论与系统层：

1. 他们的课程是**手工日程**（R3 按固定节奏后退），我们的深度由测得的
   p̂ 带子规则自动选——第一个把入场深度作为**测量驱动的分配问题**的；
2. 他们没有 (task, 入场) 分组纪律（组基线偏差问题在他们的设定里被绕过或
   忽略），我们把它作为定理 2 的推论钉死；
3. 他们没有熵账——没人在入场课程里同时闭环控熵（定理 3 全新加入）；
4. 环境级重放（真实 agentic env 状态，非文本前缀拼接）+ think 渲染消融
   是 agentic 独有的实验面；
5. 三资源理论把这一切装进一个"为什么"的框架——**论文的主张是理论，
   入场版只是理论的最小实例化**。这是和 R3 们的根本区别：他们提机制，
   我们提账本，机制是账本的一个分录。

风险对冲：如果 reviewer 仍然认为"就是个自动化 R3"，牙齿在预注册预测里
（P1 燃料-速度耦合可从旧日志零成本先验证；P2 熵消融；P5 入场轴 vs prompt
轴课程的正面对决）。理论要是真的，这些曲线会替它说话。

**与 TRAPO 混组式前缀的结构性分野（2026-08-03 用户辨析，公理层分歧）**：
TRAPO 是同一任务 8 条 rollout 混不同前缀比例（如 4×0% + 25/50/75/90% 各
1 条）同组算优势，且前缀 token 进 loss（TrSFT）；TEMPO 是组内同深度、
课程展开在时间轴（指针左移），前缀是 prompt、梯度为零。混合组的数学
后果：各臂成功率按构造异质 ⇒ 第 d 档期望优势 = p_d − p̄，**深臂恒正、
浅臂恒负，与策略好坏无关**——起点好被记成策略好，从头打的尝试（哪怕
打得不错）永远挨打，且每档 1 条使组内所有比较都是跨起跑线的不公平
比较。此结构与 DUET v1 教师混组的 Bias-1 数学同构（我们的实测疤痕：
去 BS 后 1.5B 塌 ~0%）。公平地说 TRAPO 的对价：零调度器零状态、每任务
自带全谱课程、深臂保活组——**两家买同一样东西（燃料），付的货币不同**：
TRAPO 付结构性记账偏差（每组都含、复利累积），TEMPO 付调度基建
（7 个数 + 1 指针，一次性白菜价）。差分判据见 §2.5 第 6 项。

### 2.5 v1 验证清单（对齐两周决断点）

1. **P1 回溯验证（今天可做，零 GPU）**：从现有 wandb 日志算历史运行的
   活组占比曲线，与 dJ/dt 求相关——定理 1 的免费体检；
2. **重放确定性检查**（已在验证周清单）：50 条教师轨迹逐步重放，
   observation hash 对比——入场版的基建前提；
3. **MVP 训练**：ALFWorld + Qwen3.5-2B 冷启动，四臂对比：
   纯 GRPO / 固定日程反向课程（R3 式）/ 入场版 TEMPO（无熵定价）/
   完整入场版 TEMPO——一次跑齐定理 1、3 的主证据；
4. **think 渲染消融**（2.3 节）：初心的因果检验，蹭 MVP 的设置加一臂；
5. **双档熵轨迹**（1.6 节）：2B/4B 学生各记"平均熵 + 决策点熵"两条曲线
   对性能画，检验"小模型汇率更差"——蹭 MVP，零额外训练成本；
6. **TRAPO 混组差分**（2.4 节）：同预算加一臂"组内混前缀比例"，三判据：
   ①组内深度-优势相关性（混组应显著正，TEMPO 恒零——偏差存在性的直接
   测量，日志即可算）；②0% 成功率增长速度（预言混组更慢：从头打的行为
   被结构性打压）；③毕业检测（指针给明确撤 guidance 信号，混组无等价物）。
