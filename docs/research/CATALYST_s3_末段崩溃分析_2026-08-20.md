# s3(v4 零自举规范版)末段崩溃分析

日期:2026-08-20 深夜。对象:p0_catalystv4_af_s3(seed 2025,零自举,step 100 完跑)。
状态:轨迹级定性已完成;"解码伪象 vs 真退化"终裁待 pass@k 扫评(job 50598,在跑)。

## 一、现象

greedy val(128 任务,step 10→100):
39.8 → 45.3 → 67.2 → 66.4 → **71.9** → 59.4 → 70.3 → 71.1 → 60.9 → **39.8**

巅峰 71.9@50 为同种子全场最高(s0 带画像同期 64.1;GRPO 三种子同期最高
70.3 且随即崩盘)。但 80→100 的 20 步里掉了 31.3 个点。

## 二、轨迹级定性(直接读 val 失败样本)

失败形态不是能力遗忘,而是**策略锐化进"重复动作死循环"**:

| 指标(失败样本内) | @80 | @90 | @100 |
|---|---|---|---|
| 失败数 /128 | 37 | 50 | 77 |
| Invalid action ≥3 次占比 | 16% | 48% | **59%** |
| 单一动作占比 >40% 的轨迹 | 24% | 48% | 57% |
| 最高频动作重复率(均值) | 0.34 | 0.43 | 0.50 |

典型 case:模型已在 diningtable 旁仍反复输出 `go to diningtable 1`,
环境回 "Invalid action" 后**原样重发**;think 内容退化为一句套话
("I have the pan. I need to prepare food.")。

配套机制曲线:熵 0.48@80 → 0.31@100(**收窄**,与 v5 的熵弥散 0.74
方向相反);KL 0.31→0.57 缓升无爆点;训练批内得分 44.9@85 → 36.1@100
(缓降,幅度远小于 val 崩幅)。

## 三、三点判断

1. **通病,非零自举独有**。GRPO s1 终点 43.8、s2 终点 35.9(70.3@50 后
   崩),同一形态;s0(带画像 v4)也在 80 跌过(62.5)但收回 75.0@100。
   一个 seed 的逃逸无法区分运气与机制。
2. **与 v5 死因同形不同源**。v5 是外部灌入徘徊素材(垃圾重放教坏策略);
   s3 无 rescue 通道,徘徊是 RL 后期自发的策略锐化(熵持续收窄 + 正优势
   续写把高频动作进一步抬高)。两者共同指向:**ALFWorld 上"原地打转"是
   低熵策略的天然吸子**。
3. **greedy val 可能夸大崩幅**。greedy 读分布的众数;锐化把众数推向重复
   动作,但 temperature 0.9 采样下策略可能仍有相当的成功质量。这正是
   扫评协议(同 checkpoint、greedy vs sampled n=4)要裁决的:
   - sampled 稳 + greedy 崩 → 解码伪象,选 checkpoint 报数即可;
   - 两者同崩 → 真退化,算法层需治(候选:熵下限/早停按 val 峰值)。
   grpo10 s1 的同协议裁决先例是"中间态"(greedy 跌 13.3pp,sampled 跌
   7.0pp)。

## 四、对论文与 v4.x 的含义

- 报表口径:主表应报**峰值 checkpoint 的 pass@k**(标准做法,各方法同
  规则),尾点 greedy 不作为方法优劣证据;末段不稳定作为 limitation 或
  分析节素材(三方法同病,反而是环境层的共性观察)。
- v4.x 候选(不急):熵护栏(entropy floor / 自适应温度)、按 val 峰值
  早停、m(1−m) 趋势感知(治课程吸池,见 v5 验尸 §五)。
- 扫评结果落盘后在此文档补终表与裁决(数据:`$SCRATCH/ckpt_sweep_catalystv4s3/`,
  报告:`analysis_outputs/ckpt_sweep_catalystv4s3/`)。

## 五、扫评裁决(2026-08-21 凌晨,关键步已完成)

同 128 任务、同协议(greedy n=1 / sampled T=0.9 n=4):

| step | greedy | pass@1 | pass@3 |
|---|---|---|---|
| 50 | 71.9 | **70.3** | **86.9** |
| 70 | 71.1 | 67.8 | 81.1 |
| 80 | 71.9 | 68.6 | 78.5 |
| 100 | 40.6 | 49.6 | 66.2 |

冻结规则计算:D_greedy = 31.2pp,D_sampled = 20.7pp
→ 20.7 ≥ 0.6×31.2(18.7)且 ≥7pp → **判"真退化"**。
greedy 确有放大成分(step 100 上 sampled 比 greedy 高 9 个点),但
sampled 口径也崩了五分之一,策略退化是真实的。§三.3 的第二分支生效:
**熵护栏/按峰早停进入 v4.x 必做项,且必须在铺开 WebShop/多 seed 战线
之前定案**,否则每一趟 run 都带同一个尾部隐患。

同场对照(各自巅峰 pass@1 / pass@3):s3 零自举 70.3/86.9@50;
v4_s0 带画像 74.2@100/90.6@70(未崩种子);GRPO_s0 71.1@90/90.6@100;
GRPO_s1 58.4/78.9@80(同样尾崩:pass@1 58.4→51.4)。样本效率主张成立:
**s3 在 step 50 达到 GRPO 最好种子 step 90-100 的水平,一半步数**;
零自举 s3 在同步数(50)反超带画像 s0(70.3 vs 66.6),画像非胜因在
pass@k 口径二次确认。
