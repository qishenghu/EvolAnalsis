## 1. 核心洞察：策略梯度估计器有两个槽位，整个领域在无序地填它们

策略梯度估计器：

$$\nabla J = \mathbb{E}_{y\sim \color{blue}{q}}\Big[\underbrace{\tfrac{\pi(y|x)}{\color{blue}{q(y)}}}_{\text{修正}}\cdot A(y)\cdot \nabla\log \underbrace{\pi(y|x)}_{\color{red}{\text{目标}}}\Big]$$

它有两个槽位：**采样侧 q**（样本从哪来）和**目标侧 π**（为谁的梯度负责）。用这个透镜
看 §0 的整个动物园，秩序立现：

- **合法族**（只动采样侧）：hint 采样（Guide）、前缀入场（R3/CRPS）、树分支（ARPO）、
  反事实干预（InT/CVT-RL）——它们全都是**换一个 q**；
- **非法族**（污染目标侧）：教师 token 进 loss（LUFFY/CHORD/TRAPO 的 SFT 项）——
  目标被改成 π 与"贴近教师"的混合，不动点被挪走（我们的解构定理）；
- **不可行族**（q 来自外族模型）：π/q 的分母不可算或比率退化（我们的 ESS 不可能性）。

**关键定理（契约，三条款版——2026-08-03 经用户追问修严格）**：合法程序分三类，
各有各的修正机制，不能混为一谈：

| 条款 | 程序类型 | 改什么 | 修正机制 | 双账? |
|---|---|---|---|---|
| C | 上下文程序（hint/交接笔记/自评注入） | 某决策的**条件文本** | 决策级自 IS（π/q）+ surgery | **要** |
| S | 状态程序（entry-replay/branch 回放/课程） | **你站在哪**（起始状态分布） | 起点退火回 s₀ + rehearsal + **按 (task, 起点) 分组** | 不要（给定起点，续写恒 on-policy，比率≡1） |

（脚注：解码参数改动（温度/top-p）是 C 的平凡退化情形，比率解析可算，不单列一类。
2026-08-03 依用户意见撤销原 D 类。）

C/D 的合法性来自**精确汇率**（分子分母同网络，可算可控）；S 的合法性来自**退火**
（状态分布错配无法 IS 修——状态密度比不可算——但给定起点的梯度是真 on-policy 梯度，
起点分布退回 s₀ 后目标与纯 GRPO 逐字一致）。目标侧永远纯 π。满足契约 ⇒ C/D 程序
**全程**不挪不动点，S 程序**终态**不挪不动点。组合程序按成分拆解（branch = S+C，
回放按起点分组、hint 记双账，各管各的）。

**分组细则**（Bias-1 的终极封印）：advantage 可比性要求同起点——C/D 样本与干净样本
可同组（IS 折算到同一目标）；S 样本必须自成组，组定义 = **(task, 起点状态)**。
混组平均即基线污染的复辟，分组细化天然杜绝。

一句话原理（论文的可背诵句）：

> **Rollout 是可编程的，梯度是有契约的。把一切外部知识编译进采样程序，让目标侧永远纯净。**
> （Program the rollouts. Never touch the loss.）

## 2. 三层贡献

### 2.1 契约定理（理论层）

形式化"guidance 程序"空间：程序 = 对 (起始状态分布, 上下文, 解码参数) 的任意改造。
证明三件事：

1. **合法性**：任何程序下的 IS 修正梯度无偏于纯目标 J；不动点全程不变（非渐近）。
2. **非法性**：目标侧注入教师 token ⇒ 不动点偏移量闭式可写（解构定理，含 LUFFY/CHORD/
   TRAPO-TrSFT 为特例）；外族采样 ⇒ ESS ≤ n·e^(−D₂) 不可救（跨家族 think 实测几百 nat）。
3. **可控性**：within-model 程序的 KL(q‖π) 可测，ESS 有下界估计 ⇒ 存在保 ESS 的程序
   强度控制器（这是 §2.3 控制器的理论许可）。

**动物园收编表**：每篇已有论文 = 本框架的一个程序（或一次契约违约及其可预测病理）。
这是解构定理的完全体——不是与五个家族并列，而是给它们发户口。

**OPSD 专项差分（2026-08-03 补，reviewer 必拿它对线）**：OPSD = within-model 特权自我
进**目标侧**（逐 token KL），无采样侧 guidance、无环境把关。它成立的前提是特权信息为
金标准（数学答案）。Agentic 设定的特权是**可错的**教师 trace——无门控地朝它蒸馏会把
错误一起蒸进来（OPD 系在长程 agentic 的公认局限）。预注册预测：OPSD 式 trace-特权蒸馏
在 trace 与学生状态错位处系统性退化，采样侧 + IS 记账免疫。OPSD 进 baseline 表，
并可改造为受 advantage 门控的一条臂。一句话答辩：**"OPSD 是特权可信时的目标侧解法；
特权不可信时，唯一安全的门是采样侧 + 环境把关。"**

### 2.2 多轮 context surgery（估计器层——我们独有的硬技术）

单轮 hint-RL（Guide）的比率是整条回答的比率。**多轮 agentic 是它没解决、我们独有
基建的地方**：hint/示范如果留在上下文里，会污染后续所有 turn 的分布，序列级比率
随长度爆炸。解法：

> **决策级比率约束**：guidance 只在被引导的那个决策的 prompt 里渲染，该 turn 结束后
> 由确定性渲染器**外科手术式移除**（我们的 exact-snapshot 上下文系统本来就是干这个的）。
> 于是 π/q 的差异被约束在单个决策内——比率 = 单 turn 比率，量级温和、可 clip、可监控。

这一层是纯增量工程苦活，恰好是我们已经建成、而单轮论文没有的：确定性渲染器、
逐决策快照训练、师生上下文对齐军规——全部直接复用。

### 2.3 指挥家控制器（算法层——名字的由来）

现有每篇论文都**手工设计**自己的调度器：TRAPO 的效用启发式、ADHint 的难度先验、
CRPS 的 k 控制器、ARPO 的熵触发、我们旧 DUET 的 μ 日程。CONDUCTOR 把这件事本身
算法化：

- **程序库**（每个都是已验证过的原子，现在成为"乐器"）：
  `∅`（纯 GRPO）/ `teacher-hint(τ,强度)` / `entry-replay(τ,k)`（SHERPA）/
  `self-critique-retry` / `counterfactual-branch(t,a')` / `scaffold-fade` / …
- **控制器 = 逐任务的 bandit**：每步为每个任务把 rollout 预算分配给各程序，
  效用信号 = **单位 GPU 秒产生的梯度信号量**（可测：ESS × advantage 方差贡献 ÷ 成本）。
- 教师影响的最终形态：teacher-hint / entry-replay 只是两条 bandit 臂。学生弱时它们
  效用高、被多拉；学生追平后其效用测量值自然归零、臂自动死亡——**"自适应教师影响"
  不再是任何公式，而是资源分配的涌现结果**。冷启动、crossover、强学生安全、跨家族
  免疫（外族内容只能当 hint 文本，永不进 loss）全部由同一机制覆盖。

## 3. 完整算法（一步）

```
每个训练步，对 batch 中每个任务：
1. 控制器按各程序的效用后验分配本任务的 n 条 rollout 预算
   （如：4 条 ∅，2 条 teacher-hint，2 条 entry-replay@k*）
2. 各程序生成各自的 q-rollout：
   - ∅：正常采样
   - teacher-hint：该决策 prompt 内渲染教师建议/思路 → 采样 → surgery 移除
   - entry-replay：环境重放教师前 k 步 → 学生接管
   - counterfactual-branch：回放到被诊断的 t，hint 替代动作，采短后缀组
3. 按程序类型记账：
   - C 类：双 log-prob——log π(y|净上下文) 与 log q(y|hint 上下文)
     （同网络两次 forward；surgery 保证差异局限在被引导决策内）
   - S 类：无双账（给定起点即 on-policy）；只记起点标识用于分组
   - D 类：解析比率（解码参数已知，无额外 forward）
4. 分组算优势：C/D 样本与干净样本同组（IS 折算同一目标）；
   S 样本按 (task, 起点) 自成组 → clip 后的修正比率 → 纯 π 的策略梯度
5. 用测得的 (ESS, advantage 贡献, 成本) 更新各程序的效用后验；
   成功轨迹入档案（成为未来 entry/hint 的素材）
```

超参实质只剩：程序库清单、bandit 先验、ESS 下限。没有 μ、没有 λ 日程、
没有密度比估计器、没有基线分离——**它们的职能全部被"契约 + 控制器"吸收**。

### 3.5 FAQ：为什么要记双 log-prob？（2026-08-03 与用户对齐）

因为我们用**带提示采的样本**改进**不带提示的模型**——两个分布，两本账，π/q 是汇率。

- 不记双账的两种死法：只训带 hint 的条件 → 模型 hint 依赖、测试时不迁移；
  梯度打在干净条件上却按 on-policy 记账 → 抽样有偏（多抽了 hint 建议的动作）。
- 比率的直观含义：**"这个行为里多少是模型自己的、多少是 hint 借的"**。
  例：hint 下 q=0.9 采出 "go to cabinet 1"，去 hint 重打分 π=0.2 ⇒ w≈0.22，
  好结果只有 22% 记在模型头上，但按真实频率无偏入账。
- hint 没白给：不带 hint 时好行为几乎观测不到（概率连乘到万分之一）；hint 让它
  **被看见**，双账让它**记得对**——IS 的经典角色：不改估计对象，只改估计质量。
  与 STaR 式 "hint 采样+成功 SFT" 的分界线正在于此（STaR 权重恒 1 ⇒ 有偏）。
- 附赠红利①：**比率→1 = 内化完成的传感器**，免费喂给 bandit 决定退休——旧 DUET
  用判别器苦估的 fade-out，在此是记账副产品。红利②：GRPO 本就记 old_log_prob，
  只多一列干净打分 pass——"100 行接入"的由来。
- 多轮必须配 surgery：hint 不删则后续每 token 都 q≠π，比率跨千 token 连乘爆炸；
  手术后比率约束在单个被引导决策内，温和、可 clip、可监控。

### 3.6 粒度旋钮：旧 DR3 在谱系上的位置（2026-08-03 与用户对齐）

比率估计存在一个粒度谱系，粒度越粗越好估、越粗越失真：

| 粒度 | 可估性 | 保真度 | 使用者 |
|---|---|---|---|
| token 连乘（整段） | 爆炸（跨家族 e^-数百） | 理论精确 | 无人敢用 |
| **单决策** | 温和、可 clip | **与干预的因果单位对齐** | Guide / 本框架 surgery |
| 整条序列（一个标量） | 最易（压扁的代理量） | 连坐、credit 涂抹 | 旧 DR3 |

旧 DR3 的再认识：α-relative 压扁 + w_min 地板 + NLL 摘要特征 = 它估的从来不是真比率
（真值=连乘=e^-数百，不因"序列级"而改变），而是一个有界平滑 gate。同家族时粗特征的
重叠给出漂亮的渐进 fade-out——**sequence-level 恰是它当年 work 的隐藏原因**；跨家族
时 NLL 摘要本身即可分（钝刀照样砍头），且均匀 ŵ 让重叠不错的 action 段被 think 段
**连坐**。设计定律：**比率的粒度必须等于干预的粒度**——surgery 就是把旋钮拧到
"单决策"甜点的机制。旧 DR3 由此从黑历史转正为粒度谱系上的一个数据点，可进论文。

### 3.7 FAQ："SFT→RL 不改最优点"与"CHORD/TRAPO 实测 SFT→GRPO 更差"矛盾吗？（2026-08-03 与用户对齐）

不矛盾。前者是关于**目标函数景观**的命题（argmax J 不随初始化移动——这是"地图"），
后者是关于**优化动力学**的命题（非凸、局部、有限预算的优化里，初始化决定落在哪个
盆地、走多快——这是"行车"）。最优点没动 ≠ 你能到。四个机制解释"起点更高、终点更低"：

1. **熵塌缩断掉 GRPO 的燃料**：SFT 是 forward KL，把分布压尖；GRPO 的梯度来自组内
   结果差异，全对/全错组 advantage 全零。SFT 起点探索面窄 → 有效梯度组变少 → 涨得快、
   停得早。
2. **先学后拆**：SFT 灌入 teacher 表面 token 而无底层计算支撑 → 自信地错 → RL 前期的
   梯度预算花在拆除 SFT 习惯上，总预算固定时净亏。我们自己 BC-only 的 48@50→31@100
   曲线就是这个形状。
3. **可达性有定理**：softmax PG 的收敛常数依赖初始策略对最优动作的概率下界
   （Mei et al. 2020），坏初始化可让收敛指数慢（Li, Wei & Chi 2021）。SFT 把
   非 teacher 动作压到 ~0；若 student-class 最优不在 teacher 支撑内，有限步内到不了，
   实验上与"到了更差的点"不可区分。
4. **实际管线的目标经常真的动了**：KL-ref 若重置为 SFT 检查点，目标变
   J−βKL(π‖π_SFT)，最优点被真实拉向 teacher（"最优点不变"的前提失效）；ref 若留在
   base，SFT 起点从第一步就付 KL 罚被往回拽。两种设置都偏离"纯 J"的理想陈述。

方向并非普适：base 成功率为零的冷启动（R1 的 cold-start SFT、ALFWorld 2B）里纯 GRPO
永远采不出正样本，path 干预是**必需**的——问题从"要不要"变成"以什么粒度、配什么
退火与记账"。因此 CHORD/TRAPO 的负结果不是对"path 干预不动最优点"的反驳，而是对
契约前提的支持：**未修正的 path 干预损伤动力学**。SFT→RL 是最粗暴的 path 干预
（一次性、全强度、无退火、参数空间整体推入 teacher 盆地后撒手）；CHORD（μ 连续退火）、
TRAPO（前缀粒度收缩）、本框架（决策粒度 + 双账 + surgery）是同一个病的三档不同粒度的药。

### 3.8 固定预算三资源账本：分布矫正是止损，不是造血（2026-08-03 与用户对齐）

固定预算 B 步下，最大化的对象是 J(θ_B) 而非渐近 J——整个游戏就是优化动力学。教师
数据的价值拆成三种资源：**信号密度**（非零梯度步的比例；GRPO 全对/全错组梯度为零，
冷启动近乎全零→决定长得快）、**信号方向**（指向 student-class 改进还是指向模仿
teacher→决定不长歪、不停在 teacher 次优点）、**熵预算**（后期探索资本→决定长得高、
停得晚）。

DUET v1 按此记账：mixing 是唯一正项（bootstrap：零成功组里教师样本给出非零
advantage，信号密度 0→正）；**BS/DR3 均为防御项**——BS 买回被基线污染压死的
on-policy 信号（恢复"长得快"，但仅相对裸 mixing，相对纯 GRPO 无加速），DR3 让教师
引力退场防第三层故障（保"长得高"，顺带衰减 BC 压力间接缓熵挤压）；**无组件对熵预算
做正贡献，BC 在净消耗熵**（φ(p) 只是烧得慢）。净账 = bootstrap − 残余偏置 − 熵损耗，
精确解释实验签名：bootstrap 主导的场景（弱学生/冷启动/短训练）赢，熵与 plateau 主导
的场景（长训练/强学生）优势消失。

熵的关键区分：RL 收敛本身降熵（概率集中到**自己验证过的成功**上）是良性支出；SFT 的
病态是花熵买**自己算不出的表面 token**（自信的错），事后还要 GRPO 花预算退货——烧熵、
无性能、欠债。"减缓熵坍缩"的准确表述不是少花熵，而是**别把熵花在要退货的东西上**。

槽位结论：loss 侧交付时三资源零和（补密度的 BC 必然烧熵歪方向，矫正在后面追着擦）；
采样侧交付时三资源解耦（guidance 抬组内成功率→密度↑；更新 token 仍采自近似 π 自身
分布→熵花在自验证成功上；方向由记账保证——S 类比率≡1，C 类决策级自 IS）。
**三资源在错误槽位里零和、在正确槽位里不零和**，这是"槽位搬家"最硬的一句论证。

## 4. 为什么这有 GRPO 级的"采用形状"

1. **接入成本 ≈ 100 行**：任何跑 GRPO 的团队，加"双 log-prob 记账 + 一个程序"就能用
   （比如只加 teacher-hint 臂）；尝到甜头再上控制器。GRPO 当年就是这样赢的——
   不是最聪明，是最容易换。
2. **每个 baseline 都是我们的消融**：对比实验表 = 每条臂单独钉死 vs 控制器全开。
   赢了是框架赢，输了哪条臂也能定位——实验设计天然自洽。
3. **人人能背的原理**："Program the rollouts, never touch the loss." 加上契约定理，
  这是能进教科书那一段的抽象层级。
4. **经济性**：hint/entry/branch 程序的样本大多是短后缀或高成功率区域——单位梯度
  信号的生成成本低于纯 GRPO 盲采（可实测出图）。

## 5. 与本会话各提案的关系（谱系收束）

- **DUET v1**：BS/DR3 是对"契约违约"（教师混组）的补丁——违约本身取消后不再需要；
  其判别器在新框架里无角色（可选做程序靶向的探针）。**初衷重定位（2026-08-03 与用户
  对齐）**：DUET 的初衷本来就是"做带修正的 path 干预、改善训练动力学"——初衷没有错，
  错的是投放槽位：教师影响从 loss 侧（估计器/目标槽，唯一过敏的接口）注入，于是被迫
  发明 BS/DR3/自适应 μ 三个补丁来止血。CONDUCTOR 是同一初衷在正确槽位（采样侧）的
  实现：初衷不变，槽位搬家。补丁史由此成为论文的动机证据而非包袱。
- **DUET-2 两扇门**：门 A（门控 BC）**违反契约**（目标侧），废弃；门 B（势整形）合法
  但属于 reward 槽，可作为可选程序保留。
- **SHERPA**：整体降格为 `entry-replay` 程序 + 档案子系统——它的全部价值保留，
  它的 novelty 危机（CRPS/TRAPO 邻居）解除，因为它不再是论文的主张主体。
- **两年病理档案**：全部成为契约定理的实证材料（违约 ⇒ 预言的病理逐条兑现）。

## 6. 理论包（四个可交付定理）

1. 契约定理（合法程序空间刻画 + 全程不动点不变性）；
2. 解构定理（目标侧违约的偏移闭式；LUFFY/CHORD/TRAPO-TrSFT 为特例）；
3. ESS 不可能性（外族采样的信息论下界；跨家族实测佐证）；
4. 控制器 regret 界（bandit over programs 相对最优固定程序的标准 regret 结果——
   借用成熟 bandit 理论，证明"自动调度渐近不输任何手工调度"）。

## 6.5 创新点解剖与最终评级（2026-08-03，与用户对齐）

按强度排序：① 契约定理 + 三个预注册预言（TRAPO 跨家族退化 / OPSD 状态错位退化 /
控制器同预算不输任何单臂）——**定理+预言+兑现=真贡献，定理+收编表=综述，牙齿全在
实验里**；② 多轮 context surgery——真空白但窄，作为①的构造性下半场；③ 异质 guidance
同批混跑的统一估计器与分组细则——系统级；④ bandit 控制器——方法论上最弱
（Graves 2017 bandit-over-syllabus 先例），价值是叙事性的（"自适应教师影响"的涌现实现）。

对 reviewer 的一句话：**首个让任意异质 guidance 可即插即用混入 RL 批次、且可证明
优化目标每一步都与纯 on-policy RL 逐字相同的算法，外加从测量中学会逐任务分配
guidance 的控制器。**

最终评级（诚实版）："GRPO 之于 PPO"的等级不是纸面能设计的，是被采用追认的。纸面
上限：定理立住 + 三预言兑现 + 控制器在弱学生冷启动明显赢 → 7-8 分、有 spotlight
机会；预言不兑现 → 框架论文观感、6 分挣扎。**novelty 的最后一公里在实验里，不在
构思里**——这是本方案与已死的原子提案的本质区别：原子的命运由文献判决（已死），
框架的命运由我们的实验判决（未定，可控）。
