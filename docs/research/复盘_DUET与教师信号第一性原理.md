## 一、DUET 复盘

### 1.1 做对了什么（真资产）

1. **问题诊断正确**：教师轨迹混入 GRPO 批次产生两类偏差（基线污染、
   重要性权重失真）。这个诊断有双重实锤：自家消融（去 BS → 1.5B 塌 ~0%）
   + 他家反向印证（TRAPO 组内混前缀正是 Bias-1 同构结构）。
2. **BS 是硬组件**：无参数、消融支持、机制透明。DUET 最经得起打的部分。
3. **SC 落在 reward 接口**：事后看是四个组件里唯一**零补丁**的——这不是
   巧合（见 §3）。
4. **初衷正确**：做 path 干预改善训练动力学；teacher 的 think 含可学逻辑。
   两条都被后续所有分析确认，错的从来是通道。

### 1.2 投稿暴露了什么（评审层，4/3/3）

- **被读成补丁堆叠**：BS+DR3+BC+SC 四组件互相耦合、各带超参，
  reviewer 的"复杂度/工程感"直觉其实摸到了真病灶（见 1.4）。
- **novelty 被读成组合**：每个原子都有近邻（LUFFY 混批、CHORD 加权
  SFT、POfD 势整形、GKD 在线蒸馏）。
- **理论-实现裂缝**：Eq.9 telescoping 推导被三次 code audit 证伪（红线
  ②，永不再写）；DR3 实际估的不是密度比而是有界平滑 gate（上界 ~1.13、
  地板 0.01）——理论叙事与代码行为有距离。

### 1.3 我们自己实锤了什么（rebuttal 期，比评审更狠）

- **WS 36.0 不可复现**（复现 12.3±5.2）——主表一格是噪声尖峰。
- **BC-only 先高后塌**（48@50 → 31@100）——持续教师 token 压力后期
  反噬的实物证据，后来"先学后拆/熵透支"理论的种子。
- **判别器双杀**：disc_acc→1 同时把 ŵ 压到地板、把 μ 压到谷底，教师
  影响被同一信号双通道掐死——自适应机制自己把自己关了。
- **跨家族死刑**：教师轨迹 85.2% 是 think token，逐 token 差距累出序列
  比率 e^-800；ESS ≤ n·e^(−D₂) 是信息论上限，任何比率修正都救不了。
  ICLR 新栈就是跨家族教师，此路在新设定下**物理性关闭**。
- **四层故障层级**：①基线污染 ②d_teacher≠d_π ③KL 投影不是学生能力类
  最优 ④熵挤压。

### 1.4 深层病理一句话

**修正机构的存在本身，就是通道选错的自白。** BS、DR3、自适应 μ 三个
补丁全部在为同一个决定还债：把教师 token 放进 loss。三资源账本下，
mixing 是唯一造血项（bootstrap），全部修正机制是防御项（止损不造血），
且无人管熵、BC 还在烧熵。SC 零补丁，因为 reward 接口本来就不过敏。

## 二、文献复盘（按"它回答了什么"组织，不按清单）

### 2.1 loss 通道文献：一场集体自白

LUFFY（混批+policy shaping）、CHORD（手动 μ 日程退到 0）、TRAPO 的
TrSFT（前缀进 loss）、DUET 的自适应 μ、R1 的冷启动 SFT→RL 硬切换——
**这一族方法要么自带衰减/切换机构，要么被实验证明持续加压后期反噬**
（我们的 BC-only 48→31；CHORD/TRAPO 论文里 SFT→GRPO 输给全程 GRPO 的
负结果，用户最初的悖论问题即源于此）。一个通道如果必须被计划性关闭
才能不伤害训练，它的边际价值曲线必然穿零转负——整个文献在用各自的
衰减日程集体承认这件事。

**SFT→RL 两派矛盾的解**（我们的角点统一，定理 3 互补松弛）：
guided 成功率 = 0 时（连教师牵着走都造不出燃料），前置 SFT 是唯一选择
（能力注入，R1 派对）；> 0 时 token 通道劣于 on-policy（CHORD/TRAPO
派对）。判据可测，两派各占一支。

**汇率论（用户修正定稿）**：教师 reasoning = 内在逻辑 + 外在风格，SFT
学到 ≈ 0.7 外在 + 0.3 内在。token 似然是语法层目标，风格 token 便宜、
逻辑 token 贵，梯度先捡便宜的；稀释随师生差距变大。on-policy RL 汇率
100%（只强化自己验证过的计算）。

### 2.2 起点/采样通道文献：同一种燃料，不同的货币

R3（ICML'24 反向课程）、CRPS、TRAPO 前缀重放、JSRL/DR-PO（RL 经典）
——都在买同一种燃料：把学生放到 p∈(0,1) 的出信号区。区别在付法：
- R3：开环日程，每环境重调；
- TRAPO：组内混深度 → E[adv_d] = p_d − p̄ 结构偏差（深臂恒正浅臂恒负，
  Bias-1 同构，我们用伤疤认出它）；且前缀进 loss（TrSFT）又回到 2.1；
- JSRL/DR-PO：证明"从示范状态起跑"是 RL 老原子，不是我们的发明。

**关键观察**：这一族方法（去掉 TrSFT 类污染后）**没有一个需要衰减
机构**——起点搬运在学生不需要它时自然过期。两族文献的这个分水岭
（一边人人带日程，一边无人需要日程）是通道分类学最强的经验证据。

### 2.3 资源控制文献：单轴上的重复发现

DAPO 动态采样（滤死组）、VADE/TAC/SEC（pass-rate/方差目标课程）、
Knapsack RL/CoBA/TRACE（rollout 预算分配）、Entropy Scheduling（熵
日程，开环）、Clip-Cov/KL-Cov（协方差截断）、Cui et al. 协方差定律
（ΔH ≈ −α·Cov(logπ, Â)）。每篇都在单轴上重新发现同一件事：**信号只
存在于 p∈(0,1)，熵是要管理的资本**。没有一篇把教师数据放进分配空间；
(任务 × 入场 × 程序) 的乘积空间是空的。

### 2.4 用户直接提供的关键输入（记入贡献）

- CHORD/TRAPO 的 SFT→GRPO 负结果 → 触发悖论求解（角点统一的起点）；
- TRAPO 组内混前缀的设计细节 → 触发结构偏差辨析（三差分判据）；
- SFT 汇率混合物模型（0.7 外在 + 0.3 内在）→ 汇率论定稿；
- "固定预算下长得快/长得高/保住熵"三目标公理 → TEMPO 理论的出发点；
- task-once 真实预算 → 砍掉全部逐任务机构的裁决依据。

## 三、第一性原理：教师信号何时对 LLM RL 持续正向

### 3.1 通道分类学（教师信号进入 RL 的全部接口）

| # | 接口 | 代表 | 方向完整性 | 需要衰减机构吗 | 判定 |
|---|---|---|---|---|---|
| 1 | **loss**（教师 token 进梯度） | SFT/LUFFY/CHORD/TrSFT/DUET-BC | 污染（off-policy 方向 + 汇率稀释） | **必须**（μ/shaping/切换） | 不可持续；仅角点合法 |
| 2 | **baseline**（教师样本进组统计） | naive mixing | 纯害 | 需要 BS 止血 | 不是信号通道 |
| 3 | **reward**（势整形/进度图） | POfD/DUET-SC | 保最优策略不变 | 不需要，但**自然失效**（教师地图覆盖随学生偏离而衰减） | 合法、中性偏正、有限寿命；是重定价不是供货 |
| 4 | **采样/环境**（起点、context、程序） | R3/JSRL/入场/hint | **零污染**（给定起点续写恒 on-policy，ratio≡1） | **不需要**（自然过期） | 唯一同时满足"造血 + 免修正"的接口 |
| 5 | **验证/选择**（教师当 verifier/reranker） | RLAIF 族 | 取决于教师判据质量 | 不需要 | 未深入，注记备查 |

### 3.2 "持续正向"的准确定义与可测判据

**定义**：持续正向 ≠ 永远有贡献。正确定义是：**每一步边际贡献 ≥ 0，
且随训练趋于 0 而不是穿零转负**。

**判据（可操作）**：一个通道若需要外置衰减/门控/修正机构才能不伤害
训练，它就不是持续正向的——机构的存在即自白（§1.4、§2.1 双重证据）。
反之，通道若在学生不需要时自动等价于不干预（如：学生从 s₀ 即可成功
时，入场组与普通组同分布），则它的边际贡献有非负下界。

### 3.3 采样接口的三资源论证（为什么它在第一性原理上是对的）

- **燃料**：教师独有且不可替代的资产不是它的 token，而是**"成功在哪里"
  的知识**——学生自己够不到的状态区域坐标。引理 1：p∈{0,1} 的组梯度
  精确为零（不是学得慢，是燃料沙漠）；教师起点把学生放进 p∈(0,1) 出
  燃料带 = 打井。这是造血，不是止损。
- **方向**：MDP 最优策略逐状态定义 ⇒ 换起始分布不动最优策略（S 条款）；
  从教师起点续写的梯度对"从该起点的目标"完全无偏。代价只有一个：练的
  是相邻目标（打折但干净），由退火闭合。对比 loss 通道：那里的代价是
  方向本身被污染，且随师生差距复利。
- **熵**：on-policy 探索在教师指定的关键状态上花熵 = 花在决策相关处，
  符合等边际原则；loss 通道把熵花在模仿风格 token 上 = 既浪费又前置
  梭哈（定理 3 判负）。
- **think 的归宿**：in-context 条件化（前缀含教师 think，零梯度）。
  两个不对称支撑它：**看得懂 ≪ 写得出**（师生差距越大，读的汇率相对
  写的汇率越高——恰在 SFT 最差处此通道最好）；**语义通道自带内外
  分离**（学生用自己的风格复述读到的逻辑，腔调留在 prompt 里不进梯度）。
  初心（think 值得学）不经 loss 通道也能全额兑现。

### 3.4 角点例外：能力注入

学生在最深入场仍 p = 0 的任务上，采样接口无能为力——没有任何起点
能造出燃料。此时（且仅此时）loss 通道是唯一选择：它能注入策略类里
原本不存在的行为（R1 冷启动的真正职能）。完整图景：
**token 通道 = 角点上的能力注入器；采样通道 = 角点外的持续加速器；
切换判据 = guided 成功率是否 > 0（可测）。**

## 四、诚实边界：钉死的 vs 开放的

### 4.1 复盘钉死、可当公理用的结论

1. 通道分类学与"衰减机构 = 不可持续自白"判据（§3.1-3.2）；
2. 教师的不可替代资产是"成功在哪里"的知识，不是 token 序列（§3.3）；
3. 角点判据统一 SFT-vs-RL 两派（§3.4）；
4. 三资源账本：燃料引理（死组精确零梯度）、协方差定律、汇率稀释；
5. 组内必须同质（起跑线相同才能同组排名）——TRAPO 的反例 + DUET 的
   伤疤双向钉死；
6. 跨家族教师下一切 token 级比率修正物理性失效（e^-800 / ESS 上限）。

### 4.2 真正开放的问题

1. **采样接口的实例化远不止入场**：起点只是教师知识最"薄"的用法
   （把教师压缩成一个坐标）。hint/交接笔记（C 类程序）、教师 verifier、
   语义课程等更"厚"的用法全部未探索——CONDUCTOR 的 C 条款被推到 v2
   后就没再碰过。
2. **in-context think 通道是否真承重**：目前是消融臂，不是定理。若
   think 前缀被剥离后性能不变，初心通道的现行实现就落空了。
3. **教师可达 ≠ 学生可达**：入场状态上学生策略类若表达不了后续，
   燃料仍是零（四层故障③的残影，程度轻但存在）。
4. **reward 接口与采样接口是互补还是冗余**（SC 要不要回来）：未验证。
5. **控制律的形态**：v1 被判 heuristic，v2 双恒温器用户仍不满意——
   "怎么调度"两轮都没过关，说明可能问错了层（见 4.3）。

### 4.3 一个自我诊断：探照灯偏差

漏斗从 CONDUCTOR 一路收窄到"入场深度调度"，每一步局部都有理由
（可证明、便宜、契约干净），但合起来有一个未申报的偏差：**我们一直
在往最好证明的方向收缩，而不是往教师信号最厚的方向展开**。入场版把
"教师知识"降维成了"起点坐标 + 被动前缀"，算法的全部剩余内容只是
调度工程——这可能正是两轮实例化都让人不满意的根源：它不像在**学**
教师的东西，只像在**用**教师的位置。这一条是候选病根，待用户裁决。
