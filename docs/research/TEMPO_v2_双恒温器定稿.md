# TEMPO v2：双恒温器版（定稿 2026-08-04）

> **触发**：用户判定 v1 入场版的调度机构（7 档 EMA 表、前沿指针、换档触发、
> 4/4 对冲、毕业检测）"已经变得非常 heuristic / hacking"。判定成立，机构全废。
> 本文件是算法层推倒重来的定稿。**理论层不动**（三资源三定理，见
> `TEMPO_三资源预算理论与算法.md`；通俗版第一部分仍有效）。
>
> **预算前提（用户给定，不可动摇）**：~1600 任务 × batch-8 × 200 步，
> 或 batch-16 × 100 步；只跑 1 个 epoch，**每个任务全程只见一次**。

---

## 0. 一句话版本

整个算法 = 普通 GRPO + 两个标量恒温器，每个恒温器一行更新式：

```
燃料恒温器（入场深度）:  k ← clip( k + η_k · (0.5 − p̂) , 0, k_max )
熵恒温器（熵税率）    :  λ ← [ λ + η_λ · (H̄(t) − Ĥ) ]₊
```

- `p̂` = 本训练步全部 rollout 的平均成功率（免费，数一下就有）
- `Ĥ` = 本训练步生成 token 的平均熵（训练 forward 顺手就有）
- `H̄(t)` = 熵滑轨，H₀ 线性降到 H_min（定理 3 派生）

除这两行外，**没有任何调度机构**。永久状态只有两个标量（k、λ）加教师档案。

## 1. v1 为什么病了：诊断

### 1.1 手调件清单（v1 的罪证）

| v1 机构 | 里面的 magic number | 来源 |
|---|---|---|
| 7 档深度网格 {0,15,…,90}% | 档位间距 15% | 拍脑袋 |
| 每档 EMA 成功率表 | EMA 系数 α | 拍脑袋 |
| 前沿指针 + 第 1 步扫档 | 指针初值 90% | 半拍脑袋 |
| 换档触发 | 阈值 EMA > 0.8 | 拍脑袋 |
| 4/4 对冲 | 比例 4:4 | 拍脑袋 |
| 回退规则 | 新档 ≥ 0.2 | 拍脑袋 |
| 毕业检测 | "最后一次换档" 判据 | 派生但多余 |

### 1.2 两条病根

**病根一：为了控制去识别整条曲线。** v1 想把 p(k)（每个深度档的成功率曲线）
整个估出来（7 档表），再从表里读出该站哪一档。但控制根本不需要整条曲线——
只需要一个点：p(k) = 0.5 的**根**在哪。估计整个函数、却只用它的根，
这是控制论里的经典反面教材（identification-for-control 的过度识别）。
只求根，一个标量加负反馈就够了。

**病根二：task-once 下逐任务自适应在信息论上不可能。** 每个任务只见一次，
任何"针对这个任务学到了什么"的在线状态都无处积累。所以**总体级
（population-level）标量控制器不是简化，而是这个预算体制下可行控制器的
完备类**。v1 的档位表假装在做比总体级更细的事，实际上填表的数据本来
就是总体混合的——机构比信息多，多出来的部分全是 heuristic。

## 2. 两条理论事实 → 两行更新式

### 2.1 单调性把"选深度"从 bandit 降为求根

p(k) 对 k **单调递增**：入场越深（教师前缀越长），离终点越近，越容易成功。
单调 ⇒ p(k) = p* 的根唯一 ⇒ 不需要探索各档位（bandit），只需要**求根**。
求噪声函数的根，标准工具是 Robbins-Monro 随机逼近（1951）：

```
k_{t+1} = clip( k_t + η_k (p* − p̂_t), 0, k_max )
```

- p̂ 偏高（太容易）→ k 下调（少给帮助）；p̂ 偏低（太难）→ k 上调。负反馈。
- **不需要 EMA、不需要表**：Robbins-Monro 更新自身就是时间上的滑动平均，
  再套一层 EMA 是重复造轮子。
- 64 条 rollout 的 p̂ 单步噪声 ≈ √(0.25/64) ≈ **±0.06**，对增益适中的
  控制器完全够用。

**p\* = 0.5 从 Lemma 1 派生，不是调的。** 二值奖励、组内归一化下，
死组（全成/全败）梯度恰为零，活组概率 = 1 − p⁸ − (1−p)⁸，在 p=0.5 取最大。
而且顶部很平：

| p | 活组概率 (n=8) |
|---|---|
| 0.5 | 99.2% |
| 0.3 | 94.2% |
| 0.2 | 83.2% |
| 0.1 | 57.0% |

p ∈ [0.3, 0.7] 内燃料数量几乎无差别 ⇒ p\* 的精确取值是二阶问题，
0.5 是无参数的默认。（若想利用"越浅质量越高"的三档信号质量结论，
可取平顶下沿 p\* ≈ 0.35 偏向浅入场——但这引入一个可辩论的旋钮，
v2 默认不做，预注册后不改。）

### 2.2 熵恒温器（沿用，形式与 k 环完全同构）

定理 3（协方差定律 + 等边际花费）给出熵应沿滑轨 H̄(t) = H₀ − (H₀−H_min)·t/T
匀速下降。执行手段是一行 advantage 平移：

```
Â ← Â − λ (log π − 组内均值 log π)
λ_{t+1} = [ λ_t + η_λ (H̄(t) − Ĥ_t) ]₊     （λ ∈ [0, λ_max] 安全夹）
```

熵掉得比滑轨快 → λ 升（踩刹车）；熵高于滑轨 → λ 降到 0（不干预）。
λ = 0 时整个算法退化为普通 GRPO。

两个环形式完全一样：**同一种数学对象（负反馈随机逼近）管两种资源**。
弱耦合（k 管成功率、λ 管熵，目标正交），增益都小，标准多环稳定性论证适用。

## 3. 完整算法（可直接照抄实现）

**永久状态**：k（标量，%）、λ（标量）、教师档案（每任务一条轨迹，含 think）。
没有别的。

**初值**：k₀ = k_max = 90%（t=0 学生最弱，根在最深处——理论一致初值，
免扫档）；λ₀ = 0；H₀ = 第 0 步实测。

**每个训练步 t**（batch = 8 个新任务 × 8 rollouts，任务只此一见）：

1. 每个任务取教师轨迹，截前 k% 步（量化到步边界：j = round(k% × L_teacher)）
   作为入场前缀，**含教师 think**，以 prompt 形式喂入（零梯度）。
2. 该任务 8 条 rollout **全部从同一入场点**继续（组内同深度）→ 环境跑完
   → 终局成败 r。
3. 组内 GRPO advantage（组 = task，天然同深度，ratio ≡ 1）。
4. 熵定价：Â ← Â − λ(logπ − 组均值)。
5. 正常 PPO 更新。
6. 两行恒温器更新（见 §0）。

**增益从预算派生，不是调的**：要求控制器在持续偏差 0.1 下 T/3 步内能
横穿全程：η_k · 0.1 · (T/3) = k_max ⇒ **η_k = 30·k_max/T**
（T=100 → 27；T=200 → 13.5）。η_λ 取常规对偶步长（如 0.5），一阶不敏感。

**p̂ 的定义**：二值环境（ALFWorld）= 成功率；连续奖励环境（WebShop）
= 平均终局 reward（二值时两者相等）。预注册后不改。

## 4. 一次具体演算（ALFWorld，T=100，η_k=27）

| 阶段 | k 的行为 | p̂ 的行为 | 发生了什么 |
|---|---|---|---|
| step 1 | 90% → 81.6%（90 + 27×(0.5−0.81)） | 0.81 | 只剩尾巴 10%，大多做得完，太容易，k 快速下滑 |
| step 2–10 | 滑到 ~50% | 0.7 → 0.55 | 负反馈找根 |
| step 10–40 | 45% → 30% 缓降 | 在 0.5 附近震荡 | 恒温平衡：学生在变强，根在下移，k 跟着追 |
| step 40–80 | 滑到 0 | 0.55 → 0.6 | 学生泛化，浅入场也能赢，k 自然触底 |
| step 80–100 | 钉在 0 | 自由上升 | **毕业**：纯 GRPO + 熵定价，无教师依赖 |

毕业不是被"检测"出来的，是 k 触 0 这个事实本身。若后期 p̂ 回落到 0.5 以下，
k 会自动回升——恒温器不是单行道，教师支持可自动复热。

## 5. 旋钮审计：七个手调件 → 一个旋钮

| v2 量 | 来源 | 算不算旋钮 |
|---|---|---|
| p\* = 0.5 | Lemma 1 派生 + 平顶不敏感 | 否 |
| k₀ = k_max | 理论一致初值（t=0 根最深） | 否 |
| η_k = 30·k_max/T | 预算带宽派生 | 否 |
| H̄(t) 线性滑轨 | 定理 3（等边际花费）派生 | 否 |
| H₀ | 第 0 步实测 | 否 |
| η_λ、λ_max | 常规对偶步长 + 安全夹，一阶不敏感 | 否 |
| **H_min** | 终点熵目标（nats/token，可解释） | **是，唯一真旋钮**（默认 0.5·H₀，跨环境同值，预注册后不改） |

审稿人无法对一行更新式说"hand-crafted schedule"——因为没有 schedule，
只有 setpoint，而 setpoint 是引理派生的。

## 6. 死亡名单与保留名单

**死（v1 → v2）**：7 档深度网格；每档 EMA 成功率表；前沿指针；第 1 步扫档；
换档触发（EMA>0.8）；4/4 对冲；回退规则（≥0.2）；毕业检测机构。

**保留（未被这次推倒波及）**：
- **组内同深度**（一个 task 的 8 条 rollout 同一入场点）——TRAPO 组内混深度
  会带来 E[adv_d] = p_d − p̄ 的结构偏差（Bias-1 同构，DUET 的伤疤），v2 依然规避。
- **前缀零梯度、ratio ≡ 1**——方向契约（定理 2）不变。
- **think 前缀通道**——教师推理以 in-context 方式进语境，学生用自己的
  风格续写（语义通道自动分离内在逻辑/外在风格）。**初心不变。**
- **熵定价一行式**——本来就干净。
- **重放确定性前提**——入场机制本身要求教师前缀在环境里可确定性重放，
  仍是唯一硬性 infra 前提，仍需 50 条轨迹的 observation-hash 校验。

## 7. 涌现性质（不再需要专门机构去实现的东西）

1. **毕业** = k 触 0（曾经是一套检测逻辑，现在是一个事实）。
2. **课程表** = k_t 的轨迹（曾经要设计，现在是控制器的副产品，
   而且是每次实验免费画出来的图——论文插图自动生成）。
3. **跨环境自校准**：ALFWorld 和 WebShop 难度节奏不同，开环日程
  （R3 式线性 anneal）必须每个环境重调；闭环用同一套式子两边自适应。
4. **GRPO-太强风险的优雅退化**（记忆里的科学风险之二）：若强推理学生
   从零就 p̂ > 0.5，k 直接钉 0，算法诚实地退化为 GRPO + 熵定价——
   教师通道不硬塞，"该不该用教师"由恒温器回答而非由人辩护。

## 8. 诚实弱点

1. **全局 k 对双峰难度分布的两尾浪费**：batch 里过易任务 p≈1、过难任务 p≈0
   的组仍是死组。task-once 下不可约（§1.2 病根二），用活组占比日志记账，
   论文里如实报告。
2. **k 抖动**：单步噪声 ±0.06 × 增益 27 ≈ ±1.6pp，负反馈使其有界
  （类 OU 过程），深度效应平滑，无实质影响。
3. **H_min 仍是一个真旋钮**（见 §5）。
4. **重放确定性未验证**——仍是开工前第一件事。

## 9. 预注册预测（v2 版，取代 v1 清单的调度类条目）

- **P-A**：k_t 轨迹噪声内单调缓降；ALFWorld 预算内触 0，WebShop 可能不触 0。
- **P-B**：毕业前 batch 成功率保持在 [0.35, 0.65] 恒温带内
  （对照 GRPO 从 <0.2 起步爬升）；毕业后自由上升（"长得高"可见）。
- **P-C**：活组占比全程显著高于 GRPO，尤其前 1/3。
- **P-D**：熵沿滑轨；GRPO 对照组熵指数塌缩。
- **P-E（闭环价值）**：同一套超参跨 ALFWorld/WebShop：闭环两边都稳，
  开环线性 anneal 至少一边失配。

**消融臂（六臂）**：① 纯 GRPO；② +entry 开环线性 anneal（R3 式）；
③ +entry 闭环（λ=0）；④ 全量（闭环 k + 熵恒温）；⑤ think-stripped 前缀
（只留动作，验证初心通道）；⑥ TRAPO 式组内混深度（验证 Bias-1 差分预测）。

## 10. 论文叙事增益

- "整个教师利用调度器是一行公式"——比任何机构堆叠都更 ICLR。
- 控制论定位一句话：单调性把课程选择从 bandit 降为求根，Robbins-Monro
  求根只需两个标量——**理论直接决定了机构的最小尺寸**。
- vs TRAPO：他们是手设的组内混合比例日程；我们是引理派生 setpoint 的
  闭环，且组内同深度免于结构偏差。三条差分指标（组内深度-advantage 相关 /
  0% 组增长率 / 毕业点检测）全部保留。
- vs Entropy Scheduling：他们实验发现"early stable, late anneal"形状；
  我们从等边际花费推出该形状，并用恒温器执行。
