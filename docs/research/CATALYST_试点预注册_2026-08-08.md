# CATALYST 双试点预注册(2026-08-08)

**目的**:在写一行训练代码之前,用两个受控试点裁决 CATALYST(零模仿不变式:
梯度只流过"学生自己写的、环境盖章的 token";教师是催化剂不是模板)的两条
知识通路是否有足够燃料。判据先于数据冻结,不许事后挪门柱。
背景与算法定义见 `SIEVE_算法提案_v1_2026-08-07.md`(v1)及本文件 §5(v2 差异)。

## 1. 共同设定

- 学生:Qwen3.5-4B(与采集契约同 tokenizer/上下文管理,军规链路)。
- 任务集:AF / WS 各取 **T_fail ∩ T_covered ≈ 120 题**——
  裸考失败(以本试点裸考臂为准,旧 400 rollout 每题 n=1 仅作预筛)
  且教师(flash 优先,证据强)有成功轨迹。按 seed-2026 顺序取前 120,不许挑题。
- 环境:登录节点现役栈(AF 8081 / WS 8083);采样温度与采集契约一致。
- 所有 rollout 成败全落盘;φ 打分复用 `analysis/cll_teacher_profile.py`。

## 2. P-A 转写试点(通路①:提示 → 自写 → 验证 → 事后去提示)

**臂设计**(每题每臂 n=8):
- A0 裸考:原始 prompt,无教师素材。
- A1 原文提示:教师 think(卫生清洗:剥标签/草稿块/粘连)注入为参考资料段。
- A2 重写提示:同素材先经 HD 学生腔调重写再注入(= 汇率论检验臂)。

**指标**:
- **转写率** C = P(A1 成功 | A0 全败题)(A2 同理);
- **纯度**:对 A1/A2 成功轨迹做事后去提示(prompt 换回 A0 版),φ 打分,
  对比教师原文的 think 段分布:p10 与均值应大幅回浅;
- **腔调差** Δ = C(A2) − C(A1)。

**预注册假设与判据**:
- H-A1(燃料):C ≥ **15%**(至少一个环境)→ 通路①立项;C < 8% → 判负。
- H-A2(纯度/准on-policy):去提示后自写数据 think-p10 比教师原文浅 **≥3×**
  (预期 flash AF:−1.7 → 优于 −0.6;参照学生噪声地板 −0.44)。
  不达 → "转写消灭 off-policyness"的主张降级,须改口为"显著缓解"。
- H-A3(汇率):Δ > 3pp → 腔调有实质汇率成本,训练侧采用 A2 形态;
  |Δ| ≤ 3pp → 用 A1(省一次重写调用)。

## 3. P-B 状态接管试点(通路②:entry-k 倒推课程)

**臂设计**(同一任务集,k ∈ {50%, 75%} × 每档 n=4):
重放教师前 k 比例的 action 序列推进环境(确定性已验),学生从中局接手,
prompt 含被重放历史(军规渲染),无 think 提示。

**指标**:接管成功率 S(k);单调性 S(75%) > S(50%) > S(0)=A0。

**预注册假设与判据**:
- H-B1(近端燃料):角点题 S(75%) ≥ **30%** → 倒推课程立项;< 15% 判负。
- H-B2(梯度存在):S(75%) − S(50%) ≥ 10pp(课程有坡度可爬)。

## 4. 决策矩阵(8/11 Gate 2,与用户共同执行)

## 5. 预算与调度

- 规模:P-A ≈ 120×3×8×2env ≈ 5760 episodes;P-B ≈ 120×2×4×2env ≈ 1920。
  AF 30 轮上限、WS 30 轮:1×H200(4B vLLM, max_num_seqs 16)+ 环境并行 8,
  估 **6–8 GPU 时/环境**。
- 调度:先试 1-GPU qsub 与 45217 并行;项目配额不容则 STOPFILE 暂停 45217

- 产出目录:`$SCRATCH/catalyst_pilots/{pa,pb}/...`,分析入
  `analysis_outputs/catalyst_pilots/`。

## 6.5 结果(2026-08-08 当日回填;判据未动过)

任务集:AF 120 / WS 110;A0 真基线 SR 25.3% / 13.4%;真角点(8/8 全败)52 / 56。
全部 rollout 成败落盘于 $SCRATCH/catalyst_pilots/;接管重放 divergence=0。

| 判据 | 门槛 | AlfWorld | WebShop | 判定 |
|---|---|---|---|---|
| H-A1 转写率(角点 task 级) | ≥15% | A1 **98.1%** (51/52) | A1 **58.9%** (33/56) | **双过,碾压** |
| H-A3 腔调差 Δ(A2−A1) | \|Δ\|≤3pp 用原文 | −1.9pp | +1.8pp | 用原文,免重写 |
| H-B1 角点接管 S(75%) | ≥30%(rollout 级) | **38.0%** ✓ | 18.8% ✗(task 级 51.8%) | AF 过 / WS 半过 |
| H-B2 课程坡度 | ≥10pp | +17.3pp ✓ | +9.9pp 压线 | AF 过 / WS 压线 |
| H-A2 纯度(去提示 think p10 回浅) | ≥3× | −0.82,2.1× ✗(学生地板 −0.44) | −0.05,**17–26×** ✓(≈地板) | WS 过 / AF 未达 |
| 合并残差(全通道后仍全败角点) | — | **1/52 (2%)** | 14/56 (25%) | 兜底层需求小 |

**决策矩阵落点:A✓ B(AF✓/WS半✓)→ CATALYST 旗舰成立**(转写主力+状态课程辅助)。
按预注册条款,H-A2 AF 未达 3× ⇒ "转写**消灭** off-policyness"降级为"**显著缓解**":
AF 去提示残差 −0.82 落在教师文本(−1.73)与学生地板(−0.44)之间、且浅于同家族教
师文本(122B AF −0.90)——残差正是"进入学生自写文本的教师知识"的痕迹,训练全程
φ 审计留任(认证/加权重放数据),而非假设纯度。WS 去提示后即学生地板(−0.05 vs
地板 +0.00),消灭主张在 WS 成立。

## 6. 试点不回答的问题(诚实边界)

- 退休/退火动态(需多轮训练);
- 新域(SciWorld/DeepSearch)读数——采集完成后补一轮小样即可复用同脚本。
