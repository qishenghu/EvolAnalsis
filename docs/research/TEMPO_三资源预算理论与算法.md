## 0. 设计公理与问题陈述

**公理（用户 2026-08-03 确立）**：训练预算固定为 B 步。要最大化的不是渐近 J，
而是 **J(θ_B)**。教师数据的全部价值必须折算为对 J(θ_B) 的贡献。

这一句话换掉了整个领域的分析工具。渐近分析（"我们的方法收敛到无偏最优"）在
固定预算下**没有区分力**——纯 GRPO、SFT→GRPO、几乎一切修正后的混合方法在渐近
意义下都对，但 J(θ_B) 天差地别（CHORD/TRAPO 实测 SFT→GRPO 更差、我们自己
BC-only 48@50→31@100、WS 复现塌方，全是动力学现象）。正确的问题是一个
**训练过程的最优控制问题**：

$$\max_{u_0,\dots,u_{B-1}} \; J(\theta_B), \qquad
\theta_{t+1} = \theta_t + \alpha\, g(\theta_t, u_t)$$

其中 u_t 是第 t 步的**批次生成决策**：把 rollout 预算分给哪些任务、哪些入场
状态、哪些 guidance 程序、损失里如何加权。这个控制问题不可解析求解，但它的
一阶结构可以完整刻画——刻画的结果就是三资源理论。

## 1. 三资源的形式化

一步的贡献 $\Delta J_t \approx \alpha\,\langle \nabla J(\theta_t),\,
\mathbb{E}[g_t]\rangle$。把它拆开，恰好得到三个独立的可测资源：

- **燃料 F**（信号密度）：$\mathbb{E}[g_t]$ 的幅度有多大——决定**长得快**；
- **方向 D**：$\mathbb{E}[g_t]$ 与 $\nabla J$ 的夹角——决定**不长歪、不停在
  teacher 次优点**；
- **熵预算 H**：这一步花掉多少未来的探索资本——决定**长得高、停得晚**。

以下逐一给出可证明的定量刻画。全文设二值奖励 $r\in\{0,1\}$（agentic 成功率
设定），组大小 n，组内成功率 p（依赖于任务 m、入场状态 s、guidance 程序 u）。

### 1.1 资源一：燃料引理（组级信号密度）

**引理 1（组燃料引理）**。设某组 n 条 rollout 独立采自 π（给定 (m,s,u)），
GRPO 均值基线优势 $\hat A_i = r_i - \bar r$。则：

**(a) 死组恰好零贡献**：全同组（全对或全错）的梯度**恒等于零**，且

$$\Pr[\text{死组}] \;=\; p^n + (1-p)^n.$$

**(b) 无偏缩放**：$\mathbb{E}[g_{\text{组}}] = (1-\tfrac1n)\,\nabla J_{m,s,u}$，
其中 $\nabla J_{m,s,u} = \mathrm{Cov}(r,\nabla\log\pi(\tau))$。

*证明*：$\mathbb{E}[(r_i-\bar r)\nabla\log\pi_i] = \mathbb{E}[r_i\nabla\log\pi_i]
- \tfrac1n\sum_j\mathbb{E}[r_j\nabla\log\pi_i]$。交叉项 $j\neq i$ 独立且 score
均值为零（$\mathbb{E}[\nabla\log\pi]=0$），故只剩 $(1-\tfrac1n)
\mathbb{E}[r\nabla\log\pi]$，又 $\mathbb{E}[(r-p)\nabla\log\pi]
=\mathbb{E}[r\nabla\log\pi]$。∎

**(c) 燃料上界**：由 Cauchy–Schwarz，

$$\|\nabla J_{m,s,u}\| \;\le\; \sqrt{p(1-p)}\cdot
\sqrt{\mathbb{E}\|\nabla\log\pi\|^2}.$$

**(d) 极端情形是等式**：$p\in\{0,1\}\Rightarrow r$ 为常数
$\Rightarrow \nabla J_{m,s,u}=0$ **精确成立**——这些组不是"信号弱"，是
**花了 GPU 采样、贡献严格为零**。

定义**燃料函数** $\varphi_n(p) = 1 - p^n - (1-p)^n$（组产生任何梯度的概率），
在 p=1/2 处最大。GRPO 训练的瞬时速度受 $\sqrt{p(1-p)}$ 与 $\varphi_n(p)$
双重约束——这就是"长得快"的全部数学内容：**批次里混合成功带（约 0.2<p<0.8）
的组占比，决定当步学习速度**。

推论（燃料沙漠）：冷启动时几乎所有 (任务, s₀) 的 p≈0，批次燃料≈0，纯 GRPO
的曲线平坦不是"学得慢"而是"梯度恒零"。**教师数据在燃料维度的合法角色由此唯一
确定：不是注入梯度，而是把采样搬进有燃料的地带**——入场重放（把 s 从 s₀ 挪到
教师轨迹中部，p(s) 进带）与 hint（抬高给定 s 的 p）都是"打井"，二者创造燃料
而不碰估计器。

### 1.2 资源二：方向契约（从 CONDUCTOR 继承为第二定理）

**定理 2（方向契约，三条款；证明见 CONDUCTOR §2.1，此处作为资源二的刻画）**：

- **C 条款**：只改条件文本（hint/交接笔记）的程序，配决策级自 IS（π/q 双账）
  与 surgery，梯度对纯目标 J 无偏，**不动点全程不变**；
- **S 条款**：只改入场分布的程序，给定入场后续写恒 on-policy（比率≡1），配
  (task, 入场) 分组 + 退火回 s₀。加强版陈述：MDP 最优策略是**逐状态**对象，
  对起始分布不变——S 程序在精确 MDP 意义下**根本不动最优策略**，退火只为
  函数逼近下的容量分配；
- **违约闭式**：教师 token 进 loss ⇒ 不动点偏移量闭式可写（解构定理，
  LUFFY/CHORD/TRAPO-TrSFT 为特例）；外族采样进估计器 ⇒
  ESS ≤ n·e^(−D₂) 不可救。

在三资源语言里：**方向不是连续定价的商品，是约束**——契约内程序方向成本为 0，
契约外成本无穷大（有限预算内表现为持续偏置税）。这把资源二变成可行域，
让后面的分配问题只剩两个连续变量。

### 1.3 资源三：熵账本（协方差定律与良性/病态支出）

**已知定律**（Cui et al., The Entropy Mechanism, 2505.22617；此处为引用+短推导）：
softmax 策略一步 PG 更新的熵变一阶为

$$\Delta H \;\approx\; -\alpha\,\mathbb{E}_s\,
\mathrm{Cov}_{a\sim\pi}\big(\log\pi(a|s),\; \hat A(a,s)\big).$$

直觉：给**高概率**动作正优势 ⇒ 分布更尖 ⇒ 熵跌；给**低概率**动作正优势 ⇒
熵**涨**。于是每个 token 的熵价格可测：

$$c_i \;=\; \big(\log\pi_i - \overline{\log\pi}\big)\cdot \hat A_i,$$

批次熵支出 $\hat C = \alpha\cdot\mathrm{mean}(c_i)$，逐步可从已有 logging 读出。

**良性 vs 病态支出**（§3.8 的定理化；混合物修正见通俗版 §1.4，用户
2026-08-03 提出）：RL 把概率集中到**自己验证过的成功**上，汇率 100%；
SFT 买到的是"外在风格 + 内在逻辑"的混合物，汇率 = 内在占比，且该占比随
师生差距下降——跨家族时逼近纯背诵，花熵还欠退货债。
**熵不是要守恒的，是要花对的，而且不同商店汇率不同。**

**熵红利**：$c_i<0$ 且 $\hat A_i>0$ 的样本（低概率的成功——探索性成功）同时
买性能**和**熵。定理 1 的入场搬运恰好批量制造这种样本（新地带的成功必然是
低概率事件）——**采样侧 guidance 不只熵便宜，可以熵为正**。

## 2. 三条定理：从公理到分配律

### 定理 1（燃料分配律）

一步内把 K 个组分配给候选 $(m_k, s_k, u_k)$。在正迁移假设
$\langle\nabla J,\nabla J_k\rangle \ge \rho_{\min}\|\nabla J\|\|\nabla J_k\|$
（可测；由退火与 rehearsal 维持）下，一阶增益满足

$$\Delta J \;\le\; \alpha(1-\tfrac1n)\tfrac{G}{K}
\sum_k \sqrt{p_k(1-p_k)},$$

且 $p_k\in\{0,1\}$ 的组贡献精确为零。**最大化下界/上界的分配 = 把组填进混合
成功带**。当 s₀ 处 p=0 而某入场 s 或某 hint 强度使 p 进带时，该程序的燃料
价值严格为正、方向成本为零（定理 2）——**教师数据的最优用法在燃料维度被
"推导"出来，而不是被"设计"出来**。

已有工作是本定理限制在单轴上的特例：DAPO 动态采样（把死组从批次剔除 =
$\varphi_n$ 的拒绝采样式利用，仅 prompt 轴）、VADE/TAC/SEC（pass-rate 带宽
课程，仅 prompt 轴）、Knapsack/CoBA/TRACE（rollout 数在 prompt 间的再分配，
仅组大小轴）。**没有一篇进入 (入场状态 × guidance 程序) 轴——那是 agentic
环境独有的自由度，也是教师数据居住的地方。**

### 定理 2（方向契约）

见 §1.2。作用：把分配问题的可行域限制在"采样侧程序 + 记账"内，保证定理 1
的分配无论怎么激进，目标函数每一步与纯 on-policy RL 逐字相同。

### 定理 3（熵步调定理——训练的欧拉方程）

**模型**：总熵预算 $\bar H = H_0 - H_{\min}$（下限来自生成退化/交换律拐点）。
第 t 步花 $h_t \ge 0$ 的熵可获得至多 $f_t(h_t)$ 的性能，$f_t$ 凹增
（凹性来源：每步的高收益机会——带内组——有限，边际支出流向更差的机会）。

$$\max \sum_t f_t(h_t) \quad \text{s.t.} \quad \sum_t h_t \le \bar H .$$

**KKT ⇒ 最优步调等化边际收益**：存在 λ* 使得内点处
$f_t'(h_t) = \lambda^*$，且 $f_t'(0) < \lambda^*$ 的步花 0。
这是消费平滑/水填充：**把熵当跨期预算，最优策略是让"每单位熵买到的性能"
在整个训练期恒定**。

三个推论把文献里互相矛盾的实验统一为一个互补松弛条件的两支：

- **(a) SFT→RL = 前置梭哈，内点严格次优**：t=0 一次性花光大块熵预算
  （forward KL 压尖），彼时边际收益最差（表面 token、要退货），违反等边际
  条件 ⇒ 定理直接预言"涨得快、停得早"——CHORD/TRAPO 的负结果是本定理的
  实验兑现。
- **(b) 冷启动角点解**：当采样侧一切程序都造不出燃料
  （连 full-guidance 的 p 仍≈0，即教师自己都勉强），$f_t'(0)=0$ 而唯有
  loss 侧注入有正收益 ⇒ 最优解前置——**SFT 冷启动阶段作为 KKT 角点解涌现**。
  R1 的 cold-start 与 CHORD 的反结果**是同一条互补松弛条件的两支**，
  用"guided 成功率是否 > 0"这一个可测量判别。
- **(c) 步调形状**：f_t 随 archive/前沿扩张弱改善 ⇒ 最优支出不前倾，近似
  均匀后收尾加速——恰好是 Entropy Scheduling（OpenReview fhvjv6UDAj）
  **纯实验摸出来**的"早稳后退火"。他们发现了形状，我们推导了形状。

**在线实现（对偶控制器）**：f_t' 不可直接测，用对偶上升追踪滑翔道
$\bar H(t)$（默认线性，镜像 Budgeted Training ICLR'20 的线性 LR 结论）：

$$\lambda_{t+1} = \big[\lambda_t + \eta\,(\bar H(t) - H(\theta_t))\big]_+ .$$

**工具恰好是一行优势平移**：最大化 $J + \lambda H$ 的采样梯度等价于

$$\hat A_i \;\leftarrow\; \hat A_i \;-\; \lambda_t\,
\big(\log\pi_i - \overline{\log\pi}\big),$$

即**给稀有成功发补贴、给自信成功收税，税率 λ_t 由预算滑翔道自动定**。
经典固定系数熵 bonus = λ 冻结的特例；Clip-Cov/KL-Cov = 本工具的截断式
低方差实现；ES 的预设日程 = 开环版本，我们是闭环。

## 3. TEMPO 算法（一步）

```
状态：成功档案 A（教师轨迹 + 自身成功轨迹，含逐状态入场点）；
      逐 (task, 入场, 程序) 的成功率表 p̂；对偶价格 λ；程序效用后验。

每个训练步：
1. 【分配：定理1】把 K 组填进带：对每个任务，从 {(s₀,∅), (s₀,hint σ),
   (入场 s_k, ∅), ...} 里选 p̂ 落在混合带 [0.2,0.8] 的配置；
   p̂(s₀,∅) 进带的任务逐步退火回纯 (s₀,∅)。全体 p̂≈0 的任务标记
   "燃料沙漠"，仅分配少量勘探组（bandit 探索项）。
2. 【生成：定理2 可行域】按程序类型 rollout：
   C 类（hint 等）记双 log-prob + surgery；S 类（入场重放）记入场标识。
3. 【分组】C 类与干净样本同组（IS 折算）；S 类按 (task, 入场) 自成组。
4. 【损失】纯 GRPO 策略梯度（目标侧永远 π）
   + 决策级 IS 比率（仅 C 类，clip）
   + 熵定价优势平移：Â ← Â − λ·(logπ − mean logπ)。
5. 【记账更新】
   λ ← [λ + η(H̄(t) − Ĥ_t)]₊               （对偶追踪滑翔道）
   p̂ 表按本步结果更新（燃料账）
   程序效用后验 ← 实测收益率（燃料贡献 + λ·熵红利）/成本   （bandit）
   新成功轨迹（含其全部中间状态）入档案 A
```

超参实质只剩三个：熵下限 H_min（定滑翔道）、混合带边界、程序库清单。
μ 日程、密度比估计器、基线分离、熵系数、课程阶段划分——**全部被三条定理的
在线实现吸收**。

## 5. 诚实的 novelty 审计

**已被占的**（2026-08-03 检索确认）：每个机制原子（CONDUCTOR §0 的 11 行）+
每个单资源控制器（上表）。"熵调度""带宽课程""预算分配"三个词单独都不新。

**属于我们的**：
1. **三资源联合理论本身**——燃料引理（死组精确零 + φ_n 燃料函数）、方向契约、
   熵步调定理，从一个公理（max J(θ_B)）推出，三个单资源文献分支成为三条
   定理的投影；
2. **教师数据首次进入分配空间**——所有 budget-allocation 论文只分配 rollout
   于 prompt 之间；guidance 文献只手调自己的日程。二者的乘积空间
   (任务 × 入场 × 程序) 是空的，且入场轴是 agentic 独有；
3. **角点解统一**——SFT-vs-RL 两个互相矛盾的实验文献 = 一条 KKT 条件的两支，
   附可测判据（guided 成功率）；
4. **推导出 ES 摸出来的日程形状**——理论预言已被独立论文的实验先行证实。

**最大风险**：统一理论类论文容易被读成"胶水综述"。防御同 CONDUCTOR §6.5：
牙齿全在预注册差分实验里——联合控制器必须在至少两个单轴强 baseline
（VADE 式 prompt 课程、ES 式熵日程）的盲区轴上赢，否则理论再漂亮也只是注释。

## 6. 预注册预测（可证伪清单）

- **P1（燃料-速度耦合）**：任何 GRPO 运行中，批次带内组占比与 dJ/dt 强相关；
  死组占比升到阈值 ⇒ 曲线拐平。零成本：从我们现有 wandb 日志回溯验证。
- **P2（熵消融）**：λ≡0 的 TEMPO 与完整版早期曲线重合、plateau 显著更低
  （"长得快不变、长得高受损"——资源解耦的直接证据）。
- **P3（角点翻转）**：guided 成功率 >0 的任务上采样侧碾压 loss 侧注入；
  ≈0 的任务上短 SFT 前置反超——排序按判据翻转。
- **P4（步调）**：等熵预算下，滑翔道追踪 > 前置梭哈（SFT→RL）与
  匀速无控（纯 GRPO 熵自由跌）。
- **P5（入场轴增益）**：ALFWorld 上加入入场轴的分配 > 仅 prompt 轴的
  VADE 式课程（agentic 独有自由度的直接兑现）。

## 7. 与 CONDUCTOR 的关系：不是替代，是补上屋顶

CONDUCTOR 回答了"**怎么做才合法**"（方向契约、surgery、双账）；它自评最弱的
一环是控制器效用信号 ad hoc（§6.5 第④条，"单位 GPU 秒的梯度信号量"是拍的）。
TEMPO 从固定预算公理出发，**把控制器的目标函数推导了出来**：

> 效用 = 燃料贡献（定理 1，√p(1−p) 可测） + λ_t × 熵红利（定理 3，协方差可测），
> 可行域 = 契约（定理 2）。

即：CONDUCTOR = TEMPO 的定理 2 + 执行机构；TEMPO = CONDUCTOR 的理论上层 +
另外两条定理。合并后的论文结构：**三资源分析（为什么）→ 三条定理（是什么）→
程序库与控制器（怎么做）→ 差分实验（凭什么信）**——正是用户要的
