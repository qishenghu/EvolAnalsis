# SIEVE:支撑门控的师源强化学习(算法提案 v1,2026-08-07)

**SIEVE = Support-Indexed Extraction with Verified Exploration**(筛法:取其精华、去其糟粕的机制化)。
面向 ICLR 2027。前置阅读:`ICLR2027_对话交接文档.md`、`TEACHER_COLLECTION_H200_2026-08.md`、
`analysis_outputs/cll_teacher_profile/`(含 tail_* 尾巴画像)、`figures_gate1/`。

---

## 0. 一句话

把教师影响的每一条通路(学哪个 token、学多重、给多少上下文脚手架、何时退场)都交给
**同一个自校准、免教师概率、随训练在线更新的测量量**——学生自身的中心化对数似然
φ_t = log π_θ(y_t|ctx) + H[π_θ(·|ctx)]——治理;梯度只落在两类 token 上:
学生自己被环境验证的 token(GRPO),和教师 token 中位于学生支撑内的部分(门控 BC)。
脚手架随测量收敛**自动拆除**,收敛点与纯 on-policy GRPO 重合。

用户核心问题的对应:**加速**(A)来自角点密集信号与脚手架条件化;**无损**(B)来自
"教师 token 永不进策略梯度 + 膜引理 + 自拆除";**选择**(C)来自 token 级支撑门 +
卫生掩码 + 语境/词元双通道分流;**闭环**在于所有旋钮由在线测量驱动,无手工日程。

## 1. 设定与符号

多轮 agentic RL:学生 π_θ(Qwen3.5-4B/2B)在真实环境(AlfWorld/WebShop/SciWorld/
DeepSearch)交互,GRPO 组内基线。教师为 text-only 黑盒(DeepSeek-v4-flash 跨家族 API /
Qwen3.5-122B 同家族本地),仅提供成功轨迹文本(1600 任务 seed-2026 账本,stop-on-success,
8 次尝试语义,师生同上下文契约,token 逐字节可重放——军规已四环境验证)。
教师覆盖率 37%–91% 不等:**满覆盖不存在,角点 regime 是常态**。

教师轨迹按学生 tokenizer 切分后,每 token 有段标签(think/action/other)与
φ_t(在当前 θ 下即时计算;训练 forward 顺带,零额外开销)。

## 3. 核心量:支撑门 w 与它的三个性质

**定义** φ_t = log p_t + H_t(p_t = 学生给教师 token 的概率,H_t = 该位置学生分布熵)。
**支撑门** w_t = min(1, e^{φ_t/τ})(默认 τ=1;硬阈值版作消融)。

**性质 1(零点自校准,引理)** 对学生自身样本 E[φ]=0,故 w 无需任何阈值标定;且
w_t = π_θ(y_t) / G_θ,G_θ = e^{−H} 是学生分布的几何均值概率——w 是"教师这个选择
相对学生典型选择的比值",**一个不需要教师概率的重要性代理**。

**性质 2(承诺违背语义)** φ 深负 ⇔ p 小 **且** H 小:教师与学生"已承诺"的行为冲突
(实测深尾 H≈0,正是口癖与硬枢纽);p 小但 H 大(开放位置的另一种合理说法)φ≈0,门放行。
门挡的不是"学生没见过的",是"与学生承诺相撞的"——这恰是买腔调/梯度爆炸的高危集。

**性质 3(膜引理 + 自动课程)** 门控 CE 对 logits 的更新幅度 ≤ w_t,深 OOD token 的
更新被指数压制(plain BC 恰相反:p→0 时 CE 梯度最大,见 M4 的 45–55%)。
且 w 随 θ **在线**重算:学生支撑长大后,原先被挡的 token 自动重新入场——
**门不是死刑,是排队**;对照静态过滤(IDFT/Filter-then-Reweight)这是本质差异。

## 4. 算法全貌

### 4.1 三通道路由(任务级,按在线读数分派)

对 batch 中每个任务,取重放统计(难度追踪器已有):无条件成功率 SR_u、
条件化成功率 SR_c(近窗 EMA)、教师覆盖(账本查询):

- **R0(自立)**:无教师轨迹,或 SR_u ≥ s_hi → 纯 GRPO 组。教师彻底缺席。
- **R1(可引导)**:有轨迹且非角点 → GRPO 组 + **条件化子组**:组内 ρ 比例的 rollout
  以教师素材为上下文前缀(entry 状态 / 教师 think 提示;形式由 8 月试点定),
  **梯度仍只落学生自己 token**(条件化改变输入分布而非策略,无比率问题);
  子组与本组各用各的基线(复用 BS 机制,动机从"纠偏"变为"分臂")。
  脚手架退火:ρ_task = clip(1 − SR_u/s_hi, 0, ρ_max)——学生行了,脚手架自动撤。
- **R2(角点)**:SR_u≈0 且 SR_c≈0(引导也不会)→ GRPO 组 + **门控 BC 辅助损失**
  (教师 token 梯度的唯一入口,且必须穿过 m ∘ w ∘ μ 三层)。

任务随训练在 R2→R1→R0 间自动迁移(读数驱动)。

### 4.2 损失

L(θ) = L_GRPO(学生 token;优势含熵恒温器平移)
     + μ · Σ_{教师token t} m_t · w_t · (−log π_θ(y_t))

- **m_t 卫生掩码(规则层)**:标签 token(`<think>` 等,伪影占尾 6–18%)、
  已识别家族口癖模式(flash 草稿块 " response…</action>"、粘连边界 ".The")、
  非 think/action 段。采集后一次离线标注,训练零成本。
- **w_t 支撑门(测量层)**:上式,forward 顺带。
- **μ 阀门(治理层)**:前沿债 D_w = EMA E_think[w·(−φ)^−](门放行但尚未内化的
  质量;实测初值 0.026–0.050 nats/token,恰好按家族×环境排序)。
  μ = μ_max · min(1, D_w / D_w^{init})。前沿清空 → μ→0,词元通道自熄。
  方向与 DUET v1 相反(差距大→**多**学),修正 v1 的语义倒置。

### 4.3 熵恒温器(TEMPO 组件保留)

优势平移 A′ = A + λ(−log π_θ − b),对偶更新 λ ← λ + η(H_ref − H);
H_ref 为慢参考带。一行实现,KKT 论证(模型内定理),防熵塌缩托底 B。

### 4.4 伪代码

```
for iteration:
    batch = sample_tasks()
    for task in batch:                        # 路由(重放统计,零额外 rollout)
        regime = route(coverage[task], SR_u[task], SR_c[task])
    rollouts = generate(policy, tasks,        # R1 任务按 ρ_task 混入条件化 rollout
                        condition=teacher_context if regime==R1)
    fwd = forward(policy, rollouts + teacher_traces[R2 tasks])
    φ = fwd.logp_teacher_tokens + fwd.entropy # 顺带
    w = min(1, exp(φ/τ)) * hygiene_mask
    A = grpo_advantage(rollouts, baseline_per_arm)   # 教师轨迹不入组
    A += λ*(−fwd.logp_student − b)                   # 恒温器
    loss = pg_loss(A, student_tokens) + μ * (w * ce_loss(teacher_tokens)).mean()
    update(θ);  update_EMA(D_w→μ, SR→ρ/route, H→λ)   # 全部读数驱动
```

## 5. 闭环治理表(每个旋钮:驱动量 → setpoint → 行为)

| 旋钮 | 驱动量(在线) | setpoint | 收敛行为 |
|---|---|---|---|
| w_t 支撑门 | φ_t(当前 θ) | E[φ]=0 自校准 | 支撑长大→门重开(自动课程) |
| μ 阀门 | 前沿债 D_w EMA | D_w→0 | 词元通道自熄 |
| ρ 脚手架 | SR_u EMA | SR_u→s_hi | 条件化撤除 |
| 路由 | SR_u/SR_c/覆盖 | R2→R1→R0 | 教师全面退场 |
| λ 恒温器 | 熵 H | H→H_ref | 探索底线恒守 |

**命题(脚手架自拆/不动点一致,模型内)**:各 setpoint 达成时教师项全为 0,
系统的驻点集 = 纯 GRPO 的驻点集——B(无损性)在极限处是结构保证,不是经验祈祷。

## 6. 与近邻的差异(相关工作定位)

| 工作 | 机制 | 我们的差异 |
|---|---|---|
| LUFFY | 教师混入组 + ratio shaping | M1 判死比率路线;我们教师 token 零 PG、不入组(Bias-1 结构性消除,非修正) |
| CHORD | 全局 μ 手工日程 SFT | token 级门 + 读数驱动阀门,无日程 |
| DUET v1(我们) | 判别器双职 | 仪器饱和(M1);测量职能移交 φ,方向倒置修正 |
| **TRAPO**(2512.17636)⚠ 最近邻 | TrSFT = CE×min(1,p/α)(常数信任域)+ 按回报阈值的专家前缀阶梯,单轮数学 | 词元门与 TrSFT **数学同构**(我们 = 把常数 α 换成每位置自适应 e^{−H},免调参零点);等预算下两门 98.5% 判决一致、分歧精确按熵分层(2026-08-08 实测)。**门不可作为独立 novelty 宣称**,必须显式引用并定位为 TrSFT 的熵中心化推广;差异重心在:治理层(μ 退场/不动点一致——TRAPO 无退场机制)、真实环境状态接管(vs 文本前缀)、部分覆盖/角点路由、黑盒多轮 setting、测量学贡献(解释信任域为何有效:45–55% 错配 + 承诺违背解剖) |
| IDFT/DDT | 静态语料 φ 加权 SFT | 我们:RL 闭环内**在线**门(自动课程)、环境验证、多轮 agentic、路由与治理层;引用其为词元层灵感 |
| Filter-then-Reweight | 离线过滤加权 | 同上:静态 vs 活门 |
| States-not-Tokens | 语境/状态通道 | 我们把语境通道纳入统一治理(ρ 退火、分臂基线),并与词元门互补分流精华/糟粕 |
| DAGGER/KD | 需教师在线查询/概率 | text-only 黑盒即可;教师续写@学生状态仅作 R1 扩展试点 |

**Novelty 主张(2026-08-08 修订,TRAPO 对齐后)**:novelty 重心**不在词元门**
(它是 TrSFT 家族的熵中心化推广,须显式引用 TRAPO/IDFT),而在:
①**测量学贡献**——判别器饱和裁决、CLL 尾巴解剖、45–55% 梯度错配:首次解释
"信任域式模仿为什么有效"(挡的是承诺违背=风格毒,不是罕见词);
②**治理层**——μ 阀门驱动的教师退场 + 不动点一致性(收敛=纯 GRPO;TRAPO 无
任何退场机制)+ 全旋钮读数驱动的闭环;
③**setting 扩展**——多轮真实环境的状态级接管(vs 单轮数学的文本前缀)、
部分覆盖(37–91%)与角点/无覆盖路由(TRAPO 假设全覆盖)、黑盒跨家族下的
免标签家族自适应。宣称句式:"we bring trust-region imitation into closed-loop
governance for black-box-teacher agentic RL, and supply the measurement science
that explains when and why it works."

## 7. 宣称分级

- **定理/引理(可证)**:零点自校准与 w=π/G 恒等;膜引理(更新幅度 ≤ w);
  不动点一致性(setpoint 达成 ⇒ 教师项=0)。
- **模型内定理**:熵恒温器 KKT;燃料引理沿用(R2 存在性论证)。
- **预注册假设(试点裁决)**:汇率论(HD 重写对照,决定 R2 是否加风格中和重写);
  语境通道因果增益(entry/think-prefix 试点);角点必要性方向。

## 9. 风险与开放点(8 月试点排程)

1. **汇率风险**:近支撑 token 的门控 BC 仍可能买到腔调 → HD 重写对照试点(8/8–8/10);
   若坏,R2 加"学生腔调重写后再门控"预处理(HD 基建同一套)。
2. **语境通道形式未定**:entry vs think-prefix vs 续写@学生状态 → 试点后定,
   R1 实现按试点胜者收敛,叙事主角(词元门 vs 语境)届时与用户定夺。
3. **SC(进度图)去留**:v1 不带,作扩展消融(极简卖点优先)——待用户拍板。
4. **门形式**(软/硬/τ)与 s_hi、ρ_max:消融定,不影响骨架。
