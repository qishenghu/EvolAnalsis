# CATALYST 项目进展汇报(2026-08-17)

**目标会议**:ICLR 2027(abstract 9/18,全文 9/25)
**核心科学问题**:teacher 引入的 off-policyness 如何处理,才能让 on-policy 模型以闭环方式"取其精华、去其糟粕"——**加速 RL 学习,同时不损伤天花板**。
**实验设置**:ALFWorld,Qwen3.5-4B,GRPO 框架,4×H200;训练池 800 任务,冻结 128 题 held-out 评测;评测协议 = 贪心 + 采样 n=4(报 pass@1 / pass@3 / 任务覆盖率)。

---

## 〇、前史:DUET 在 NeurIPS 2026 被质疑什么,CATALYST 如何逐条回应

**DUET 回顾**(NeurIPS 2026 投稿,3/4/3 分被拒):correct-then-extract 框架——教师轨迹混入 GRPO 后先纠偏(基线分离 BS、判别器密度比修复 DR3),再抽取(自适应 μ 的 BC 动作通道 + 进度图 shaping 的状态通道 SC)。

**三位评审的批评归纳**(依据 `neurips_reviews/` 原文):

| # | 批评(评审原意) | 出处 |
|---|---|---|
| R1 | **"principled" 名不副实**:SC 靠环境特定的手工状态匹配、shaping 非策略不变,却是效果的命门(WebShop 无 SC 1.0% vs 18.5%)——收益可能来自手工 shaping 而非"原理性纠偏" | bDeY |
| R2 | **DR3 理论存疑**:Eq.9 疑似双重计数;教师缓存经成功过滤,判别器分的可能是"成功 vs 失败"而非"教师 vs 学生"——是启发式加权,不是密度比 | bDeY / UyKJ / y9x6 |
| R3 | **收益归因混淆**:到底是纠偏框架有效,还是 BC 通道"更多模仿监督"有效?缺隔离分析 | y9x6 |
| R4 | **pick-two 例外**:组合探索型任务上 GRPO 反超所有教师混入方法——教师示范并非总有益,论文未解释 | UyKJ |
| R5 | **超参过多、系统复杂**:判别器要训练同步、比率要稳定、进度图要构建——"额外活动部件带来工程开销与新故障模式" | UyKJ / y9x6 |
| R6 | **单 seed 无置信区间**:稀疏奖励 RL 高方差,增益可能是训练方差伪影 | y9x6 |
| R7 | **教师依赖不明**:缓存规模/质量/多样性敏感性未探;泛化性限于可做状态匹配的文本环境 | 三位共同 |

**迁移逻辑:CATALYST 不是 DUET 换皮,而是对每条批评的结构性回应**——

| 批评 | CATALYST 的回应(现状) |
|---|---|
| R1 手工 shaping | **删除**状态匹配与 shaping 整条线;教师影响只经两个信息通道(prompt 参考 / 起点选择),损失恒为纯 PG;v4 进一步收敛为单一分配法则 |
| R2 DR3 存疑 | **删除**判别器与密度比整套机制——教师 token 根本不进损失(零模仿不变式),off-policy 权重的需求从根上消失 |
| R3 模仿混淆 | v1 的受控失败直接实证了这个混淆的危害(token 克隆带毒,§二);v2 起零 token 克隆,任何增益只能来自 RL 本身,归因干净 |
| R4 pick-two 例外 | 被我们复现并推广:健康 GRPO 的裸探索覆盖率 78%(§三)——这个"例外"其实是常态;v4 的目标锚定因子 (1−V̂_裸) 让教师影响在裸探索足够强时**自动让位**,把评审指出的现象变成了机制设计的输入 |
| R5 复杂度 | v4 参数 15→4、净代码负增长;新增部件只有一张成功率统计表(对照 DUET:判别器+进度图+双通道调度) |
| R6 单 seed | 本轮协议:所有对照 3 seed 报均值±std;另有贪心假象研究与健康基线重跑(§五)回应测量可靠性 |
| R7 教师依赖 | 学生状态池使教师素材在 epoch 2 即退役(命中率 0.92,§四)——教师依赖**自动衰减且可测量**;hint 通过 critic 自退火;多环境扩展(WebShop/DeepSearch/SciWorld)在计划内、教师数据已采 |

**一句话**:NeurIPS 的七条批评被我们凝练为一个立项命题——"teacher 的 off-policyness 如何闭环地取其精华、去其糟粕,加速学习而不伤天花板"——CATALYST 的每一代都是对这个命题的一次逼近,评审最担心的三件事(手工 shaping、模仿混淆、复杂度)在结构上已不存在。

## 一、一页总览:四代方法,三次失败,每次失败都换来一条机制定律

| 版本 | 核心机制 | 结果(pass@1/pass@3 峰值) | 裁决 | 换来的定律 |
|---|---|---|---|---|
| v1 转写重放 | 提示引导成功 → 剥提示 token 克隆(BC) | 46.7 / 64.6 | ❌ 输 GRPO | **L1:off-policyness 有两层**——"谁写的 token"与"写时条件于什么";剥条件再克隆 = 亲手制造第二层 |
| v2 entry-k 阶梯 | 教师中局状态接管 + 阶梯课程 + 治理 | 44.7 / 57.6 | ❌ 输 GRPO 也输 v1 | **L2:组基线零梯度病**——同起点/高成功率的小组组内全同,GRPO 组均值基线发不出梯度 |
| v3 分布课程 | 逐槽 frac 采样 + 课程 critic + 学生状态池 | **69.7 / 84.4**(step 60) | ⚖️ 前 60 步大胜,终点微败 | **L3:熵是探索预算**——课程把 100 步的探索燃料 60 步烧完;臂不退场变成税 |
| v4 统一法则(设计已验证,待实现) | 一个公式统一"练什么"与"怎么计账" | 回放验证通过 | 🔜 | 把 v1–v3 的五个补丁收敛为一条分配法则 |

**基线也有故事**:老 GRPO 基线(53.5/73.4)被环境泄漏拖残;健康重跑版 GRPO10 达到 **69.1/88.9**——公平基线比我们想象强 15pp。当前真实战局:**v3 与健康 GRPO 各胜一段**(v3 加速 1.5–2 倍,GRPO 终点微幅领先但统计平局)。

## 二、v1:转写重放——毒从"剥条件"进来

**设计**:角点任务注入教师思路提示("提示当参考、答案自己写"),成功轨迹剥掉提示后做 token 级 BC 重放。零模仿不变式:教师 token 永不进损失。

**结果**:采样口径全面输 GRPO(41.0 vs 50.6 pass@1 @step50)。

**归因(逐轨迹阅读 + 全量行为指纹)**:
- **21.0%(361/1715)的入池轨迹,think 在明确引用提示**("The reference mentioned the laptop is on the sofa");剥掉提示再克隆这些 token = 训练模型**凭空引用不存在的参考**;
- 行为指纹:"Wait" 口癖从 0.1% 涨到训练期 9.4%、评测 step50 爆至 **61.9%**(GRPO 全程 0.0%);状态幻觉("CD 肯定被别人拿走了")2 倍于 GRPO;think 词数被钉死(GRPO 自发从 40 词涨到 161 词,v1 停在 42);
- 典型案例:拎着喷瓶在柜子和马桶之间来回 20 步找喷瓶——工作记忆崩坏;
- **CLL 自校准门(w=min(1,e^φ))没防住**:φ 零点校准假设样本在分布内,剥提示后恰在需要防守时失效;teacher forcing 下泄漏短语只有第一个 token 意外。

**定律 L1**:零模仿不变式在 token 层成立、在信息层失守。修法方向:**转移走环境,不走克隆**。

## 三、v2:entry-k 阶梯——三条机制断层 + 意外发现第四条

**设计**:砍掉重放;教师中局状态接管(重放教师前 k 个 action 推进环境、学生接管,教师 think 从不出现)+ 阶梯课程(75%→50%→25%)+ 治理(促升/退休)。

**结果**:病灶全部清除(Wait 0.0%、状态幻觉 0、think 恢复),但采样口径**连 v1 都不如**(44.7/57.6 vs 46.7/64.6),且 pass@1 峰值出现在 step 10 后一路平坦。

**归因(9,747 条训练轨迹逐条归臂 + 素材册对账)**:

1. **组内相关性坍缩**:同任务 4 个 entry 槽共享同一确定性起点 → 结局高度相关。294 个 entry 组:全败 46.9%、全成 35.4%、**混合(有梯度)仅 17.7%**——甚至低于同任务裸对照组的 20.3%。真正携带梯度的 entry rollout 仅约占总量 2%;
2. **阶梯遍历算术不可行**:走完梯子最少 150–200 步 > 100 步训练预算(800 任务每 50 步才轮到一次);100 步内 0 个任务毕业;
3. **教师状态不在学生分布上**:87 步后角点任务自身裸成功率纹丝不动(0.057→0.058)——练会了"从教师走到的状态续写",但学生自己到不了那些状态(状态层 exposure bias);
4. **(意外的第四条,影响最大)hint 臂零梯度**:SR_hint≈0.83 的 2–4 槽小组,~72% 概率组内全同 → 分臂组基线优势恒 0——**最强的通道大部分时间不产生梯度**。合并账本:v1/v2 ≈ 把 15–30% rollout 投入零梯度黑洞的 GRPO。

**决定性对照**:任务覆盖率(4 采样至少成一次)GRPO 78% vs v2 62% / v1 64%——"GRPO 在角点全 0"的立论预设在 val 端不成立,GRPO 的裸探索自己攻克了大量任务。

**定律 L2**:高成功率 × 小组 × 组基线 = 自我消音。课程越成功,组基线越失灵。

## 四、v3:分布课程 + 课程 critic + 学生状态池——加速成立,续航不足

**设计**(对 L2 的机制级修复):
- **分布课程**:4 个 entry 槽逐槽独立采样 frac(去相关),区间按成败移动;
- **课程 critic**:entry/hint 臂优势改为 A = r − V̂(逐任务分段 EMA,全局段退化兜底)——全同组照样出梯度;
- **学生状态池**:entry 起点改为学生自产成功轨迹的中途状态(hint 造燃料 → 状态入池 → 学生从自己的状态练裸续写),教师册仅冷启动兜底;
- 角点混臂 2 hint + 4 entry + 2 裸。

**结果(与健康基线 GRPO10 同协议对照)**:

| step | v3 (p@1/p@3) | GRPO10 | v3 领先 |
|---|---|---|---|
| 30 | 50.6 / 71.9 | 43.9 / 62.3 | +6.7 / +9.6 |
| 50 | 61.5 / 77.7 | 46.9 / 65.6 | +14.6 / +12.1 |
| **60** | **69.7 / 84.4** | 48.2 / 67.4 | **+21.5 / +17.0** |
| 80 | 62.3 / 78.7 | 62.7 / 80.9 | −0.4 / −2.2 |
| 100 | 66.4 / 82.2 | 69.1 / 88.9 | −2.7 / −6.7 |

- **加速结论性成立**:v3 在 step 60 达到 GRPO10 需要 90–100 步才到的水平(**1.5–2 倍步数效率**);覆盖率 step 30 时 98 vs 84;
- **机制全部按设计闭环**:状态池命中率 0.86–0.92(教师册在 epoch 2 基本退役)、critic 自退火(hint 优势 0.8→0.05)、重放 divergence 全程 0;
- **终点微败但统计平局**:峰对峰 69.7 vs 71.1(差 1.4pp,SE 2–4pp)。

**为什么 60 步后被反超(深度归因)**:

1. **熵透支(主因)**:critic 对成功发统一正优势 → 探索更快兑换为利用;v3 熵在 step 55 塌到 0.155,**GRPO10 到终点熵还有 0.46–0.59**。覆盖率停在 111 的时刻恰是熵塌的时刻;GRPO10 靠健康的熵把尾部任务磨到 116;
2. **臂税不退火**:臂预算全程 14–25%,毕业条件 100 步内一次未触发;v3 训练批成功率从 step 40 起顶死在 73%(批被课程垫得太容易),GRPO10 的 54%→72% 全程在前沿;
3. **基建扰动**:60→70 的 21.5pp 跳水大半是环境泄漏垂死期喂毒(128 题中 62 题同时变差,全盘性;39 个重灾任务 22 个在 80 步恢复;v1/v3/GRPO10 三个 run 全死在 step≈76 的 mmap 天花板)。

**定律 L3**:课程的收益前置,不设退场机制就变成税;熵是有限的探索预算,统一正优势是它的透支通道。

## 五、基线的教训:被基建拖残的对手不配当基线

- 老 GRPO 与 GRPO10 配置 diff 后**唯一差异是漂移门阈值**(数值地板 0.02→0.025),但终点 val 差 34pp(39.1 vs 73.4);
- 根因:老 GRPO 100 步跑在同一作业里,AlfWorld 栈的 libdownward mmap 泄漏使其后半程**训练数据和评测都在垂死环境上**(val 从 55.5 塌到 22.7 的形状与泄漏进程一致);
- 处置:①所有对照重跑于健康协议;②队列加**预防性换血**(每 50 步主动轮换作业换新环境栈,对齐 checkpoint 边界);③上游一行真修尝试(PddlEnv.close 调 close_lib)单进程有效但生产负载下 AgentGym 硬崩,已回滚,离线压测归因进行中;
- **方法学结论:基建健康度值 15pp——比大多数算法改进都大。任何"超越"必须先证明基线是健康的。**

同期沉淀:基建雷区册(L1–L10 + N1–N7,均实炸过)、统一作业前置库、提交前配置校验器、队列熔断、评测方法学(贪心把跌幅放大一倍、系统性低估 agentic 策略 5–10pp;裁决一律用采样 pass@1/pass@3 + 覆盖率)。

## 六、v4:把五个补丁收敛为一条法则(设计已完成回放验证)

**动机**(导师要求:不做 DUET 式缝缝补补):复盘发现 v1–v3 的每个补丁都在近似同一件事。

**统一法则**:一个任务有一族练法 context c ∈ {裸、带提示、从进度 f 接管}(教师知识只扩充 context 集合,永不进损失)。对每个 (任务, c) 维护成功率后验 V̂,则:

> **分配**:8 个槽位按可学习性打分竞价——裸:V̂(1−V̂);辅助:V̂(1−V̂)·**(1−V̂_裸)**(目标锚定:脚手架价值与目标未解决程度成正比);每任务保底 2 裸槽(目标分布锚定)。
> **计账**:每条 rollout 优势 A = r − b,b = Beta 后验留一均值 (n₀·m + Σ_{j≠i} r_j)/(n₀ + k − 1)。
> **估计**:V̂ 三层收缩——全局分段 EMA(快,追策略非平稳)⊕ 逐任务 EMA(慢)⊕ 精度加权合成。

**性质**:k 大时基线 → RLOO 留一均值(与 Dr.GRPO 弃 std 同盟);context 集合退化为{裸}时**逐字还原 GRPO**;课程的出现、聚焦、退场都是推论;参数从 ~15 个降到 4 个(n₀、α、f 段数、裸保底)。

**与近邻工作的关系**(须在论文中明示):CHORD 的 p(1−p)/LUFFY 的 π/(π+γ) 是 **token 级模仿加权**("教师的哪些 token 值得抄"),我们的 V̂(1−V̂) 是 **episode 级实验分配**("哪种练习值得做"),数学形式同源、作用层级不同;"中等难度采样"思想承自 GoalGAN/TSCL/PLR 课程谱系——我们的增量是①context 族由教师知识生成且零模仿、②一个估计量同时做分配与基线(因此一次性治愈 L2)、③GRPO 是特例。

**历史数据因果回放验证**(12,800 条 v3 真实 rollout,估计器只见"当时已发生"的数据):

| 检验 | 结果 | 裁决 |
|---|---|---|
| 携梯度行占比 | 组基线 43.0% / v3 critic 53.7% / **拟议 77.2%** | ✅ 强通过 |
| 分配退火 | 无锚定因子:恒 60% 不退火(**第一版被证伪**);加锚定后 39.8→33.9% 自发下行,中带命中 51.4→63.6% 上行 | ✅ 证伪→修正→通过 |
| 优势均值(熵前提) | 逐 era −0.02/+0.02/+0.01,无系统性正质量 | ✅ 通过 |
| 校准(Brier) | 0.259,未稳定优于常数基线(离线标签噪声所致;运行时标签精确) | ⚠️ 列为在线一级探针,连续劣于即停车 |

回放能证伪不能证实(策略在新分配下的演化离线不可见)——但设计已从"推演可信"升级为"历史数据不反对、且被数据改进过一轮"。

## 七、可进论文的科学发现清单

1. **off-policyness 的两层分解**(token 层 / 信息-条件层)+ 剥条件克隆的失败案例与行为指纹证据链(引用泄漏 21% → "Wait" 61.9%);
2. **组基线零梯度病**:课程/引导成功率越高,GRPO 组基线越失灵(三次独立发作:角点裸组、同起点 entry 组、高 SR hint 组);统一解 = 带先验的留一基线;
3. **熵即探索预算**:统一正优势的透支机制 + 健康 GRPO 的熵-覆盖率联动实测(熵 0.5 vs 0.15 ⇄ 覆盖 116 vs 111);
4. **课程价值前置定律**与目标锚定退场因子 (1−V̂_bare);
5. **评测方法学**:贪心假象(放大跌幅 2 倍、低估 5–10pp)、覆盖率作为 pass@k 的机制解释量、被基建拖残的基线(34pp)——"公平基线是最难的 baseline";
6. **加速×天花板**的主命题实证:v3 已给出"1.5–2 倍加速、终点统计平局"的单 seed 证据,v4 冲"全程支配"。
