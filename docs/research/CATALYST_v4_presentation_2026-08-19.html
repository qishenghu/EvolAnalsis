v4 是什么:一条法则,四个参数

一个任务的一族练法 context ∈ { 裸做 · 带提示做 · 从进度 f 接管做 }
教师知识只扩充这个集合(prompt / 起点),永不进损失

估计:V̂(任务,c) = 全局分段 EMA ⊕ 逐任务 EMA(精度加权收缩)

排产:裸 m(1−m);辅助 m(1−m)·(1−V̂裸)(目标锚定)

计账:A = r − (n₀m + Σj≠irj)/(n₀+k−1)(所有臂统一)

还原性:context 退化为{裸} → 逐字还原 GRPO/RLOO

参数 15 → 4;课程的出现、聚焦、退场全部是推论,不再有手调阈值

胜因 A:统一优势基线 —— 三处零梯度病一次治愈

  • GRPO 组均值基线的死穴:组内全同 → 零梯度。三代人踩了三次:角点裸组(v1)、同起点 entry 组(v2)、高成功率 hint 小组(v1–v3)
  • 历史回放:携梯度行 43.0% → 77.2%;在线实测 0.56–1.0
  • 隐藏红利:辅助退场后,v4 的"纯 GRPO 阶段"仍是更好的 GRPO——全同裸组照样出梯度,领先没有被回吐
